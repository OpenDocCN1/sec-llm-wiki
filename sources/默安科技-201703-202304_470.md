# 默安科技入选“网络安全行业全景图”酷厂商

近日，权威安全媒体“安全牛”发布2017年网络安全行业全景图。17个安全领域的200家安全企业和相关机构入选，其中默安科技入选“酷厂商”。

 

![](../Images/8438e2689f5b1a0b42f8b98be74e3ff1.png)

 

5月份，WannaCry勒索者病毒爆发，一夜间突袭150个国家，使至少30万台电脑被病毒感染。让行业和企业意识到：在云计算逐步普及的今天，网络边界越来越不清晰，业务应用场景越来越复杂，但是企业的云上、云下却存在大量漏洞及威胁，病毒只需要入侵一台设备，就能瞬间感染网内缺乏防护的其他设备。从而攻陷企业云下网络，并扩散至云上网络。

 

基于威胁的变化及客户的防护的需求，默安科技针对云上的云计算安全、云下的研发安全推出了一系列解决方案。

 

依托海量数据和深度机器学习，默安科技发布了全面管控云计算平台安全风险的“磐石”云平台安全解决方案和“墨盾”云租户安全解决方案，提供态势感知、幻盾欺骗防御云蜜网、云平台防火墙、镜像安全检测以及哨兵云、云应用防护、防篡改、DDoS防护产品和服务。同时，结合静态白盒分析、被动测试、大数据挖掘等技术，默安科技还推出了包含“雳鉴”被动扫描模块的DevSecOps（安全开发生命周期）解决方案，并提供渗透测试、蓝军对抗、安全培训等服务，从而为企业提供从云下到云上的全方位安全保障和从研发到运营的一致性安全体验。

 

　　默安科技由原阿里安全部总监聂万泉、资深安全专家云舒和高级安全专家汪利辉联合创立。其中，云舒、聂万泉2009年作为阿里云创始员工，曾负责云平台安全及面向租户的安全产品(云盾)。就在上个月，默安科技入选极客公园“2017年最具投资价值企业榜单”。

 

“2017年网络安全行业全景图由权威安全媒体”安全牛发布。该全景图目的是向社会推荐各安全细分领域的优秀厂商。该全景地图共分为17大安全领域、59个细分领域，包含约200家安全企业和相关机构。
