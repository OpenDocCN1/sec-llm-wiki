# 这两个漏洞覆盖微软大部分操作系统，你公司的服务器和电脑打补丁了嘛？

微软最新公告披露了两个正在被利用的漏洞：LNK文件远程代码执行漏洞和Windows搜索远程命令执行漏洞。利用这两个漏洞，黑客可以借助U盘、光盘、网络共享、邮件等方式对目标发动远程攻击，进而控制用户电脑或公司网络。

![](../Images/c48a9ff0bfb81738b14cdb005110ed8d.png)

这两个漏洞不仅涉及最新的Windows 10系统，还影响到Windows XP、Vista以及Windows Server 2003系统。虽然微软已经停止了对这些老版本系统的官方技术支持，但是公布漏洞修复方案中依旧包含这些老版本。

  

默安科技安全专家表示，这两个漏洞影涉及到微软众多操作系统，建议企业和用户尽快更新相关补丁。  

  

Windows Search远程代码执行漏洞修复补丁地址：

https://support.microsoft.com/zh-cn/help/4025687/microsoft-security-advisory-4025685-guidance-for-older-platforms 

  

LNK文件远程代码执行漏洞修复补丁地址：

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2017-8464

  

上个月，全球大量电脑遭遇勒索病毒攻击，微软紧急发布的修复补丁中包含已停止官方技术支持服务的XP系统。此次微软发布的安全补丁针对大部分Windows系统，不禁让人担心下一轮网络攻击是否很快来到。

  

**什么场景下会触发这两个漏洞？**  

  

微软罪行这两个漏洞的名字分别是：Windows Search远程代码执行漏洞（编号：CVE-2017-8543）、LNK文件远程代码执行漏洞（编号：CVE-2017-8464）。

  

1、黑客可以利用Windows搜索服务送精心构造的SMB消息，从而利用此漏洞提升权限，从而并进一步控制电脑。

  

2、黑客通过移动存储、邮件或远程共享等方式发送一个恶意的LNK文件和关联的恶意二进制代码，当用户用打开该磁盘、共享或解析LNK文件的软件时，恶意文件就会在目标系统上执行攻击者的代码，并进一步控制电脑。

  

3、黑客可以不经身份验证，直接通过SMB服务连接远程触发漏洞，然后控制目标电脑。

**小知识：LNK文件和Powershell**

  

LNK文件：Windows中的快捷链接，不过Windows中的链接文件不止这一种，还有shortcut、hard link、junction point、symbolic link等4种。

  

Powershell：一种通用命令行和Shell脚本语言，可与多种技术进行集成和交互。PowerShell在后台运行。利用PowerShell，可不借助于任何可执行文件而获取系统信息。利用PowerShell，网络犯罪分子已造成了几起引人注目的事件，如2016年3月的PowerWare勒索软件，以及2016年4月的新型Fareit恶意软件变种。因为该类事件有上升趋势，安全管理员已熟知如何防止PowerShell脚本被用于破坏活动。
