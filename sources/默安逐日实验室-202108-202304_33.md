# 在野漏洞分析：CVE-2021-31956 Windows内核提权

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkxMjI3MDgwOA==&mid=2247483752&idx=1&sn=c1b4c093a499d49ac5627437b55441a1&chksm=c10e35dff679bcc91f910e925785592fe15a66fcb7ea45c9dfb941375521fa95e6bc4e69ba1e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzkxMjI3MDgwOA==&mid=2247483752&idx=1&sn=c1b4c093a499d49ac5627437b55441a1&chksm=c10e35dff679bcc91f910e925785592fe15a66fcb7ea45c9dfb941375521fa95e6bc4e69ba1e&scene=27#wechat_redirect)

2021年6月份，卡巴斯基捕获在野0day chrome full chain 利用链，其组织为PuzzleMaker。

  

该利用链使用了Chrome 1day CVE-2021-21220/CVE-2021-21224 V8 RCE 漏洞实现远程代码执行，并串联了内核信息泄露漏洞CVE-2021-31955、Ntfs.sys 内核提权漏洞CVE-2021-31956 来实现沙盒逃逸。  
  
CVE-2021-31956 为整数下溢漏洞，可导致内核池溢出，从低完整度提升到system权限。

  

**01**

**分析**

  

漏洞发生在ntfs.sys 中的NtfsQueryEaUserEaList 函数  

  

![](../Images/1ae130c59c7a0442060f16e4ae6d2545.png)

  
通过构造不同的EA query，其中PrevEaPadding 长度可以为0,1,2,3  
  

![](../Images/ab48c304eb7f44779e16e06dac08f072.png)

  
而在使用API NtQueryEaFile时，可通过控制buffer 长度，在合理设置的情况下进一步使UserBufferLength 为0。  
  
为此当UserBufferLength - PrevEaPadding 出现 0 - 1/2/3 的情况时，eax 会为0xffffffff/...  
  

![](../Images/e2547c128f226cdf1f0a7c989e1830cf.png)

  
于是突破了“if ( RawEaSize <= UserBufferLength - PrevEaPadding )” 的限制，“memmove(NextFullEa, ThisEa, RawEaSize)” 中NextFullEa 位于内核分页池中，将发生池溢出的情况。  

  

**02**

**利用**

  
该漏洞利用较为简单，我们可以控制溢出的数据和大小，直接使用SegmentHeap aligned chunk confusion 来构造任意读，之后通过fake eprocess 来构造任意减，从而修改privileges，进一步获取SeDebugPrivileges 权限，通过远程线程注入winlogon 来弹出cmd。
