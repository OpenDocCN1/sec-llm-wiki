# 八月份恶意软件之“十恶不赦”排行榜

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwOTc4MTE4Nw==&mid=2247485946&idx=1&sn=7d3bc5e07ce014f2fd83eb3d0a604291&chksm=976fe156a01868404a0d9dfbe081f01fc598eb29a974c655531055875aec71be1f47732e320d&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIwOTc4MTE4Nw==&mid=2247485946&idx=1&sn=7d3bc5e07ce014f2fd83eb3d0a604291&chksm=976fe156a01868404a0d9dfbe081f01fc598eb29a974c655531055875aec71be1f47732e320d&scene=27#wechat_redirect)

包括去年以及本年的前几期，我不止一次说明了对国外网站**CheckPoint**每月发布这个排行榜Top10，直译过来应该叫做“**最受欢迎的恶意软件**”。鉴于恶意软件给社会产生带来最多的是不利影响，又是排名前十位，造成的影响相对也是最大的，所以我选用了“**十恶不赦**”来突出表达对这些恶意软件的个人情感。  

![](../Images/fb240412ed8e11ed1e0bbed9fdb2dd5d.png)

根据**Check Point**最新的全球威胁指数，8月份使用**Ramnit**银行木马的攻击大幅增加。由于大规模的攻击活动将受害者的机器转换为恶意代理服务器，**Ramnit**在过去几个月对全球的影响增加近一倍。**8**月份，**Ramnit** 在威胁指数中跃升至第 **6** 位 。这使得它成为使用银行特洛伊木马的上升趋势中最普遍的银行木马，自**2018**年**6**月以来已增加一倍以上。同时标志着黑客越来越多地使用银行木马来瞄准受害者并快速获利。另一个突显出了恶意黑客在企图勒索钱财方面是顽强和复杂的。 

![](../Images/760998235ce8b61b97d7e20a33be6c2b.png)

在此期间，**Coinhive**仍然是最流行的恶意软件，仍占据“**十恶不赦**”之首，全球范围内影响的17％。其次**Dorkbot**和**Andromeda**分别其随其后，位居第二和第三位，全球影响占比为6％。

*\*****箭头与上个月的排名变化有关****。* 

1.  **↔****Coinhive ** - **Crypto Miner**， **Cryptominer**，用于在用户访问网页时执行**Monero**加密货币的在线挖掘，在用户不知情的情况下通过挖掘门罗币获得收入利润。植入的**JavaScript**使用用户机器的大量算力来挖掘加密货币，并可能致使系统崩溃。。
    
2.  **↑****基于Dorkbot ** -是一种基于**IRC**设计的蠕虫，可以以操作员执行远程代码，以及下载其他恶意软件到被感染的机器。是一个银行木马，其主要动机是窃取敏感信息并可以发起拒绝服务攻击。
    
3.  **↑Andromeda** - 是一款模块化僵尸程序，主要用作后门。在受感染的主机上，可以修改以创建不同类型的僵尸网络，运行其他的恶意软件。
    
4.  **↓Cryptoloot** - **Cryptominer**，利用受害者的**CPU**或**GPU**功率和现有的资源开采加密的区块链和发布新的加密货币，是**Coinhive**的有力竞争对手。
    
5.  **↔****Jsecoin **\- 可以嵌入网站的JavaScript矿工。使用JSEcoin，可以直接在浏览器中运行矿工，以换取无广告体验，游戏内货币和其他奖励
    
6.  **↑     Ramnit** - 是一款能够窃取银行凭据，**FTP**密码，会话**cookie**和个人数据的银行特洛伊木马。
    
7.  **↔****XMRig **\- 是一种开源利用**CPU**进行挖掘恶意软件，用于挖掘**Monero**加密货币，并于**2017**年**5**月首次被发现。
    
8.  **↓Roughted** - 大规模攻击各种网站和有效负载，以提供用于恶意广告传播，如诈骗广告软件，漏洞利用工具包和勒索软件。可用于攻击任何类型的平台和操作系统，并可以绕过广告拦截软件和指纹识别，以确保其进行最有效的相关攻击
    
9.  **↓Conficker-**允许远程操作和恶意软件下载的蠕虫。受感染的计算机由僵尸网络控制，僵尸网络与其命令和控制服务器联系以接收指令。
    
10.  **↑Nivdort **\- 多用途机器人，也称为**Bayrob**，用于收集密码，修改系统设置和下载其他恶意软件。它通常通过垃圾邮件传播，其中收件人地址以二进制文件编码，从而使每个文件都是唯一的。 
     

![](../Images/22c37455271122b27c8edf38b170c947.png)

**八月份三大移动恶意软件：**  

1.  **Lokibot -     Android**银行木马和信息窃取程序，它也可以变成一个勒索软件，以锁定手机，以防其管理员权限被删除。
    
2.  **Lotoor -     Hack**工具利用**Android**操作系统上的漏洞获取受感染移动设备的root权限。
    
3.  **Triada  -     Android**的模块化后门，为下载的恶意软件授予超级用户权限，有助于它嵌入到系统进程中。Triada也被视为欺骗浏览器中加载的URL。 
    

漏洞方面，首先是CVE-2017-7269，全球影响力为47％。排在第二位的是OpenSSL TLS DTLS心跳信息披露，全球影响力为41％，其次是CVE-2017-5638，影响了36％的组织。

 **八月份的三大漏洞：**![](../Images/b037300b3942f8f4509a087743d22956.png)

1.  **↔****微软IIS的WebDAV ScStoragePathFromUrl缓冲区溢出（CVE-2017-7269）** -通过在R2通过Microsoft Internet Information Services 6.0中的网络到Microsoft Windows Server 2003发送制作的请求，远程攻击者可以执行任意代码或引起拒绝目标服务器上的服务条件。这主要是由于HTTP请求中对长报头的不正确验证导致的缓冲区溢出漏洞。
    
2.  **↑OpenSSL     TLS DTLS****心跳信息泄露（CVE-2014-0160;     CVE-2014-0346）** - OpenSSL中存在信息泄露漏洞。该漏洞是由于处理TLS / DTLS心跳包时出错。攻击者可以利用此漏洞披露已连接客户端或服务器的内存内容。
    
3.  **↑D-Link     DSL-2750B****远程命令执行** - D-Link DSL-2750B路由器中报告了一个远程执行代码漏洞。成功利用可能导致易受攻击设备上的任意代码执行。
