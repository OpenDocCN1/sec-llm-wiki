# 思科发布其产品中32种缺陷的安全补丁更新

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwOTc4MTE4Nw==&mid=2247485933&idx=1&sn=bf29f6ddc476d101f6313e0356169c42&chksm=976fe141a01868573b01ac16ddfb5e0c1b1b66fcbd2c8042057d3613b1af639263912c05224f&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIwOTc4MTE4Nw==&mid=2247485933&idx=1&sn=bf29f6ddc476d101f6313e0356169c42&chksm=976fe141a01868573b01ac16ddfb5e0c1b1b66fcbd2c8042057d3613b1af639263912c05224f&scene=27#wechat_redirect)

思科9月5日发布了 30项安全补丁咨询，以解决其产品中总共32个安全漏洞，其中三个安全等级被评为“**高危**”，包括解决最近披露的**Apache Struts**远程代码执行漏洞。  
  
在其余29个漏洞中，有14个被评为“**高**”，15个“**中**”，解决了Cisco Routers，Cisco Webex，Cisco Umbrella，思科SD-WAN解决方案，思科云服务平台，思科数据中心网络等产品的安全漏洞。![](../Images/b420c59ad4aa8996af453f430917b0d2.png)

  
  

思科解决了三个关键安全漏洞**Apache Struts，Cisco Umbrella API**和**Cisco RV110W**，**RV130W**和**RV215W**路由器的管理界面问题。

![](../Images/7c004b62548ed92103bcbdd664d80871.png)

Apache Struts中的漏洞可能允许未经身份验证的远程攻击者在目标系统上执行任意代码。  

![](../Images/e019616bc3a1b928b399f378659c921e.png)

该漏洞的存在是因为受影响的软件不能充分验证用户提供的输入，允许使用没有命名空间值的结果以及使用没有值或操作的  *url*标记。如果上层操作或配置也没有命名空间或通配符命名空间，则攻击者可以通过发送向受影响的应用程序提交恶意输入以进行处理的请求来利用此漏洞。如果成功，攻击者可以在目标系统上受影响的应用程序的安全上下文中执行任意代码。

![](../Images/34f4036f097f2706e5c399b951e63a3f.png)

  

Cisco Umbrella API中的漏洞可能允许经过身份验证的远程攻击者查看和修改其组织和其他组织中的数据。

该漏洞是由于Cisco Umbrella的API接口的身份验证配置不足。攻击者可以利用此漏洞查看并可能修改其组织或其他组织的数据。成功利用漏洞可能允许攻击者跨多个组织读取或修改数据。思科发布了解决此漏洞的软件更新。![](../Images/acd38c43fffb9c351aeae732ca50eb91.png)

Cisco RV110W Wireless-N VPN防火墙，Cisco RV130W Wireless-N多功能VPN路由器和Cisco RV215W Wireless-N VPN路由器的基于Web的管理界面中的漏洞可能允许未经身份验证的远程攻击者导致拒绝服务条件或执行任意代码。![](../Images/993aad0d7bc76854f2db17555cefb955.png)  

鼎信在此郑重提醒广大用户朋友，请检查自己网络环境，是否存在受影响的网络设备，及时更新固件、软件补丁，降低安全风险。欲要了解详情，请通过右下方“**原文链接**”前往思科官网。
