# 警惕GlobeImposter勒索病毒针对高价值服务器的攻击

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwOTc4MTE4Nw==&mid=2247485876&idx=1&sn=b61620a61f0cbed0830e1f87fe53a55b&chksm=976fe118a018680e6bd0da2fd39a6b3256ee3585a4d2a0d2b045492e8e43585b9a83d2ce5c14&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIwOTc4MTE4Nw==&mid=2247485876&idx=1&sn=b61620a61f0cbed0830e1f87fe53a55b&chksm=976fe118a018680e6bd0da2fd39a6b3256ee3585a4d2a0d2b045492e8e43585b9a83d2ce5c14&scene=27#wechat_redirect)

勒索软件程序已经存在多年了，但直到最近几年它们才真正出现的大规模井喷现象，在网络上发布了数以百万计的独立样本，使今天的我们在使用互联网时不得不留意观察他们的每一步。如果你因为降低了警惕和警觉，最终感染了一种名为GlobeImposter最新勒索软件变种，那么就变的很不幸了。据专家分析以及现代密码学理论勾勒的前景来看，如果一旦被加密，除了支付勒索赎金外，几乎是无解的。而网络上所谓帮人解码的人，很有可能只是这个利益链条上的一份子。

一方面国外的信息显示，在过去的几天里，FortiGuard Labs捕获了许多JS（JavaScript）脚本。根据FortiGuard Labs的安全工程师分析，新的GlobeImposter勒索软件变种。FortiGuard Labs安全人员选了其中一个并进行了快速分析。其审查的变体版本是“726”。并演示了这个勒索软件的细节，而最新我国360监测到最新的版本，以及发布了相关的安全警告信息。

![](../Images/bc5c448538d66fc7efdf79604e6385f9.png)

据国内安全企业360安全监测到的情况看，自2018年8月21日起，多地发生GlobeImposter勒索病毒事件，经过定性分析，攻击者在突破边界防御后利用黑客工具进行内网渗透并选择高价值目标服务器人工投放勒索病毒，360安全监测与响应中心对该事件的风险评级为高危。而且，被新变种感染后服务器文件被加密，且加密文件名后缀为\*.RESERVE。360方面认为，这次攻击事件不同以往普通的勒索病毒事件，除了之前的传播手段外，还通过RDP弱口令暴力破解服务器密码，人工投毒（常伴随共享文件夹感染）成为主要手段。

以下是360给出的一些信息，供大家参考：

**攻击工具及特征**

 ![](../Images/c878fb037a1a3c4454a910cf3dbc2c14.png)

  

黑客突破边界防御后，会以工具辅助手工的方式，对内网其他机器进行渗透。通过对多个现场的调查，黑客所使用的工具包括但不限于：

  

1.  全功能远控木马

2.  自动化添加管理员的脚本

3.  内网共享扫描工具

4.  Windows 密码抓取工具

5.  网络嗅探、多协议暴破工具

6.  浏览器密码查看工具

 

攻击者在打开内网突破口后，会在内网对其他主机进行口令暴破。在内网横向移动至一台新的主机后，会尝试进行包括但不限于以下操作：

1.  手动或用工具卸载主机上安装的防护软件

2.  下载或上传黑客工具包

3.   手动启用远程控制以及勒索病毒

 

![](../Images/c520ebf082b8c82cc814f692a9bf7ec3.png)

   

**易受攻击影响的机构**

  

 

  

本次攻击者主要的突破边界手段可能为Windows远程桌面服务密码暴力破解，在进入内网后会进行多种方法获取登陆凭据并在内网横向传播。

  

综上，符合以下特征的机构将更容易遭到攻击者的侵害：

1.  存在弱口令且Windows远程桌面服务(3389端口)暴露在互联网上的机构。

2.  内网Windows终端、服务器使用相同或者少数几组口令。

3.  Windows服务器、终端未部署或未及时更新安全加固和杀毒软件

 

![](../Images/339861b9578d3be608da2549d3bf5fee.png)

  

**处置建议**

  

 

**一、紧急处置方案**

 

1.  对于已中招服务器:  下线隔离。

2.  对于未中招服务器:

1）在网络边界防火墙上全局关闭3389端口或3389端口只对特定IP开放。

2）开启Windows防火墙，尽量关闭3389、445、139、135等不用的高危端口。

3）每台服务器设置唯一口令，且复杂度要求采用大小写字母、数字、特殊符号混合的组合结构，口令位数足够长（15位、两种组合以上）。

 

![](../Images/9fabd73ac2c818a5b36900d9731fdf43.png)

**二、后续跟进方案**  

 

 对于已下线隔离中招服务器，联系专业技术服务机构进行日志及样本分析。

 

**服务器、终端防护**

 

1.  所有服务器、终端应强行实施复杂密码策略，杜绝弱口令

2.  杜绝使用通用密码管理所有机器

3.  安装杀毒软件、终端安全管理软件并及时更新病毒库

4.  及时安装漏洞补丁

5.  服务器开启关键日志收集功能，为安全事件的追踪溯源提供基础

 

![](../Images/76a8910ba39e752711e54dcba516e97d.png)

**网络防护与安全监测**  

 

1.  对内网安全域进行合理划分。各个安全域之间限制严格的 ACL，限制横向移动的范围。

2.  重要业务系统及核心数据库应当设置独立的安全区域并做好区域边界的安全防御，严格限制重要区域的访问权限并关闭telnet、snmp等不必要、不安全的服务。

3.  在网络内架设 IDS/IPS 设备，及时发现、阻断内网的横向移动行为。

4.  在网络内架设全流量记录设备，以及发现内网的横向移动行为，并为追踪溯源提供良好的基础。

 

![](../Images/d23ca3ffad6a0fe4e682c6fc91b75d03.png)

**应用系统防护及数据备份**  

 

1.  应用系统层面，需要对应用系统进行安全渗透测试与加固，保障应用系统自身安全可控。

2.  对业务系统及数据进行及时备份，并验证备份系统及备份数据的可用性。

3.  建立安全灾备预案，一但核心系统遭受攻击，需要确保备份业务系统可以立即启用；同时，需要做好备份系统与主系统的安全隔离工作，辟免主系统和备份系统同时被攻击，影响业务连续性。

 ![](../Images/b5d0a49d776206ce08bc63ff01871cea.png)

最后360给出的结语中，是我们老生常谈的几句话了，再次我们借花献佛再次引用360结语内容，期盼大家能够重视并认真对待自己的网络。在此，再次强调“**安全意识即自我保护意识**”，没人喜欢自身财产及周围环境受到危害，那么保护好她，从安全意识开始。加强安全意识保护好自己的网络，保护好自己的声誉，保护好自己的财产，保护好自己！![](../Images/92e302cee724a0fdb023c43d433bcf25.png)

安全防护本身是一个动态的对抗过程，在以上安全加固措施的基础上，日常工作中，还需要加强系统使用过程的管理与网络安全状态的实时监测：

1、  电脑中不使用不明来历的U盘、移动硬盘等存储设备；不接入公共网络，同时机构的内部网络中不运行不明来历的设备接入。

2、   要常态化的开展安全检查和评估，及时发现安全薄弱环节，及时修补安全漏洞和安全管理机制上的不足，时刻保持系统的安全维持在一个相对较高的水平；（类似定期体检）

3、   及时关注并跟进网络安全的技术进步，有条件的单位，可以采取新型的基于大数据的流量的监测设备并配合专业的分析服务，以便做到蠕虫病毒的第一时间发现、第一时间处置、第一时间溯源根除。![](../Images/f7f3479379491a4f6f9edbd662a3eda2.png)
