# 从CIA通过网络安插“间谍“遍布世界各个角落说起

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwOTc4MTE4Nw==&mid=2247485845&idx=1&sn=37aa8ead4107f07174ec0bdf51239bb5&chksm=976fe139a018682fe9d203ecb409a1275139ccb62df016e1a8c214edcacc5b8e642c9132b1bd&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIwOTc4MTE4Nw==&mid=2247485845&idx=1&sn=37aa8ead4107f07174ec0bdf51239bb5&chksm=976fe139a018682fe9d203ecb409a1275139ccb62df016e1a8c214edcacc5b8e642c9132b1bd&scene=27#wechat_redirect)

**特朗普“黑衣人”看日食**

去年，美国总统看日食之前，宣布美军网络司令部升级，基本上向世界宣布网络战争的可能性大大增加，而美国又在**FBI**的策动下，到处搜寻其他国家所谓的网络间谍，以制造被伤害的假象。同时，最近我们看到美国撕毁与伊朗签署的核协议，同时美联社及美国各大安全网站都在鼓吹伊朗黑客反击的问题。我们也看到维基解密，一次次给**CIA**上新菜点眼药，通过新菜让世人，至少信息安全界以及各国政府看到了美国是有多么诚意的破坏全世界的网络安全，危及世界信息安全的。

![](../Images/9ee4be7f6db14ec09e3401667807272d.png)

维基解密发布了**CIA**的一个“**Vault 7**”的漏洞黑客工具一个接一个，最后的更新是“**Vault 8**”的第一个黑客工具。通过“**Vault 7**”是一个系列看，“**Vault 8**”不可能是只有一个恶意软件工具，应当也是一个系列，何时完全被揭秘，这个有待时间考验。通过“**Vault 7**”、“**Vault8**”揭示了**CIA**是如何通过网络在世界各地安插的间谍伙伴紧密协作，秘密进行网络间谍活动收集世界各地系统中的数据的。**CIA**为世界各地的联络特工提供了，具有预设置的操作系统和软件特征收集系统的硬件，来实现将世界各地生物验证特征系统上数据进行分享。以此，我们不自然的就会想到斯诺登事件有关“棱镜门”的一些往事。

今天，咱们一起回顾一下“**ExpressLane**”被维基解密曝光的恶意软件工具。**CIA**可以对于那些不愿意分享他们的生物特征数据的代理机构，**CIA**的技术服务局（**OTS**）则开发了一种能秘密渗透到系统，从中收集数据的工具。其名曰：**ExpressLane**。这是**CIA**提供的一个可以手动升级，安装到生物识别系统的间谍软件。

由维基解密泄露的**CIA**文件显示，世界各地被**OTS**人员访问后，会被秘密安装**ExpressLane**木马，同时安装显示升级安装屏幕信息及进度条，看上去好像是在升级你的正常的生物识别系统。其实正在安装**CIA**炮制的木马，你的设备上收集的个人生物识别信息将通过网络，被**CIA**抓取走。

![](../Images/773b83fb8bbebcf4d02a3a8ce39be7ea.png)

其中说明文档介绍到，**ExpressLane包含**两个组件：

创建分区：在目标系统上创建一个隐藏的分区，以加密和压缩的形式存储收集的信息。

![](../Images/f38b8546847a62b0e0b967f8a4b021b0.png)

**数据导出**：英文原文是“Exit Ramp”。用以访问上传隐藏分区收集到的生物指纹并隐藏加密的数据。

![](../Images/143457fc0bca75dd0a3c4c96f9399286.png)

此款间**CIA**谍软件的最新版本是**ExpressLane3.1.1**，默认情况下会在安装后六个月，为了节省空间会自行删除。当然**OTA**人员也可以根据需要，来修改删除修改日期。

据维基解密文档介绍，**CIA**提供的这款生物识别系统是基于**Cross Match**的产品，同时这家公司的产品也曾经帮助美军对本拉登尸身进行身份鉴别。曾经帮助过美军将本拉登验明正身的“**正义**”公司，转眼变成了美国人民及全世界政府和人民的敌人。因为他不仅仅部署在美国以外的地方，斯诺登已经清楚的告诫美国人了，他们还监视美国国民的日常隐私。根据以前报道结合本次维基解密的**ExpressLane**，在**ExpressLane**之前维基解密共已经发布了**CIA**的**21**批次“**Vault 7**”系列黑客或间谍软件。

![](../Images/b6f2bc17e91e8f7c0c4de3087284b1e8.png)

从中，我们可以清晰的看到。美国在监视本国人民及刺探世界上其他国家信息的疯狂程度，而在维基解密未揭秘之前，给外界的假象是多么的正直与善良，每天吆喝着世界其他国家黑客入侵了他们某某部门，某某处的。而殊不知，贼喊捉贼的竟然是如此疯狂的制造黑客病毒致使其蔓延，而且遍布全球有针对性的刺探他国情报。这是“**世界警察**”的“**正义**”风范吗？美国**CIA**秉持这一种无赖可耻的盗贼嘴脸，结合**FBI**抓捕他国人员，一边背信弃义的盗窃自己国民和他国数据，一边又装扮成一个无辜的受害者。  

以美国的科技实力，随时可以将部队一个小分支伪装成他国的黑客，进而“取证”以制造舆论，掌握媒体话语权，造成被攻击受害者的假象，而攻击美国的恶意工具很多都是出自美国政府之手，例如造成极大影响的“**WannaCry**”其就是美国**NSA**（美国国家安全局）泄露“**EternalBlue**”即“**永恒之蓝**”。所以我们看到的网络世界是真真假假，虚虚实实的。不排除直接看到的现象听到的事件，但也应该多一点警觉冰山下或许藏着更大的东西。

。  

![](../Images/71a767ca106adc97416bf84aee4db512.png)

在网络信息风险不断加剧的今天，作为世界头号强国的责任与担当就是破坏世界网络的安全，这点委实令人感觉到匪夷所思啊。当今世界，中国在快速发展的同时，我们要明白不能因噎废食，既要保证信息化的建设，同时也要保证重要基础设施的建设安全，还有运营单位的安全意识培养。在我们周围是否隐藏着**CIA**的特工，他们不会明白告诉你我，但是我们身边绝对不全是无害的人。维基解密告诉我们，这些幽灵鬼魂们撒旦信徒们，遍布全世界的正冒充者着上帝的使者与子民行苟且之事。  

![](../Images/32fa6ecdef26597d0aea3fa69bb997e7.png)

我们应该在新形势下，保持深刻而清醒认识并勇于创新积极研发我国拥有自主产权的网络安全产品，提升技术等综合实力，同时结合国家的政策法规及公安部门共同构筑一道安全的基础信息网络，使我国的信息安全不断得到加强、巩固。《**网络安全法**》已经实行，我们要切实学习运用《**网络安全法**》，根据《**网络安全法**》作为规范与指导，积累经验提升综合应对能力，把我国由信息安全大国建设为一个信息安全的强国。安全意识其实就是自我保护意识，没有良好的安全意识，就没有良好的自我保护意识，自身安全就会陷入被动挨打的处境。保护网络安全，是一个全方位体系性的东西，是一个常读常新的东西，需要我们必须保持一个日日新的心态，去积极勇敢的面对。

**鼎信，愿与你一起为此担当一份责任。**
