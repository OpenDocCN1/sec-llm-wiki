# 看行业大势所趋：解决IT-OT融合的挑战

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwOTc4MTE4Nw==&mid=2247485777&idx=1&sn=4b6c2abbe9d87b79c26903258020c06b&chksm=976fe1fda01868eb1c3ca43ba05b87daec182e3e8e5072e326f305d742101d34299575a798d6&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIwOTc4MTE4Nw==&mid=2247485777&idx=1&sn=4b6c2abbe9d87b79c26903258020c06b&chksm=976fe1fda01868eb1c3ca43ba05b87daec182e3e8e5072e326f305d742101d34299575a798d6&scene=27#wechat_redirect)

数十年来，计算机和数据网络或称为信息技术（**IT**），使得世界互联互通变得非常便捷。工业控制系统（**ICS**）运营和过程控制组也通常被称为运营技术（**OT**），作为孤立和独立的网络运行，OT与IT的目标和要求完全不同。然而，这状况早已经开始慢慢发生变化，以至于**“工业4.0”**的出现与我国的**“中国制造2025”**的大力推动提倡下，发生着巨大变化。

在最基本的层面上，我们了解到**IT**负责数据的创建，传输，存储和保护。网络威胁可能会对组织产生直接的财务影响，通常会导致市场上客户信心丧失，政策上受到罚款和处罚，甚至是法律层面上发生法律纠纷等等，可谓不一而足吧。

![](../Images/75a4ade67684d4de3d7b1df97fd7e554.png)

而另外一方面，**OT**专注于建立和维护具有物理影响的控制过程，例如生产制造和生产环境。由于新技术与理念在最近的发展过程中，**OT**在数字市场中表现的需要更有效地竞争，现在使得这些传统上独立的环境需要与**IT**环境做有机的融合。我们看到越来越多的行业已经开始通过部署新的工业物联网**（IIoT）**设备（如智能电表，自动化资产分配系统和自我监控变压器）将网络和数字通信集成到**OT**运行环境空间中来，使得**OT**更加高效且便于管理。在看到巨大便捷性与效率之下，我们理应看到起存在的安全风险挑战的一面。

**OT****安全带来的挑战**

**OT**的快速适应新时代的变化为其引入了**IT**方面的新风险。若成功实现网络攻击，攻击**OT**的** ICS**，监控和数据采集**（SCADA）**控制系统甚至连接物理设备（如阀门，仪表或交换机），可能会对关键信息基础设施和服务等，造成破坏性的后果。会影响生产与环境，甚至是危及人的生命。当然还存在引发次生风险，其包括无法正确识别，测量和跟踪的风险，影响面向客户的系统的**IT**中断以及由于灾难性事件导致的业务运营中断。安全风险不仅仅是来自企业组织缺乏安全专业知识的内部员工，还包括安全服务外包给第三方供应商，这些挑战都使得安全风险变得更加复杂。这其中是由于整个计算行业面临的网络安全技能差距日益扩大，最重要的可能是即使是经验丰富的**IT**安全专业人员，大部分可能几乎没有**OT**环境的经验。

因此，研究发现近**90****％****OT**基础架构的组织在其监控和数据采集与工业控制系统（**SCADA / ICS**）架构中遇到了安全漏洞，其中超过一半的漏洞发生在过去**12**个月内。安全问题包括病毒威胁（**77****％**），内部威胁（**73****％**）或外部（**70****％**）黑客威胁，敏感或机密信息泄漏（**72****％**）以及缺乏设备身份验证（**67****％**）。超过三分之一的人现在关注对连接的物联网设备内置的后门的利用。

![](../Images/481f1c75b5043c7869a5a898712c2f74.png)

**克服阻力**  

内部强大的阻力为**IT**与**OT**的融合带来了超强度的挑战，因此两个方面的团队和基础设施结合在一起，使得双方都存在不信任。其主要是由于两个方面的团队在理解和解决网络风险方面存在根本的分歧，其使用的是不兼容的方法。

我们理解的IT的首要安全优先事项是保护数据，包括知识产权，公司财务以及员工或客户私人数据等等不一而足。为了应对这些挑战，他们倾向于遵循传统的**CIA**三个层级来确保安全：机密性**（Confidentiality）**、完整性**（Integrity）**、可用性**（Availability）**。

然而作为另一方面的**OT**使用倒置的**CIA**模型，即遵循的是**AIC**模型，其中可用性是第一位的，安全性通常是把可用性作为首要任务。**OT**团队需要确保控制流程和生产环节等因素不会因网络变化而面临风险。我们因此可以看到**OT**网络中的基础架构组件往往具有更长的生命周期，而传统的**IT**最佳实践方式（如修补和更新）可能会使当前的功能系统处于脱机风险，从而产生重大且意想不到的生产安全后果。

![](../Images/7a95583ee16898fdb2b680bf94c61262.png)

**如何融合**

虽然存在着这些差异，但是作为**“工业4.0”**与**“中国制造2025”**等构想的出现，说明融合是必然的趋势，并非棘手到完全无法调和，而且世界各国信息安全专家以及生产系统运行专家都在研究探讨其融合的合理性。那么需要精心规划和协调，结合开放式沟通和有效的彼此倾听，对于融合这些不同环境来说可谓至关重要。

  

这需要包括：

**执行战略调整**：团队领导者需要深入了解并同意融合这些资源。明确共同目标和定义的预期结果，有助于所有团队推动有效的解决方案的实现。![](../Images/f32bcc0303dc213b909e119ae0f4f217.png)

**建立统一联合工作组**：一旦确定了目标和预期结果，团队的代表应共同讨论发表意见、提出面临的问题，通过合理有效的辩论将要确定的战略，制定一套共同的行之有效的项目流程范围。第一个目标应该是相互提醒项目所面临的挑战。将有助于推动各方提出都能接受的解决方案。当然，这个过程准备需要一定的时间来进行。

**运行试点计划**：试点或测试在信息安全工作中的重要性是不言而喻。联合工作组概述的流程的每一步都需要在受控环境中运行，有时是重复运行，然后才能在生产网络中开始部署实施。在操作控制中存在很多利害关系，安全防范措施和应急计划应用到实际运行环境之前，应进行充分考虑与调整是至关重要的。

![](../Images/28a4973db1619d920a212bc0facad604.png)

**融合不仅仅涉及的是技术**  

集成**IT**和**OT**需要的不仅仅是融合网络资源和技术。组织必须避免为其网络的**OT**部分重复开发安全团队，带来资源的的重复浪费。工作人员，培训和资源的重叠维持不仅是费用问题，而且由此可能导致治理，风险管理和合规问题的产生。

**复杂问题简单化**

新型数字经济的成功，需要开发能够无缝利用所有可用资源的集成网络，当然是包括**OT**网络内部的**ICS** / **SCADA**系统。虽然恶意网络攻击者展现了利用不断扩大的数字攻击的能力，但企业组织需要做出的回应不应当是在他们的安全配线柜中添加新的隔离设备，而是通过部署集成安全框架来优先考虑关键功能，如高效协作，高级分析，以及基于风险的决策，积极的应对策略。这种方法围绕灵活的结构策略进行构建，在规模上实现全面保护，同时将**IT**和**OT**环境中的适当解决方案集成到单个集中式自动化安全系统中。
