# Dixons Carphone数据泄露1000万，尤金卡巴斯基看世界信息安全

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwOTc4MTE4Nw==&mid=2247485775&idx=1&sn=56b5612a663c446c0d584720eb0a46b9&chksm=976fe1e3a01868f59028f60e5fd054f00adb5658686e429a3c5c2b0c12af2702722d244a50b5&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIwOTc4MTE4Nw==&mid=2247485775&idx=1&sn=56b5612a663c446c0d584720eb0a46b9&chksm=976fe1e3a01868f59028f60e5fd054f00adb5658686e429a3c5c2b0c12af2702722d244a50b5&scene=27#wechat_redirect)

**Dixons Carphone**是一家总部位于伦敦的跨国电气和电信零售商和服务的公司，于**2014**年**8**月**7**日由**Dixons Retail**和**CarphoneWarehouse Group**合并而成。 

通过英国《**卫报**》报道，**Dixons Carphone**表示对大规模数据泄露的调查发现，去年可能泄露数据达**1000**万客户的个人数据，这几乎是最初推测设想的**10**倍之多。当初预计涉及未经授权访问的个人记录为**120**万，首次报告为去年**6**月份的数据泄露，但未提供任何切实的证据。 

![](../Images/afcf7261c170bb974413be9bd62d1e5c.png)

首席执行官亚历克斯·鲍多克（**Alex Baldock**）表示：“自去年我们的数据安全审查发现泄露行为以来，我们一直在全力以赴地做好准备。包括关闭未经授权的访问，添加新的安全措施并启动即时调查，才使得我们能够更全面地了解我们今天正在更新的事件。再一次，我们对自己所做的不足之处感到失望，对于我们给客户造成的任何困扰，我们深感抱歉。我想向他们保证，我们将完全致力于使我们的个人数据更安全。”   

同时该公司表示，泄露数据包含客户的姓名，地址或电子邮件地址等个人数据的记录，但没有财务信息。同时，他们正在写信给客户为数据泄露的事情进行道歉，由于没有证据表明有人因此遭受经济损失，因此并未打算支付赔偿金。国家网络安全中心是英国情报和安全部门**GCHQ**的一个分支机构，正在帮助**Dixons Carphone**进行调查。**Dixons**表示已采取进一步的安全措施，以防止未来可能遭受的网络攻击。

![](../Images/03126a01fc67555f2ccfc8b90f65ad87.png)

很庆幸的是**Dixons Carphone**的数据泄露事件是发生在，欧洲通用数据保护条例生效之前，数据泄露发生在**2017**年。根据以前的数据保护法，最高罚款额才为**500,000**英镑。而根据**GDPR**规则，公司可能面临最高**2000**万欧元（**1760**万英镑）或全球营业额的**4****％**，以较大者为准。 

![](../Images/237eed1bfb5f1f318d58112d30a3807c.png)

另外安全新闻里，卡巴斯基实验室的首席执行官尤金卡巴斯基表示，如果我们单独打击网络攻击，我们注定要失败。尤金卡巴斯基谈到，通过他们的“**全球透明度倡议**”，将继续推动开放式合作打开大门：一次改变拯救一次网络世界。
