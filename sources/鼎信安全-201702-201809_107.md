# 四月份十恶不赦的恶意软件排行榜

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwOTc4MTE4Nw==&mid=2247485414&idx=2&sn=eaafd511ac1992d3d99b350d7a7f5e78&chksm=976fef4aa018665c8a3c282358c60d95b98d7517f1f2254e0668a2c67c54723762cc98d2c044&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIwOTc4MTE4Nw==&mid=2247485414&idx=2&sn=eaafd511ac1992d3d99b350d7a7f5e78&chksm=976fef4aa018665c8a3c282358c60d95b98d7517f1f2254e0668a2c67c54723762cc98d2c044&scene=27#wechat_redirect)

我们从Check Point研究人员在分析了来自全球传感器网络和数百万数据点的4月威胁数据后，来看四月份全球威胁指数来看四月份有哪些十恶不赦的恶意软件，可能大家也能预测到，恶意软件的排行榜变化应该不会太大。首先，我们了解到网络犯罪分子利用锁定的是未修复的安全漏洞，加密挖掘恶意软件对世界各地的组织来说仍然是一个日益严重的威胁。

 

Cryptomining到2018年4月，已经是连续第四个月占据十大恶意软件榜首了。Coinhive变种在全球范围内保持16％的最高流行度，而另一个加密挖掘恶意软件Cryptoloot紧随其后，全球范围达到14％，看着这个比例，有时不得不说我们队加密挖掘恶意软件了解甚少。 

另外研究人员发现了一种新趋势，网络犯罪分子针对Microsoft Windows Server 2003（CVE-2017-7269）和Oracle WebLogic（CVE-2017-10271）中的未修补服务器漏洞进行攻击，以此非法获取加密货币。世界上46％的企业组织机构都存在面向Microsoft Windows Server 2003漏洞，而Oracle WebLogic漏洞中紧随其后，全球有40％的企业组织机构，还未修复。

 然而这两个漏洞的安全补丁其实已公开发布至少六个月了，但全球近一半的组织仍受这些已知漏洞的影响。这清楚地提醒企业组织，安全意识及安全基础知识（如修补程序）何其重要，是确保网络安全的必要步骤。为了真正保持安全，企业组织必须采用多层次的网络安全策略，以防止已存在的恶意软件系列及全新的威胁。 

* * *

**2018年4月份十大最高风险恶意软件：**

**\*箭头与前一个月的排名变化相关**

1.  **↔Coinhive** - Crypto-Miner设计用于在用户访问网页时在用户不知情或不批准的情况下执行Monero加密货币的在线挖掘
    
2.  **↑ ****Cryptoloot** - Crypto-Miner，它使用受害者的CPU或GPU功率和现有资源将交易添加到区块链并释放新货币。
    
3.  **↑ ******Roughted**** - 大规模恶意广告用于传递各种恶意网站和有效载荷，如诈骗，广告软件，漏洞利用工具和勒索软件。它可以用来攻击任何类型的平台和操作系统，并利用广告拦截器旁路和指纹识别来确保它提供最相关的攻击。
    
4.  **↑Jsecoin** - 可嵌入网站的JavaScript矿工。使用JSEcoin，您可以直接在浏览器中运行矿工，以换取无广告体验，游戏币和其他奖励
    
5.  **↑Andromeda** - 模块化机器人主要用作后门，在受感染的主机上提供额外的恶意软件，但可以修改以创建不同类型的僵尸网络。
    
6.  **↔**Fireball**** - 可以变成全功能恶意软件下载器的浏览器劫持程序。它能够在受害机器上执行任何代码，从而导致从窃取凭证到丢弃额外恶意软件等各种操作。
    
7.  **↑XMRig** - XMRig是一款用于Monero加密货币挖掘过程的开源CPU挖掘软件，于2017年5月首次在野外发布。
    
8.  **↑Dorkbot-**基于IRC的蠕虫设计允许其运营商远程执行代码，并将其他恶意软件下载到被感染系统，其主要动机是窃取敏感信息并发起拒绝服务攻击。
    
9.  **↑Nivdort-**多用途bot，也被称为Bayrob，用于收集密码，修改系统设置并下载其他恶意软件。它通常通过垃圾邮件与二进制编码的收件人地址进行传播，从而使每个文件都是唯一的。
    
10.  **↓**Necurs** -**僵尸网络用于通过垃圾邮件传播恶意软件，主要是勒索软件和银行木马。
     

 

* * *

Lokibot是一种授权超级用户权限下载恶意软件的Android银行木马病毒，是最受欢迎的恶意软件，用于攻击企业组织的移动设备，其次是Triada和Hiddad。

**四月份排名前三位的“最具威胁”的手机恶意软件：**

1.  **Lokibot** - Android银行木马和信息窃取者，也可以变成勒索软件来锁定手机。
    
2.  **Triada** - Android的模块化后门，授予超级用户权限下载恶意软件。
    
3.  **Hiddad** - 重新包装合法应用的Android恶意软件，然后将它们发布到第三方商店。
    

 

* * *

研究人员还分析了被利用最严重的网络漏洞。首先是**CVE-2017-7269**，全球影响率为**46％**，其次是**CVE-2017-10271**，影响全球**40％**的组织。第三，SQL注入影响全球**16％**的企业组织机构。

 

**四月份最受欢迎的3个漏洞：**

1.  **↑Microsoft IIS WebDAV ScStoragePathFromUrl缓冲区溢出（CVE-2017-7269） -**通过Microsoft Internet Information Services 6.0通过网络向Microsoft Windows Server 2003 R2发送精心制作的请求，远程攻击者可能执行任意代码或导致拒绝服务条件在目标服务器上。这主要是由于HTTP请求中长头部验证不当导致缓冲区溢出漏洞。
    
2.  **↓Oracle WebLogic WLS安全组件远程执行代码（CVE-2017-10271）** - Oracle WebLogic WLS中存在一个远程执行代码漏洞。这是由于Oracle WebLogic处理xml解码的方式。成功的攻击可能会导致远程代码执行。
    
3.  **↓SQL注入** - 在从客户端到应用程序的输入中插入注入SQL查询，同时利用应用程序软件中的安全漏洞。
