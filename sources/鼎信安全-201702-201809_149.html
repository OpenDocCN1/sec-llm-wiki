2018年3月最流行的恶意软件软件是什么？

今年3月，Coinhive连续第四个月保持流行榜的第一的地位，影响18％的组织，其次是Rig EK Exploit Kit（17％），而Cryptoloot是第三（影响15％）。XMRig是8个最常见的恶意软件变体，影响组织的5％。

 

 2018年3月排行前十的恶意软件：

*箭头与前一个月的排名变化相关。

  1. ↔Coinhive - Crypto Miner设计用于在用户访问网页时执行Monero加密货币的在线挖掘，而无需用户了解或批准与用户的利益。植入的JavaScript使用最终用户的巨大计算资源来挖掘硬币并可能导致系统崩溃。

  2. ↑Rig ek - 利用工具包于2014年首次推出.Rig为Flash，Java，Silverlight和Internet Explorer提供漏洞利用。感染链开始于重定向到包含JavaScript的登录页面，该页面检查易受攻击的插件并提供漏洞利用

  3. ↓Cryptoloot - Crypto-Miner，利用受害者的CPU或GPU能力和现有资源进行加密挖掘 - 向区块链添加交易并释放新货币。它是Coinhive的竞争对手，试图通过减少网站收入的百分比来拉动它。

  4. ↑ Roughted - 大规模恶意广告用于传递各种恶意网站和有效载荷，如诈骗，广告软件，漏洞利用工具和勒索软件。它可以用来攻击任何类型的平台和操作系统，并利用广告拦截器旁路和指纹识别来确保它提供最相关的攻击。

  5. ↓Jsecoin - 可嵌入网站的JavaScript矿工。使用JSEcoin，您可以直接在浏览器中运行矿工，以换取无广告体验，游戏币和其他奖励

  6. ↔ Fireball  - 可以变成全功能恶意软件下载器的浏览器劫持程序。它能够在受害机器上执行任何代码，从而导致从窃取凭证到丢弃额外恶意软件等各种操作。

  7. ↑Andromeda - 模块化机器人主要用作后门，在受感染的主机上提供额外的恶意软件，但可以修改以创建不同类型的僵尸网络。

  8. ↑XMRig - XMRig是一款用于Monero加密货币挖掘过程的开源CPU挖掘软件，于2017年5月首次出现在野外。

  9. ↓Necurs- 僵尸网络用于通过垃圾邮件传播恶意软件，主要是勒索软件和银行木马。

  10. ↑Conficker - 允许远程操作和恶意软件下载的蠕虫。受感染的机器由僵尸网络控制，该僵尸网络与其命令与控制服务器联系以接收指令。

 

Lokibot是一种授权超级用户权限下载恶意软件的Android银行木马病毒，是最受欢迎的恶意软件，用于攻击组织的移动房产，其次是Triada和Hiddad。

 

 3月份排名前3名的移动恶意软件：

  1. Lokibot - Android银行木马和信息窃取者，也可以变成勒索软件来锁定手机。

  2. Triada - Android的模块化后门，授予超级用户权限下载恶意软件。

  3. Hiddad - 重新包装成合法应用的Android恶意软件，然后将它们发布到第三方商店。

由CheckPoint的研究人员，进行了一次分析，被利用最严重的网络漏洞。CVE-2017-10271的全球影响率为26％，排在第二位的是影响19％的SQL注入漏洞，排在第三位的是CVE-2015-1635，全球影响率为12％。

 

3月份最受欢迎的3个漏洞：

  1. Oracle WebLogic WLS安全组件远程执行代码（CVE-2017-10271） - Oracle WebLogic WLS中存在一个远程执行代码漏洞。这是由于Oracle WebLogic处理xml解码的方式。成功的攻击可能会导致远程代码执行。

  2. SQL注入 - 在从客户端到应用程序的输入中插入注入SQL查询，同时利用应用程序软件中的安全漏洞。

  3. Microsoft Windows HTTP.sys远程执行代码（MS15-034：CVE-2015-1635） - Windows操作系统中报告了远程执行代码漏洞。该漏洞是由于HTTP.sys处理恶意HTTP头的方式造成的。成功的利用会导致远程代码执行。
