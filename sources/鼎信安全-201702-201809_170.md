# “中本聪”面临巨额起诉，监控比特币美国国税局胜诉

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwOTc4MTE4Nw==&mid=2247484858&idx=1&sn=4807db9c300835ed3251a14c3d0ff7d4&chksm=976fed16a0186400d91c5d25d288389fd0428c34b6da35741950f65ee9f725c4237d1a470c54&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIwOTc4MTE4Nw==&mid=2247484858&idx=1&sn=4807db9c300835ed3251a14c3d0ff7d4&chksm=976fed16a0186400d91c5d25d288389fd0428c34b6da35741950f65ee9f725c4237d1a470c54&scene=27#wechat_redirect)

**说故事前，先上一张自称“中本聪”的Craig Wright的图片。**

![](../Images/3d8846b7dc0a9a31756fdb04affbf32b.png)

据报道，自称是比特币发明人的澳大利亚人**Craig Wright**被其前商业伙伴的家人起诉。报道称，**Wright**与**Dave Kleiman**一同开发了比特币，而**Kleiman**的比特币被**Wright**扣押，其涉嫌扣押数量居称在**30**万到**110**万之间。

该诉讼称“目前还不清楚**Wright**与**Kleiman**是否都创造了比特币。当然，不可否认的是二人从一开始就参与了比特币，并积累了大量的比特币。”而**Wright**通过伪造文件说服了**Kleiman**的家人，称**Kleiman**已经将两家公司的全部所有权转让给**W&K Info Defense Research**。

另外美国方面，据**MarketWatch**于**2**月**27**日报道，比特币交易所之一的**Coinbase**上周五告诉其用户，该公司将在未来27天内，把超过**13000**名用户的数据呈交给美国国税局。美国国税局曾于**2016**年**11**月发布了一项命令，要求**Coinbase**交出在**2013**年到**2015**年间购买比特币的用户记录，以便国税局判断谁进行了逃税漏税。**2017**年**11**月，美国法院作出最终判决，美国国税局胜诉。**Coinbase**从最初的抗拒这道命令，到最终不得不同意交出交易数额较高的用户信息，作为妥协。

![](../Images/ec76574f9ee0f518b1bf704da6a2272b.png)

如此这般，比特币新闻又一次风起云涌。一方面是自称**“中本聪”**的人陷入官司，另一方面美国国税局这个中心机构介入了比特币，等于说对比特币进入了监管模式。而曾经以为比特币不受政府审查的拥趸们，也陷入新的沉思了。曾经只是一厢情愿的东西，如今变得很真实很现实了。而很多人内心诉求也因泡沫化，而可能破灭。

比特币在去年**ICO**风波中，我国祭起了管控的法宝，比特币一路狂跌，充分显示了它的泡沫属性。从我国到韩国、印度以及最近美国国税局的胜诉，无不穿刺着比特币这个大泡沫。而比特币是不是躲在技术幌子下的庞氏骗局，很多人或许都明白，不过都心存侥幸，认为自己不会是最后的接盘侠，自认为进入这个局，自己可以掌控。股市的起起伏伏，还有对应的实体企业支撑，而比特币的虚拟性和现实生产没有任何联系，最终如果破灭将一文不值。

比特币只是区块链应用的一个实验性的案例，在此我们期待区块链对现实世界正向的作用越来越明显，让亿万人从中受益。让区块链技术如发电技术一样，让世界变得更加光明，更加灿烂。
