# 日本再为比特币狂跌增加一动因

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwOTc4MTE4Nw==&mid=2247484812&idx=1&sn=4a2a062555d1986469bc79942411514c&chksm=976fed20a018643698c534c8424104f1a9d18046d216bf5065b22da2c85750ed1e80ba46654f&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIwOTc4MTE4Nw==&mid=2247484812&idx=1&sn=4a2a062555d1986469bc79942411514c&chksm=976fed20a018643698c534c8424104f1a9d18046d216bf5065b22da2c85750ed1e80ba46654f&scene=27#wechat_redirect)

日本**Coincheck**价值高达**5.3**亿美金的电子货币被窃，比特币神话越来越变成一个笑话，而比特币的噱头越来越需要一个中心管制的组织介入，比如**Coincheck**此次事件，日本财务大臣麻生太郎在媒体通气会上说：“**我们已经展开了现场检查，以确保保护客户的资产。**”日有官员曾暗示**Coincheck**缺乏适当的安全措施，容易使自己陷入被盗的境地。

![](../Images/28fded760fd3ca13cfda04fbe82fb20b.png)

随着印度上周四宣布，将采取措施防止使用加密货币，比特币在狂升之后，遭遇首次跌破**9000**美元。

**1**月**26**日，黑客攻击下，**Coincheck**被窃取了五亿二仟三佰万加密电子货币NEM，超过了另一起日本虚拟货币交易所**MtGox**在**2014**年被盗窃的四亿八千万美元。**Coincheck**方面亦表示，将动用自家资金偿还所有失去控股权的**26**万客户，每股**NEM**为**88.549**日元。此笔退款，以日元结算，非加密货币。日本是加密货币的主要市场，日本通过法律确定了的加密货币交易由**FSA**进行监管，并在**2017**年生效。

![](../Images/2702198b8dfeb9608e04112a6f021efd.png)

在中国、韩国明确不接受加密货币投机倒把后，印度政府也于上周四表示将严厉打击加密货币的使用。印度财长在新德里说：“**采取一切措施，消除使用加密资产未非法活动提供资金或作为支付系统的一部分。**”  从加密货币诞生之日起，加密货币存在的价值除了炒作，就是和罪恶走的最近了。

![](../Images/efe4a831070aa2ba1df4a6a501bc91a7.png)

比特币在**12**月狂飙接近**2**万美元后，至上周五即**2018**年**2**月**2**日下跌至**8800**美元，截止文章发布是比特币已经跌到**8200**美元左右，而莱特币和以太坊等其他数字货币，也遭受了近期高峰后的巨大损失。可见投资者，也明白加密货币的功用，一旦各国对其非法活动进行管控，加密货币也就丧失了它的撒旦的魔力。

![](../Images/ba1b010142967c42733fa73201a4ad6c.png)

技术本身或无善恶，不过利用技术的投机与非法活动，那么必然将技术埋藏深渊，这个问题只是迟早的事情。在加密货币炒作的热火朝天的同时，各国各地区众多有远见的志士们，正在研究区块链更有益于这个世界，使世界更加公平与明朗方面应用，而技术的优点将会被慢慢的开发更适合人类的利益发展。而比特币为代表的虚拟加密货币，以投机与阴暗并存的魔鬼必将会被消灭。所谓陈杂泛起，比特币这些加密货币，不过是撒旦撒给世人的一种诱惑。

![](../Images/9a2c222d1639206108d26eb27fc50e13.png)

加密货币的安全与否，不仅仅在于加密货币本身的存在，任何事物的存在都有自己的存在的土壤，而如果不是全方位周全的安全，那么比特币的安全就是一个笑话，一次次账面价值上亿虚拟货币被盗，正一次次说明了比特币的安全离不开信息化的安全。只有着眼整个信息产业链的安全，才能为未来无论是比特币还是其他加密货币，以至于区块链技术的其他未知产品和服务带来相对较好的安全。
