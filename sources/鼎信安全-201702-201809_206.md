# 上周关注度较高的产品安全漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwOTc4MTE4Nw==&mid=2247484691&idx=2&sn=06eb7fd493c850a5d69e6c25f6882b52&chksm=976fedbfa01864a9275366e33d208cd741641acf39c776a8cc3f0811d32986d2e982d6405d60&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIwOTc4MTE4Nw==&mid=2247484691&idx=2&sn=06eb7fd493c850a5d69e6c25f6882b52&chksm=976fedbfa01864a9275366e33d208cd741641acf39c776a8cc3f0811d32986d2e982d6405d60&scene=27#wechat_redirect)

**一、境外厂商产品漏洞**

**1、多款Cisco产品Cisco NX-OS System Software命令注入漏洞（CNVD-2017-36141）**

Cisco Nexus 5000 Series Switches是美国思科公司的Cisco Nexus系列数据中心级交换机。本地攻击者可利用该漏洞在以root权限在受影响系统上执行任意命令。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-36141

**2、Apache Hadoop信息泄露漏洞（CNVD-2017-36014）**

Apache Hadoop是美国阿帕奇（Apache）软件基金会的一套开源的分布式系统基础架构。攻击者可借助暴力破解攻击利用该漏洞破解密钥。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-36014

**3、Symantec Endpoint Protection权限提升漏洞**

Symantec Endpoint Protection是一款企业版病毒防护软件。用户可利用该漏洞越权访问资源。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-36232

**4、Google Android Qualcomm组件权限提升漏洞（CNVD-2017-36518）**

安卓（Android）是一种基于Linux的自由及开放源代码的操作系统。攻击者可利用该漏洞实现权限提升。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-36518

**5、EMC RSA Authentication Agentfor Web for Apache Web Server身份验证绕过漏洞**

EMC RSA Authentication Agent for Webfor Apache Web Server是美国易安信公司的一套用于Apache Web服务器的远程访问请求验证软件。远程攻击者可利用该漏洞绕过身份验证。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-36122

**二、境内厂商产品漏洞**

**1、优诺科技知商管理系统存在SQL注入漏洞**

沈阳优诺科技有限公司专注于中小企业知识产权体系搭建维护，品牌营销策划，品牌推广营销等领域。攻击者可利用该漏洞获取数据库敏感信息。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-34146

**2、禅道9.1.2版本存在SQL注入漏洞**

禅道是一款开源项目管理软件。该漏洞是由于系统未能对用户提交的数据进行有效地过滤。攻击者可利用该漏洞获取数据库敏感信息。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-34149

**3、嵩嵩报名系统存在万能密码登录漏洞**

嵩嵩报名系统是一个以asp+access进行开发的报名系统源码。攻击者可利用该漏洞绕过后台验证，从而成功登录。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-34145

**4、APPCMS 2.0.101版本存在恶意后门**

APPCMS是一套专业的APP内容管理系统。攻击者可通过此后门获取网站管理员登录信息。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-34303

**5、DM企业建站系统v201710存在SQL注入漏洞**

DM建站系统是由php+mysql开发的一套专门用于中小企业网站建设的开源cms。 攻击者可利用该漏洞获取数据库敏感信息。

参考链接：http://www.cnvd.org.cn/flaw/show/CNVD-2017-34212
