RSA爆两漏洞影响范围巨大

原文：http://mp.weixin.qq.com/s?__biz=MzIwOTc4MTE4Nw==&mid=2247484669&idx=1&sn=0c6ce2f37d1a79d5e3a66699c7f1120e&chksm=976fec51a0186547495f3d7260ee7a74a736a5b88993f248fc587d06c366b34fa2ce051f316b&scene=27#wechat_redirect

近日，RSA Authentication SDK（软件开发工具包）中发现了两个关键漏洞，务必并尽快进行修补。

 

CVE-2017-14377：身份验证绕过，影响了Apache Web服务器的RSA身份验证代理。这个漏洞可能被远程的未经验证的用户利用，通过发送一个触发验证错误的精心设计的数据包，这样就可以访问目标上的资源。

 

当用于Apache Web Server的RSA身份验证代理程序配置为使用TCP协议与RSA Authentication Manager服务器进行通信时，才会出现此漏洞。

 

作为默认配置的UDP不容易受到攻击。有关配置详细信息，请参阅RSA AuthenticationAgent 8.x for Web for Apache Web Server安装和配置指南。

 

可以通过配置认证代理使用UDP来缓解这个问题，RSA已经在以下地址发布了补丁：

 

https://community.rsa.com/community/products/securid/authentication-agent-web-apache

 

CVE-2017-14378：影响C的RSA身份验证代理SDK，这意味着使用SDK开发的任何其他系统都将继承该漏洞。该漏洞不会影响SDK的Java版本。

 

RSA身份验证代理SDK版本8.5和8.7具有影响TCP异步模式实现的错误处理漏洞，攻击者可以利用这些漏洞绕过某些实现中的身份验证。

 

针对C的RSA身份验证代理API / SDK8.5 / 8.6具有错误处理漏洞，可能导致在某些实现中绕过身份验证。当在TCP异步模式下使用API / SDK并且API / SDK的返回代码没有被应用程序正确处理时，将会发生此问题。

 

SDK的C版本补丁可以在以下网址找到：

 

https://community.rsa.com/docs/DOC-40601#agents
