# 哪个牛人让推特总统特朗普消失于推特？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwOTc4MTE4Nw==&mid=2247484561&idx=1&sn=d853d3824230b48c49fa99576be9bd79&chksm=976fec3da018652bc3cc52498f08450dbb7bcd69ed59ecd811319f8545d398bdbd455820c1c4&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIwOTc4MTE4Nw==&mid=2247484561&idx=1&sn=d853d3824230b48c49fa99576be9bd79&chksm=976fec3da018652bc3cc52498f08450dbb7bcd69ed59ecd811319f8545d398bdbd455820c1c4&scene=27#wechat_redirect)

米国总统这几天，可以说占据我国的各大媒体的头条，我们在他的热度下，来谈谈前几天米国人的现任总统特朗普在推特上消失了，从这起乌龙事件而去延伸关于网络信息安全的一个话题。特朗普一直坚持利用自己的推特，面向公众，并且被批评使用的安卓手机是不安全的。在过去，特朗普通过推特，称赞普京“非常聪明”，向女记者发送侮辱性言辞等等。

  

![](../Images/fbc233c891467c66e90ecec9aef63f39.png)

  

首先这不是个假新闻，推特总统特朗普，在推特消失了11分钟，全世界人都无法**@****realDonaldTrump**，@后的信息是“**@realDonaldTrump**不存在”。上周四，推特活活的真把在推特上活力四射的米国大总统特朗普“**拉黑**”了！

  

![](../Images/3c9d8685950cb339b9c32f53615c9d43.png)

  

当互联网上的人们，尽力搜索总统的**@realDonaldTrump**个人推特账号时，屏幕上显示的消息竟然是“不存在”！之后传出的消息是，特朗普短暂消失的原因是，推特一名员工最后一天工作造成的。理解这句话，应该是一个员工要离职了，工作的最后一天把米国总统弄丢了。而互联网媒体还张贴了关于推特工作人员的恶作剧，甚至嘲笑幕后罪魁可能是希拉里或奥巴马。

  

![](../Images/82e0503c6ded7c153e2044972f5c65d0.png)

  

前一段时间，还以为上演黑衣人，特朗普去了外星球呢？最后推特总部在声明自己的对此次事件的困惑后，发布声明称，此事并非偶然事件，通过调查了解到，是由于推特员工工作最后一天造成了这个恶作剧。其正在进行全面的内部审查。不过，这个职员身份并未透露，可能是个临时工吧。

  

![](../Images/0a1b76e4583cbd59176e4f1768688aea.png)

  

而安全专家对此，产生了警觉。建议推特应该防止此类事情再次发生。可以通过彻底审查雇员，或者从法律层面探索，想办法惩治流氓离职员工，将其作为一种震慑。而专家甚至建议，应该想办法保护特朗普的推特账号，组织雇员对特朗普账号的操作，在维护账号时采取两名工作人员，共同完成达到互相监视的目的。

  

![](../Images/b802df259e381804406a610901fcf9ea.png)

  

在爱德华斯诺登成为世界英雄之后，美国极其严密的网络监视事件，大白于天下。与此之后，美国安全局所做的工作，更加严密。为此花费与负担，也可谓巨大。而一个不愿具名的推特前雇员透露，一个即将离职的员工，特权是被暂停的，暂停特权的雇员，是不太可能劫持一个账户发送信息的。也有媒体说，导致特朗普总统消失的，罪魁祸首可能是服务承包商，而不是雇员。

  

  

![](../Images/94ae12cc7f52c99b03d7fd3101dde89c.png)

  

从中我们也可以看到，最为信息化高度发达的美国，各项政策法规非常完善的国度，其信息安全依然严重。甚至可以令其总统，在网络上消失11分钟，着实对全世界的信息安全来说是一个警示。而在这个恶作剧之后，我们其实还未曾得到事件的来龙去脉，离真相还很远。然而，这也为我们的信息安全工作添加了难度，也添加了乐趣。信息安全其实一直在路上，只有不断增强的安全，不断变化的安全，没有一劳永逸的安全。
