# 一起了解一下几款优秀的备份软件

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwOTc4MTE4Nw==&mid=2247484508&idx=1&sn=50fdc84ffe3df20fb4858334d2b751de&chksm=976fecf0a01865e63bc6a54779ed41f0c76124ed923c43de7e9f3de89a176a2ed82d1ce85ab5&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIwOTc4MTE4Nw==&mid=2247484508&idx=1&sn=50fdc84ffe3df20fb4858334d2b751de&chksm=976fecf0a01865e63bc6a54779ed41f0c76124ed923c43de7e9f3de89a176a2ed82d1ce85ab5&scene=27#wechat_redirect)

数据业务的联系性，一直是广大**IT**从业者与企业头疼的问题，而一个好的备份系统，可以有效的解决这些烦恼。很多企业最终会学到一个很痛的教训后，耳边回响起辛晓琪的《**领悟**》中高潮的部分**：**“**多么痛的领悟！**”，而在领悟后，你可能得到最常见的答案就是**：备份、备份、备份**！定期备份对于任何业务都是至关重要的，他也有助于防止勒索软件的攻击以及服务器故障等。  

  

管理和协调备份也可能是一件非常头疼的事情，那么或许通过购买专业的备份软件，可以使你的工作更加轻松，什么是最好的备份软件呢？其实各有千秋，这里介绍几款获得比较多认可的，供大家参考。同时声明，我们做的只是广而告之！

  

* * *

**Acronis Backup 12.5**  

![](../Images/a6d0ea2f47905dea58abcbff1061f203.png)

  

这款软件也算与我有一点缘分的，刚刚回到这个城市，也差一点去学这个产品，做这个产品的技术。数据保护方面**Acronis**是一款顶尖品牌的产品，具有良好的基础，简单快速部署、支持大批量设备、增强的虚拟化支持等优点。

**Acronis**还添加了防篡改防御功能，自动停止恶意流氓软件的加密。这点是针对最近风行的加密恶意软件的，其价值意义不言而喻。同时此款软件具有适合任何组织，是大型企业备份的最佳备选项之一，具有提供卓越的价值。

  

* * *

**IDrive Business**  

![](../Images/81309829b9ef8eb35ba39ef0774d2073.png)

  

每一款备份软件都有它各自的优点，那么**Idrive Business**则是一个非常便宜的解决方案，其优越的性价比或许是最吸引人的地方。西方媒体报道，第一年41英镑起，对于初始创业公司或许算是比较有吸引力的。而此款软件对**MacOS、Windows、Linux**系统可以很好的支持。同时也支持对**Exchange、SharePoint、SQL、Oracle**等服务器备份，移动设备备份。支持即时备份、基于镜像备份、混合备份、文件同步等。这些功能结合这个价格，对于企业来说是一个不错的性价比了。

  

* * *

## **Veritas Backup Exec 16**

![](../Images/773a3b1ad26488824511da76dced582a.png)

**Veritas Backup Exec 16**对于管理大型组织来说，是比较有优势的。其直观易用的控制台以及一定的智能化，意味着备份和恢复策略可以变得省时省事易于追踪。平台支持起点则比较高，完全支持**Windows Server 2016**的核心操作，以及**Amazon ****S3**和**Microsoft ****Azure**，当然也可以轻松备份**Exchange**和**SQLserver**。此种备份方案，功能多样，适合面向更大型的企业选择。

  

* * *

## **Arcserve Backup r17**

![](../Images/3ec8f9ca25b9441ca04561a4509687fd.png)

直观的界面，用户友好的备份方案或许**Arcserve**的**Backup ****r17**套件也是不错的选择。可以支持**Windows10**和**Exchange ****2016**，以及很好的兼容LTO-7磁带机和更好的**vSphere ****6**集成，该软件功能是非常强大的。而且该软件还提供重复文件检索删除的增值服务，数据压缩比达**8:1。**可谓价格合理、使用方面，也不失为一个考虑方案。

  

* * *

## Hyperoo 2.4

![](../Images/541102bc8f320a95b2849b87e77a27bd.png)

  

**Hyperoo**的备份产品有一定的局限性，主要用于**Hyper-V**环境，但也可以用于其他备份操作。**Hyperoo2.4**支持使用任何存储，包括本地磁盘、NAS驱动器和**IP ****SAN**以及云存储等。其具有另一个亮点则是，测试过程中两分钟内恢复了一个**8GB**的虚拟磁盘。所谓各有所长，各有千秋，作为备份一族的产品，**Hyperoo**也可以作为你的备份解决方案。
