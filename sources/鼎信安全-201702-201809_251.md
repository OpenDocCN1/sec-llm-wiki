# 黑客和你家中的一切可被控制的智能设备

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwOTc4MTE4Nw==&mid=2247484487&idx=1&sn=2bc27824cb5ccea2937e162551d39ac3&chksm=976feceba01865fd372b9483d50d00a3fb8e281791d3709b5593d3d3271771bbb5c896286085&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIwOTc4MTE4Nw==&mid=2247484487&idx=1&sn=2bc27824cb5ccea2937e162551d39ac3&chksm=976feceba01865fd372b9483d50d00a3fb8e281791d3709b5593d3d3271771bbb5c896286085&scene=27#wechat_redirect)

LG电子智能家居系列设备的一个漏洞，允许远程访问和控制其整个生态系统中的任何设备。这其中包括冰箱、烤箱、洗碗机、洗衣机、烘干机、空调、吸尘器等。  

  

![](../Images/76073b6cabf168bd99256eab6a3304f4.png)

  

Check Point 发现了这一个缺陷漏洞，并将其取名为“HomeHack”，整个缺陷暴露了数以百万计的LG SmartThinQ设备的用户，面临未授权的远程控制的风险。LG SmartThinkQ移动应用和云应用程序存在允许黑客远程登录的问题，黑客可以通过接管合法LG账户，并控制真空吸尘器及其集成摄像机。一旦控制了特定用户的LG账户，与该账户相关联的任何LG设备或其他设备均可能被攻击控制。

  

  

![](../Images/135387af11484bab7ccf04618de03333.png)

  

显而易见的是，黑客可以通过摄像机，窥视用户家里的一举一动。该摄像机实时视频会发送到LG SmartThinQ应用程序，本身作为HomeGuard安全功能的一部分，而如今变成了家庭私生活曝光台。攻击者同样可以控制，家中其他智能设备的开关，通过远程进行开与关。以前调侃过几句话，黑客可以控制你的冰箱的温度，而如今LG的缺陷漏洞已经为我们诠释，前段时间的语言已经是现实。

  

![](../Images/dda601f0d8465a46656ab641ac22393b.png)

  

随着智能家居相关智能设备的越来越丰富，而智能设备的网络安全问题，才刚刚不断被发掘。黑客将把重点定位到个人设备上，这些智能设备未网络犯罪分子，提供了更多的软件缺陷的利用机会。从而造成家庭用户对设备的访问中断，敏感数据外泄等。用户同时也需要意识到设备的网络安全及个人隐私风险。而设备厂商同时必须关注智能设备面临的攻击风险，不断强化软硬件的安全性。

  

![](../Images/8888754063ecf6d58fd09cc338335a61.png)

  

如今，LG方面是已经修复了被发掘出来的漏洞，用户需用通过更新其应用程序，来提高安全性，以便在享受智能设备的同时，兼顾安全性。同时，这件事情也给我们留下来比较广泛的思考，在智能设备越来越便捷的同时，我们是否准备好迎接它可能带来的负面问题。当负面不可避免时，我们是否有心理准备或应急措施呢？

  

![](../Images/536aa0adb905f8e1e626bb69b047cf60.png)

  

我想，物联网的安全一如前几次说过的，才刚刚开始。而我们面对的问题，将拥有传统的也必将有新兴的。在构筑传统网络安全的同时，让我们随时迎接新兴问题的考验。我们将与大家一起，继续关注网络信息相关安全的发展与进步，让我们携手并进，为当下及未来网络信息安全事业，奉献一份力量。
