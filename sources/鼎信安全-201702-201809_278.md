# 美国网络安全意识月的各周主题安排

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwOTc4MTE4Nw==&mid=2247484356&idx=1&sn=c864ae5696a0921b91d0adb4420c353b&chksm=976feb68a018627e4300ad7dab736fc1902507b6bf28acd1aacf117b41787597bfda1600691a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIwOTc4MTE4Nw==&mid=2247484356&idx=1&sn=c864ae5696a0921b91d0adb4420c353b&chksm=976feb68a018627e4300ad7dab736fc1902507b6bf28acd1aacf117b41787597bfda1600691a&scene=27#wechat_redirect)

我们来通过了解美国网络安全意识月的各个周的主题，看看美国社会与企业如何在网络安全宣传引导中制定战略的。  

![](../Images/aa763d206724ea646915302524ebe5dd.png)

**第一周（10月2日-6日）：简单的在线安全操作步骤。**本周是关于网络安全基础知识的宣传：个人与企业自己在上网过程中，可以做些什么，如何应对网络安全事件。如：学习如何使用密码，抵御网络邮件钓鱼等，以有效的降低网络风险。

![](../Images/753bfa7fedd2fb258f642a110b0c2a54.png)

**第二周（10月9日-13日）：每一个人要注意工作场所的网络安全。**第二周针对公司企业所有权下的网络安全最佳做法。包括有效的员工培训，加上美国国家标准技术研究所网络安全框架等资源和标准，以帮助降低恶意攻击的频次和严重程度。

![](../Images/d824d003a3c46386a12f0e00a881a7f9.png)

**第三周（10月16日-20日）：今天的互联网预测。**智能家居，企业和物联网设备的发展即代表着机遇同时也存在着风险。本周主要展示个人敏感信息在智能设备革命中的关键作用，以及对数据的存储、传输和处理的安全要求。

![](../Images/76073b6cabf168bd99256eab6a3304f4.png)

**第四周（10月23日-27日）：互联网要你：考虑网络安全的职业前景。**如福布斯统计，到2019年预计美国将有200万专业网络安全人员的短缺。强调学校教育及青年学生可以在网络安全领域做好准备，引导市场和职业向这个方向转移，配合网络安全这个不断膨胀的市场。

![](../Images/4243dcaa348e6c22fedd82f2f41a02b0.png)

**第五周（10月30日-31日）保护关键信息基础设施免受威胁。**讲述关键信息基础设施的重要性，以及面临的安全问题。如通过利用过时的SCADA和ICS系统、通过利用现有的公共事业和基础设施进行攻击行为，了解网络安全与国家关键信息基础设施之间的重要联系。

![](../Images/9228c33f7cd5a8eb45ff791d1f3764fe.png)

从中我们看到，创造长期的网络安全文化，是提供网络安全意识的第一步，为进一步深入长期的网络安全工作打好基础。在国际信息化时代，国际间网络安全合作也是大势所趋，而从中我们也可以借鉴到很多信息化发达地区的经验，为我国的互联网事业提供参考，在夯实我国网络安全方面，可以使我们有更多借鉴和吸收，取长补短完善我国网络安全。

![](../Images/59b547ac56a3fd239b79e503984bf347.png)

  

个人、企业要根据自身情况，提高公共网络安全意识，提升应对能力。通过新的培训和教育，稳步推动国家网络安全事业。于此，我们将与您一起在推动网络安全建设的路上，同心同德，一起前进，共同喜迎十九大的召开。
