# 十九大新闻中心网站和微信公众号今日开通

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwOTc4MTE4Nw==&mid=2247484326&idx=1&sn=94c564b6465ebc739cba2c55e2ca79e0&chksm=976feb0aa018621ce40abda67b9e423efe7329f5395ab63f8cc11d9f6fa3d9687df11b8c6582&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIwOTc4MTE4Nw==&mid=2247484326&idx=1&sn=94c564b6465ebc739cba2c55e2ca79e0&chksm=976feb0aa018621ce40abda67b9e423efe7329f5395ab63f8cc11d9f6fa3d9687df11b8c6582&scene=27#wechat_redirect)

北京10月9日电 记者从有关方面获悉，中国共产党第十九次全国代表大会新闻中心网站（http://19th.cpcnews.cn）和微信公众号（名称：十九大新闻中心，微信号：cpcnews19th）将于10月11日开通。

![](../Images/ebcb6743ca7e406cb782b2a988f26567.png)

 据悉，十九大新闻中心网站和微信公众号将及时发布大会的各项议程、动态、公告、通知等，用中、英文为中外记者和国内外读者提供有关中国共产党第十九次全国代表大会的信息，提供历次党代会的背景资料、党的理论知识等。中外记者还可以通过微信公众号咨询、了解新闻中心各项服务内容和措施。
