# 黑客大显神威奴役Windows服务器为其挖掘门罗币

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwOTc4MTE4Nw==&mid=2247484241&idx=1&sn=d43bbc0d37ef11c876d23aeb2e8f3fe0&chksm=976febfda01862ebc747fabcd208aec0ad06cce3a4d0a7ee8a33b600397829d89ab9c707c0d5&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIwOTc4MTE4Nw==&mid=2247484241&idx=1&sn=d43bbc0d37ef11c876d23aeb2e8f3fe0&chksm=976febfda01862ebc747fabcd208aec0ad06cce3a4d0a7ee8a33b600397829d89ab9c707c0d5&scene=27#wechat_redirect)

微软的实力，在互联网界应该是没人否认的。而能够把微软产品作为一个奴隶般驱使的黑客，也真心又一次赚足了眼球。  

加密数字货币采矿机的投入，是非常昂贵的一笔支出。上篇文章中，我也提到了关于高价矿机以及电费支出的问题。而黑客则可以利用其技术手段，去收集富裕的算力，来挖掘加密数字货币。黑客利用恶意软件，劫持并窃取计算机资源，赚取价值数十万美元的数字加密货币，已经开始不再是新闻了。

![](../Images/e33201e1079b54659fd9dd5c0f066124.png)

不过毕竟这个事件，再次挑战了传统IT巨头的安全威信，还是有点新闻价值的吧。ESET的安全人员发现了一款恶意软件，感染了数百个Windows Web服务器，并使用恶意加密矿工，短短3个月内挖矿获得价值63000美元的门罗币（Monero）。据ESET的一份报告，黑客仅仅对合法的Menero采矿软件进行了修改，并利用IIS 6.0中的一个已知漏洞，在尚未打补丁的Windows服务器上秘密安装矿工软件。

![](../Images/5887f8b3af778524c5841e0f4010143c.png)

而ESET报告了这起事件，却未能识别攻击者。同时指出攻击者一直在利用未修补的Windows Web服务器，自今年5月份至今，开采类似比特币的门罗币。而攻击者利用的漏洞（**CVE-2017-7269**）于**2017**年**3**月份被发现，主要影响**Windows Server 2003  IIS**** 6.0**版Web服务器。而黑客针对未打补丁的**2003**的机器，使其成为挖矿的奴隶，把一个个肉鸡直接变现成**Menero**，市场价值已超**63000**美元。

![](../Images/f09401321e63228a27c136aaec24b50e.png)

据报道，**Monero**市场总价值约**14**亿美元，实际上远远落后于比特币的市场估值，但是网络黑客还是热衷于**Monero**的挖掘。而**Menero**提供的是不可追溯的交易，也是当今世界上匿名加密货币的一分子。而这也不是第一起关于**Menero**恶意软件窃取计算机资源的案例，自五月中旬以来，研究人员就发现了一个称为“**Adylkuzz**”的恶意软件，该软件利用的有**NSA**创建的**EternalBlue**的漏洞利用，并感染未修补漏洞的**Windows**主机。

![](../Images/d7c7b1a1e8530eda78a2655c6ac3d6b7.png)

加密数字货币的技术支撑来自区块链技术，而区块链技术是被认为网络信息发展的下一个制高点，而我国以及世界各国，在此方面都不断投入研究。以期利用区块链技术，惠及世界大众。而在技术无善恶的前提下，不同的组织和个人，会根据自身利益去拓展技术的进步。而黑客利用肉鸡作为挖矿奴隶这类事件，一方面值得我们惊醒的同时。也应该明白在技术利用过程中，是有善恶之分的。在一个现代社会的环境下。一个技术能不能真正带给所有人以利益的公正性，而不是极少数人对普通人洗劫的工具，这才是我们真正需要正视的。

![](../Images/bf3d44bea436d36a97fe297734b392f6.png)

技术，终归是技术。然而技术能否改变一切呢？我想这个值得每一个人去思考，所谓一千个观众心中有一千个哈姆雷特，千人千面吧。在此，我希望每一个人都可以从技术红利中获得公平公正的分配，而不是作为黑暗挖掘与非法交易的保护伞。

**保卫、保护、保障网络安全，一个不能也不敢懈怠的信念！**
