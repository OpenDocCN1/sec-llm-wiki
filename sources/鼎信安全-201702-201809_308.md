# 当你定位你的汽车却变成跟踪你的利器

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwOTc4MTE4Nw==&mid=2247484195&idx=1&sn=222ee653df96ccf63f2d8a80f85e89eb&chksm=976feb8fa0186299a494dc47d5e9098770f3b293f0a4812536086e14d0541654e74618df76ea&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIwOTc4MTE4Nw==&mid=2247484195&idx=1&sn=222ee653df96ccf63f2d8a80f85e89eb&chksm=976feb8fa0186299a494dc47d5e9098770f3b293f0a4812536086e14d0541654e74618df76ea&scene=27#wechat_redirect)

今天，咱们继续谈网络信息安全。对于网络信息安全，是一个严肃的话题，可能在谈论时有点枯燥乏味，不过我们尽量谈论时用严肃的态度来传递客观的信息。  

![](../Images/4e4c2b3da46a7b469100210a9ac84c88.png)

据国外媒体最近报道，一个令人不安的消息是，原属于车辆跟踪设备公司**SVR ****Tracking**的50多万条登录凭证存在在线泄露可能。极有可能会暴露使用其公司服务的司机及企业的个人数据和车辆的详细信息。而于此前，在Amazon S3服务器上暴露了它秘钥，而本次数据泄漏又是一个云服务器上敏感数据的错误配置的例子。

![](../Images/e04d651602de5c69e50d356e2670f95b.png)

**Kromtech**安全中心，首先发现了**Amazon ****Web ****Server**（**AWS**） **S3**面向公众的云存储错误配置的问题。其中包括属于**SVR**的缓存一度可以被公开访问。

对于**SVR**跟踪服务可以提供允许客户来跟踪其爱车，客户可以监控与寻找其车辆，以防车辆被盗。而如果一旦信息用户信息泄露，本是提供便利之用的服务，立马变成侵犯其个人隐私及车辆被盗风险性加大的不利情况。而此次泄露的缓存数据可能包含**54****万**个**SVR**账户的详细信息，包括**Email**、密码、用户个人信息、**VIN**、**GPS**设备的**IMEI**码等。其次泄露还包括，**339**个日志，包括车辆状态及维修记录的照片与数据，以及**427**个跟踪经销商的档案信息等。

![](../Images/753bfa7fedd2fb258f642a110b0c2a54.png)

**Kromtech**公司警告**AWS ****S3**云存储错误配置，可能在今后需要加强保护。但目前情况下，还不清楚是否有黑客拿到了其可以公开访问的数据。

在网络信息安全的领域里，再好的安全防护都不是多余的。我们能够做到的是，基于现有的基础设施做最好基础防护，以及网络信息安全防范意识的宣传普及和加强。普及网络信息安全意识与知识，是面向且有利于广大群众的一项长期工作。我们将利用我们在网络信息安全方面的专长与经验，尽力让更多人的网络信息安全合法权益得到重视与保护。

![](../Images/4bafdb8c5bbcfc4424efc847dcf2da8f.png)

随着《**网络安全法**》的出台，在保护个人信息方面已经有明确规定。而最近全国人大委员会及网信办等单位主导的关于《**网络安全法**》的“**一法一决定**”的督导普查工作也在按部就班的进行中。同期第四届以“**网络安全为人民，网络安全靠人民**”为主题的**“国家网络安全周”**也在进行中，普及网络安全发展及网络安全知识，是为了每一个网络公民的合法权益得到保护。从法律法规惩治违法犯罪行为到宣传正向引导多种途径结合，一方面阻恶，一方面扬善。共同推进网络信息安全的发展与普及工作。也为我国“**十三五规划**”能够坚实有效顺利实施保驾护航。
