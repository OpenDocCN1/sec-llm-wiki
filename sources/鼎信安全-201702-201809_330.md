# 医疗卫生方面恐怖：黑客可以远程控制自动输液泵

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwOTc4MTE4Nw==&mid=2247484094&idx=1&sn=26e28092f37befda038f4e19ac9620df&chksm=976fea12a0186304369fe790bbc53e870e091a242e80bc55255a9b2686687bcb6116b31e2267&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIwOTc4MTE4Nw==&mid=2247484094&idx=1&sn=26e28092f37befda038f4e19ac9620df&chksm=976fea12a0186304369fe790bbc53e870e091a242e80bc55255a9b2686687bcb6116b31e2267&scene=27#wechat_redirect)

信息化，为各行各业的接入带来了利好的影响同时，也存在着不同程度的风险与危机。当我们过度的宣传他的便利性时，公众往往被带到一面倒的思维模式中去，而忘记有可能会遭到不利的影响。在智能化慢慢走入我们的生活，令我们的生活变得更加便捷容易的同时，我们不得不考虑它有可能存在的风险。  

![](../Images/a7f405d83ad0cde0a13b065268087824.png)

相信有部分朋友看过杰拉德·巴特勒主演的《守法公民》这部电影，本来平和的注射死刑，变成了残酷的折磨致死，其原因只是主角远程入侵服务器，更改几个数字，调换了药品，遂使得原来预定的注射死刑，变成了极度的酷刑，致使犯人血脉暴涨折磨致死。这只是电影的一个小片段，给予我们的画面感应该也是蛮真实的，在恐怖的画面效果中，主角进行了复仇的第一步。

![](../Images/f44d8b9fcecc8dcc5699eda590519121.png)

现实世界事实证明，在急性护理环境中使用的注射器输液泵可以被黑客远程访问和操纵，从而影响预设程序的操作。周四时ICS-CERT发出了警告。特种医疗器械制造商史密斯医疗公司制造的Medfusion 4000无线注射器输液泵中存在八个安全漏洞，最新暴露的漏洞（CVE-2017-12725）的CVSS威胁得分高达9.8，在设备默认配置未更改时，可以自动建立无线连接。

高危风险缺陷漏洞包括：

*   缓冲区溢出错误（CVE-2017-12718）可能会在某些情况下被目标设备用于远程执行代码。
    
*   如果泵配置为允许FTP连接，则缺少认证（CVE-2017-12720）。
    
*   存在用于泵的FTP服务器的硬编码凭证（CVE-2017-12724）。
    
*   缺乏适当的主机证书验证（CVE-2017-12721），使泵容易受到中间人（MitM）攻击。
    

其余为中等风险漏洞，报道称Smiths Medical计划在2018年1月发布新版本1.6.1中对以上问题加以解决。在新版本未发布前，建议医疗机构可以采取一些防御措施，包括为设备分配静态IP，监测网络恶意活动，隔离安装输液泵，设置高强度密码，定期备份等。  

上月FDA提醒，有150万的心脏起搏器面临黑客威胁的恐惧。由健康技术公司Abbott生产的“Accent”、“Anthem”、“Accent MRI”、“Accent ST”、“Assure”和“Allure”六款起搏器，存在着安全隐患，需要找回。据报道召回起搏器将软件更新还引入了数据加密，操作系统修复，禁用网络连接功能的能力，尝试与起搏器通信的任何外部设备都需要授权。

![](../Images/1b535327a2d1e9130817c3150416bc64.png)

从报道来看，还未发现黑客攻击起搏器造成意外事件发生，但是威胁可能性已经足以使植入心脏起搏器的心脏病患者受到伤害，甚至随时面临付出生命的巨大风险。

通过好莱坞电影，以及现实世界的安全事件报道，足以引起我们的重视。很多潜在的危险，如患者的心脏起搏器是不允许我们有一丝马虎的，一旦发生了危险，没有重来一次的机会。同时作为自动输液泵，一般都是用在特殊的急救过程中，也是事关生命的设备。信息安全带来的威胁，是我们社会上每一个人都可能面临的问题。

卫生医疗作为关键信息基础设施的一部分，对于社会民生、国家安全以至于全民都是至关重要的，在此方面的信息安全也是国家层面给予重视。“十三五规划”中提到把提升人的发展能力放在突出重要位置，全面提高教育、医疗卫生水平，着力增强人民科学文化和健康素质，加快建设人力资本强国。
