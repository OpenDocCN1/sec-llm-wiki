# 黑客可利用Apache Struts2中关键漏洞控制Web服务器

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwOTc4MTE4Nw==&mid=2247484060&idx=1&sn=a4b4198b2297021e95f12e5e95a46906&chksm=976fea30a0186326ae4565de80df2ca35f38319148333df6e956189e188d3dd639e8723b8ac8&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIwOTc4MTE4Nw==&mid=2247484060&idx=1&sn=a4b4198b2297021e95f12e5e95a46906&chksm=976fea30a0186326ae4565de80df2ca35f38319148333df6e956189e188d3dd639e8723b8ac8&scene=27#wechat_redirect)

据最新消息称，安全研究人员在流行的**Apache Struts Web**框架中，发现了关键的远程执行代码漏洞。远程攻击者可以利用该漏洞，在服务器上运行恶意代码。

该漏洞为**CVE-2017-9805**属于一种编程错误，存在着Struts处理不可信源的数据。具体来说，**Struts REST**插件无法处理**XML**有效负载，同时对他们进行反序列化。

![](../Images/a30377fa33f827d636bc343ca67865c0.png)

自2008年以来，所有**Apache Struts 2.5**到**2.5.12**版本，都在受影响之列，所有使用这些框架的**REST**插件的Web应用程序皆容易受到远程攻击。据**LGTM**研究员介绍，这些漏洞弱点很容易被利用，仅需要浏览器支持既可以实现远程攻击。通过远程入侵Apache服务器后，最终可能危及到同一网络中的其他服务器的安全。据报道，此漏洞缺陷是利用JAVA中的不安全的反序列化，类似的在2015年出现过**Chris Frohoffhe 、Gabriel Lawrence** 属于**Apache Commons collections**中的一个漏洞。

**此漏洞于Struts 2.5.13得到修复，因此鼎信建议：**

1，使用**Apache 2.5**到**2.5.12**的用户，尽快升级**Apache Struts2.5.13**或**Struts 2.3.34**。

2， 如果系统没有使用Struts REST插件，那么可以直接删除Struts REST插件，或者在配置文件中加入如下代码，限制服务端文件的扩展名  

| **    `<constant name=``"struts.action.extension"` `value=``"xhtml,,json"` `/>`** |
| --- |
