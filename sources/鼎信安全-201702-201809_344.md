# 维基解密被黑恢复后立即干了一件漂亮的泄密事件

| 2017年8月31日，维基解密发布了**CIA**的**Angelfire**项目的文件。**Angelfire**是由五个植入组件组成，其中包括**Solartime、wolfcreek、Keystone**（以前的**MagicWand**）、**BadMFS**以及**Windows Transitory File**系统。和以前**“****Vault 7” **系列中发布的CIA黑客工具（如**Grasshopper**和**AfterMidnight**）一样，它是一个持久性框架，可以植入加载到**Windows **操作系统（包括**Win7**或**XP**）等目标计算机上进行运行。![](../Images/4a65a8a819176fdb3866fcd73fb5fa56.png) |
| --- |
| **Solartime**用以修改引导扇区，以便在**Windows**加载引导驱动程序时，一起执行**Wolfcreek(内核代码）。**可以加载运行**Angelfire**植入程序。根据文件透露，加载植入程序会在被感染机器上造成内存泄露。**Wolfcreek**是一个自动加载驱动程序（**Solartime**执行的内核代码），用于加载其他驱动程序和用户模式的应用程序。![](../Images/2d3cebf21a7a8e5353297bd67cb6e1c3.png)  
**Keystone**是**Wolfcreek**植入程序的一部分，加载恶意应用程序。加载恶意程序直接到内存中，所以不改动系统文件，很少能有检测软件检测到它已经运行在电脑中。一般它会伪装成“**C:\\Windows\\system32\\svchost.exe**”,如果操作系统安装在其他分区，应该可以在任务管理器中进程中看到。

![](../Images/bee28991e95f26a31fa357108921ba5b.png) |
| **BadMFS**是实现在活动分区中创建隐藏的文件系统。用以存储**Wolfcreek**及所有驱动及植入程序。所有文件将被加密，以避免防恶意代码软件对字符串或**PE**头文件进行扫描。隐藏文件系统的引用存储名以“**zf**”为特征，可以通过这些信息检测到某个版本的**BadMFS**。

![](../Images/e25d370de3a1b7fe284e0b5953a99cd0.png)  
**Windows Transitory File**系统是安装**Angelfire**的新方法。它允许CIA间谍特工为特定的工作创建临时文件。包括安装或向**Angelfire**添加文件、删除文件等，而不是在磁盘上放置独立的组件。 |
