# 对云安全账户的攻击数量增加了高达300%

| 根据微软的安全分析报告，对云端账户的攻击数量持续增加，数量增长竟然高达300%。报告称，企业或个人的微软账户成为攻击者的诱人的目标，基于云账户的攻击频次与复杂程度正在加速。微软声明表示，密码可靠性差、密码管理差，极易成为攻击的原因。微软同时，也在采取区分恶意IP地址的安全策略，划分“可信任IP地址”或“可信任设备”等方式，来降低风险。![](../Images/94aa5ce1f23d447117a67786d61af3fb.png) |

| 根据Alert Logic的《网络安全趋势2017 spotlight Report》报告，对欧洲的公司调查结果是，安全人员两个最大的担心是对隐私数据和违反法规的威胁。这些公司组织，在保护云计算基础设施方面，遇到很大问题。他们内部很多缺少专业的安全方面的知识，应对日益复杂的数据保护的威胁，应对系统和应用程序的不断增长的需求。还有降低安全成本、持续服务、及时响应等。![](../Images/cc1c3ca28256752089a8732eb5f722e7.png) |
| 随着云计算的采用率的不断攀升，安全专业人士其实最关心的还是如何保护好云端的数据，国外有研讨会也申明：如果你无法控制云应用，你的数据与丢失没有分别。云安全，大数据是摆在我们面前的一个新课题，也是考验我们的一个现实问题。伴随这个我国信息化的发展，思维与理念要与时俱进，具备国际视野，协同工作保护我们的网络安全。![](../Images/3eee59618866d634eeb59b957da8e01f.png) |
