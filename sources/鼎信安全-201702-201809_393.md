# ESET Antivirus中的严重故障使Mac用户受到远程攻击

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwOTc4MTE4Nw==&mid=2247483684&idx=1&sn=9bce25341fd444823d47f62ce8d122f1&chksm=976fe988a018609e8f5fbda666a77c3decc85ad6c347581b46cc91cac93fdacbea676a0967f5&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIwOTc4MTE4Nw==&mid=2247483684&idx=1&sn=9bce25341fd444823d47f62ce8d122f1&chksm=976fe988a018609e8f5fbda666a77c3decc85ad6c347581b46cc91cac93fdacbea676a0967f5&scene=27#wechat_redirect)

对于黑客来说，没有什么比在广泛使用的软件中利用漏洞更为刺激，而不必太费力的事情了？  
  

![](../Images/c75c53f143e12b8609067efcbce50a52.png)

在ESET的防病毒软件中发现了一个这样易于使用但关键的漏洞，它可以允许任何未经验证的攻击者在Mac系统上以root权限远程执行任意代码。  
  
在安全团队的研究人员JasonGeffner和JanBee于2016年11月初发现了ESET EndpointAntivirus 6中用于macOS的关键安全漏洞（CVE-2016-9892）。  

 

如在完整的公开中详细描述的，所有黑客需要在Mac计算机上获得根级远程代码执行是使用自签名HTTPS证书拦截ESET防病毒软件包与其后端服务器的连接，中间（MITM）攻击者，并利用XML库缺陷。  
  
实际问题与名为**esets\_daemon**的服务相关，该服务以root用户身份运行。该服务与2013年3月发布的**POCO XML**解析器库版本1.4.6p1的过期版本静态链接。  
  
该POCO版本基于2007年的Expat XML解析器库版本2.0.1的版本，这受到公开已知的XML解析漏洞（CVE-2016-0718）的影响，可能允许攻击者通过恶意XML内容执行任意代码。  
  
现在，当esets\_daemon在激活ESET EndpointAntivirus产品期间向https://edf.eset.com/edf发送请求时，MITM攻击者可以使用自签名HTTPS证书拦截提交格式错误的XML文档的请求。

此事件触发CVE-2016-0718缺陷，该缺陷在esets\_daemon解析XML内容时以root权限执行恶意代码。  
  
此攻击是可能的，因为ESET防病毒未验证Web服务器的证书。  
  
以下是二人解释：  
  
“ESET Endpoint Antivirus 6的易受攻击版本与过时的XML解析库静态链接，并且不执行正确的服务器身份验证，允许远程未经身份验证的攻击者在易受攻击的客户端上以root身份执行任意代码。  
  

现在，由于黑客控制连接，他们可以发送恶意内容到Mac计算机，以劫持XML解析器和执行代码作为根。  
  
Google研究人员还发布了概念验证（PoC）漏洞攻击代码，这仅显示如何使用ESET反病毒应用程序导致崩溃。  
  
ESET在2月21日通过升级POCO解析库并配置其产品以验证SSL证书来解决此漏洞。  
  
该修补程序在版本6.4.168.0的ESET EndpointAntivirus for macOS 版本中可用。因此，使用MAC的ESET用户朋友请确保您的防病毒软件包已补丁到最新。
