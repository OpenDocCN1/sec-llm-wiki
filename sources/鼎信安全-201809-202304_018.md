# 关于VMware ESXi存在高危漏洞已被大规模勒索攻击的风险提示

近日，以VMware ESXi服务器为目标的大规模勒素软件攻击正在席卷全球，包括法国、芬苏兰、加拿大、美国、意大利等多个国家数千台服务器遭到入侵。

![](../Images/6269f350d6a0c9fdad7f5dafd7d50627.png)

腾讯、网易、某学院官网等多家网站均发出“**关于虚拟机管理软件（VMware ESXi）存在高危漏洞在国外已被大规模勒索攻击**”的相关风险提示。

工业和信息化部网络安全威胁和漏洞信息共享平台，于2月10日也发出了“**关于防范利用VMware ESXi高危漏洞实施勒索攻击的风险提示**”。

![](../Images/2ca35e66843be324080b207738c15d38.png)  

攻击者利用了2021年2月公开的高危漏洞(CNVD-2021-12321，https://www.cnvd.org.cn/flaw/show/CNVD-2021-12321)，可以向WMware ESXi软件目标服务器427端口发送恶意构造的数据包，从而触发其OpenSLP服务堆缓冲区溢出，并执行任意代码，风险等级**高**。

![](../Images/6269f350d6a0c9fdad7f5dafd7d50627.png)

漏洞回顾

  

漏洞描述

VMware ESXi 是VMware开放的服务器资源整合平台，可实现用较少的硬件集中管理多台服务器，并提升服务器性能和安全性。

VMware ESXi OpenSLP堆溢出漏洞，与ESXi宿主机处于同一网段的攻击者利用该漏洞，向目标427端口发送恶意构造请求，从而触发OpenSLP服务堆溢出漏洞，导致远程代码执行。

  

影响范围

VMware ESXi70U1c-17325551 7.0版本；

VMware ESXi670-202102401-SG 6.7版本；

VMware ESXi650-202102101-SG 6.5版本。

  

修复建议

官方已发布漏洞修复更新，鼎信安全建议您及时更新相关官方补丁避免安全风险。（更新前请做好备份！）
