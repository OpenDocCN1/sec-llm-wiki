# “国防七子”西工大遭钓鱼邮件：初判为境外黑客网络攻击，已立案侦查

西北工业大学官方公众号6月22日发布公开声明。近期，该校**电子邮件系统发现批以科研评审、答辩邀请和出国通知等为主题的钓鱼邮件****，****内含木马程序，引诱部分师生点击链接，非法获取师生电子邮箱登录权限，致使相关邮件数据出现被窃取风险**。

同时，部分教职工的个人上网电脑中也发现遭受网络攻击的痕迹。上述发送钓鱼邮件和发起网络攻击的行为对西北工业大学校内信息系统和广大师生的重要数据造成重大安全威胁。该校第一时间报警，**经公安机关立案侦查，初步判定是境外黑客组织和不法分子发起的网络攻击行为。**

**网络钓鱼攻击不绝**

**邮件安全事件频发**

  

近年来全球电子邮件攻击明显增加，**近80%的组织成为了基于电子邮件的勒索软件的攻击目标**。电子邮件凭借方便快捷、成熟可靠的属性以及适用各类业务场景的特性，在几乎所有行业中发挥着信息沟通的重要作用，这也使得电子邮件成为备受攻击的目标。

2011年，**一起持续两年时间我国各大高校、国企以及政府的大规模钓鱼邮件攻击被发现**。其邮件攻击活动主要运用社会工程学（如鱼叉式钓鱼邮件、伪装成政府军队人员的钓鱼PDF文档）手段，针对我国各大高校、国企以及政府等重要单位开展的大规模钓鱼行动。基于攻击具有极强的隐蔽性、持续性和危害性，**清华大学还进行了“钓鱼邮件演练”****，****提醒大家关注网络信息安全，邮箱登录后不会再次验证密码。**

**政企、高校用户是网络钓鱼攻击的主要目标，****用户的安全意识也是第一道防线**。因此不但要构建安全稳定的邮箱防御体系，更要不断提高员工、高校师生钓鱼邮件的防护意识，通过系统化、长期的培训，提高大家鉴别假冒邮件的能力，给政企单位及高校师生提供一个安全稳定的邮件环境。

**实战化反钓鱼演练**

**提升政企、高校单位整体安全意识**

**鼎信邮件安全意识钓鱼平台**▲****为应对钓鱼攻击事件频发以及政企、高校单位提升全员邮件安全防范意识的需求，鼎信安全**依托多年网络安全实战经验**，**为政企、高校单位客户提供实战化邮件安全反诈防骗演练服务**，根据用户单位及人员的实际情况，**设计模拟真实邮件钓鱼场景，有效检测用户单位内部人员网络钓鱼风险**。通过操作简便、高度可视化的技术工具，实施监控用户单位人员钓鱼邮件反应情况，基于单位内部人员敏感数据泄露情况，针对性分析各部门、各类别员工等针对邮件钓鱼诈骗的安全意识及行为特性，输出专业分析报告，**协助用户组织实施针对性安全意识提升工作，助力政企、高校单位增强全员网络安全意识**。
