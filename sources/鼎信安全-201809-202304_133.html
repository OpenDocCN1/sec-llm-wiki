01

漏洞描述


近日，Spring Cloud Function被披露出存在RCE漏洞,漏洞成因是由于恶意构造的SpEL表达式造成的。Spring Cloud Function 是Spring Boot 的函数计算框架，它抽象出所有传输细节和基础架构，允许开发人员保留所有熟悉的工具和流程，并专注于业务逻辑。

02

影响版本


3.0.0.RELEASE <= Spring Cloud Function <= 3.2.2

03

利用条件


远程通过HTTP攻击，攻击方式简单，可通过互联网直接实现。
