01

漏洞概述



3月9日，微软发布3月安全更新补丁，修复了71个安全问题，涉及Windows、Exchange Server、Remote Desktop Client、Azure等广泛使用的产品，其中包括权限提升、远程代码执行等高危漏洞类型。

本月微软月度更新修复的漏洞中，严重程度为关键（Critical）的漏洞有3个，重要（Important）漏洞有68个，其中包括3个0day漏洞：

Remote Desktop Client远程代码执行漏洞（CVE-2022-21990）

Windows 传真和扫描服务权限提升漏洞（CVE-2022-24459）

.NET 和 Visual Studio 远程代码执行漏洞（CVE-2022-24512）

鼎信安全提醒相关用户尽快更新补丁进行防护，避免引发漏洞相关的网络安全事件。
02

重点漏洞简述



本月发布根据漏洞性质分类如下：


  • 25个提权漏洞

  • 3个安全功能绕过漏洞

  • 29个远程代码执行漏洞

  • 6个信息披露漏洞

  • 4个拒绝服务漏洞

  • 3个欺骗漏洞

  • 21个Edge-Chromium漏洞


需要重点关注的漏洞：


  • Remote Desktop Client远程代码执行漏洞（CVE-2022-21990/CVE-2022-23285）

  • Windows Fax and Scan Service权限提升漏洞（CVE-2022-24459）

  • .NET 和 Visual Studio 远程代码执行漏洞（CVE-2022-24512）

  • HEVC Video Extensions远程代码执行漏洞（CVE-2022-22006）

  • VP9 Video Extensions远程代码执行漏洞（CVE-2022-24501）

  • Microsoft Exchange Server远程代码执行漏洞（CVE-2022-23277）

  • Azure Site Recovery 权限提升漏洞（CVE-2022-24469）

  • Windows SMBv3 Client/Server 远程代码执行漏洞（CVE-2022-24508）

修复建议



目前微软官方已针对受支持的产品版本发布了修复以上漏洞的安全补丁，鼎信安全建议受影响用户尽快安装补丁进行防护，官方下载链接：
https://msrc.microsoft.com/update-guide/en-us/releaseNote/2022-Mar
注：由于网络问题、计算机环境问题等原因，Windows Update的补丁更新可能出现失败。用户在安装补丁后，应及时检查补丁是否成功更新。
右键点击Windows图标，选择“设置(N)”，选择“更新和安全”-“Windows更新”，查看该页面上的提示信息，也可点击“查看更新历史记录”查看历史更新情况。
针对未成功安装的更新，可点击更新名称跳转到微软官方下载页面，建议用户点击该页面上的链接，转到“Microsoft更新目录”网站下载独立程序包并安装。
