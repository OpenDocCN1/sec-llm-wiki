# Apache Log4j 2远程代码执行漏洞预警

2021年12月10日，国家信息安全漏洞共享平台（CNVD）收录了Apache Log4j2远程代码执行漏洞（CNVD-2021-95914）。攻击者利用该漏洞，可在未授权的情况下远程执行代码。目前，Apache官方已发布补丁修复该漏洞。CNVD建议受影响用户立即更新至最新版本，同时采取防范性措施避免漏洞攻击威胁。

![](../Images/45c7e5d5ad0a45dfb8df272318e3d928.png)

  
  

1

**漏洞通告**

  
Apache Log4j2是一款非常优秀的Java日志框架,Apache Log4j 2是  Log4j的升级版本，该版本与之前的log4j1.x相比带来了显著的性能提升，被广泛应用，根据披露，该漏洞是由 Log4j2 提供的 lookup 功能造成，处理数据时，并未对用户输入进行过滤和检测，导致攻击者可通过构造恶意请求在目标服务器上执行任意代码。  
  

2

**影响范围**

Apache Log4j 2.x < 2.15.0-rc2

受影响的组件包括且不限于：

●Apache Druid

●Apache Flink

●Apache Flume 

●Apache Struts2

●Apache Solr

●Apache Dubbo

●Apache Kafka

●Spring-boot-starter-log4j 等

![](../Images/9781e37c6825e6c9e7cb3fb1a61dd27b.png)

  
  

3

**修复建议**  

  

1、设置jvm参数  

Dlog4j2.formatMsgNoLookups=true

2、设置  

log4j2.formatMsgNoLookups=True

3、系统环境变量

FORMAT\_MESSAGES\_PATTERN\_DISABLE\_LOOKUPS = true

4、采用 rasp 对lookup的调用进行阻断。

5、采用waf对请求内容进行检测,在waf中设置如对含有"$ { } jndi ldap 以及dnslog "的流量进行过滤和阻断。

6、非必要的业务不出网。

7、目前POC已被公开，官方已发布安全版本至log4j-2.15.0-rc2，请尽快升级到最新版本。

8、采用高版本jdk(11.0.1、8u191、7u201、6u211及以上)
