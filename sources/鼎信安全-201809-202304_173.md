**01 情况概述**

10月6日，Apache官方发布补丁更新通知来解决多个高危安全漏洞，其中包括被广泛利用的HTTP服务器中的路径遍历和文件泄露漏洞。由于Apache HTTP Server 2.4.49中路径规范化存在缺陷，攻击者可以使用路径遍历漏洞将URL映射到预期文档根目录之外的文件，从而获取服务器部分文件。

河南鼎信提醒受影响的政企客户升级Apache至最新版本，避免引发漏洞相关的网络安全事件。

  

**02 漏洞描述**

**1、****Apache HTTP Server 2.4.49中的路径遍历和文件泄露漏洞(CVE-2021-41773)**

在Apache HTTP Server 2.4.49中对路径规范化所做的更改中发现了一个缺陷，攻击者可以使用目录遍历攻击将URL映射到预期文档根目录之外的文件。如果文档根目录之外的文件未设置成“要求全部拒绝”的配置，则攻击者的请求将可能会成功。此外，此缺陷可能会泄露CGI脚本等解释文件的来源。

已知此问题已被广泛利用，此问题只影响Apache 2.4.49版本，Apache此次更新即可解决此问题。

  

**2、处理HTTP/2请求期间空指针取消引用漏洞（CVE****\-2021-41524）**

在对2.4.49 httpd进行模糊测试时，当攻击者发送特制的请求时，发现HTTP/2在处理期间检测到新的空指针取消引用，允许外部源对服务器进行DoS。

该漏洞影响2.4.49版本，尚未发现漏洞利用事件，Apache此次更新即可解决此问题。

  

**03 受影响版本**

Apache 2.4.49

  

**04 修复建议**

建议受影响的用户升级Apache至最新版本。备注：企业生产环境部署补丁前，建议进行充分测试，避免出现意外。
