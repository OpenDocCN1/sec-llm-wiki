**01**

**情况概述**

  
  
  

9月22日，VMware官方发布安全公告，披露了多个中高危安全漏洞，其中CVE-2021-22005 VMware vCenter Server任意文件上传漏洞为严重漏洞。攻击者可伪造恶意请求，通过vCenter中的Analytics服务，上传恶意文件，执行远程代码。

河南鼎信提醒受影响的政企客户**升级VMware vCenter Server至最新版本**，避免引发漏洞相关的网络安全事件。

![](../Images/129d956a417f5558e2c982ac486d0edc.png)

**02**

**漏洞描述**

  
  
  

**1、vCenter Server 文件上传漏洞(CVE-2021-22005) **** 严重**

vCenter Sever在分析服务中包含任意文件上传漏洞。VMware已评估此问题的严重性处于严重严重性范围内，最高CVSSv3基本分数为9.8。此问题不会影响vCenter Server 6.5。  

**2、vCenter Server本地提权漏洞(CVE-2021-21991) **** 高危**

由于vCenter Server处理会话令牌的方式，它包含一个本地提权漏洞。VMware已评估此问题的严重性在重要严重性范围内，最高CVSSv3基本分数为8.8。

  

**3、vCenter Server反向代理绕过漏洞(CVE-2021-22006) **** 高危**

由于端点处理URI的方式，vCenter Server包含反向代理绕过漏洞。VMware已评估此问题的严重性在重要严重性范围内，最高CVSSv3基本分数为8.3。此问题不会影响vCenter Server 6.5。  

**4、vCenter服务器未经身份验证的API端点漏洞(CVE-2021-22011)****  高危**

vCenter Sever在vCenter Sever内容库中包含一个未经身份验证的API端点漏洞。VMware已评估此问题的严重性在重要严重性范围内，最高CVSS3基本分数为8.1。  

**5、vCenter Server权限不当本地提权漏洞(CVE-2021-22015)****  高危**

由于文件和目录权限不当，vCenter Server包含多个本地提权漏洞。VMware已评估这些问题的严重性在重要严重性范围内，最高CVSSv3基本分数为7.8。  

**6、vCenter Server未经身份验证的API信息泄露漏洞(CVE-2021-22012)****中危**

由于未经身份验证的设备管理APl，vCenter Sever包含一个信息泄露漏洞。VMware已评估此问题的严重性在重要严重性范围内，最高CVSSyv3基本分数为7.5。此问题仅影响vCenter Server 6.5。  

**7、vCenter Server文件路径遍历漏洞(CVE-2021-22013)  ****高危**

vCenter Server包含一个文件路径遍历漏洞，导致设备管理API中的信息泄露。VMware已评估此问题的严重性在重要严重性范围内最高CVSSv3基本分数为7.5。此问题仅影响vCenter Server 6.5。  

**8、vCenter Server反映了XSS漏洞(CVE-2021-22016) ****低危**

由于缺乏输入清理，vCenter Server包含一个反映的跨站点脚本漏洞。VMware已评估此问题的严重性在重要严重性范围内，最高CVSSv3基本分数为7.5,此问题仅影响vCenter Server 6.7。  

**9、vCenter Server rhttpproxy 绕过漏洞(CVE-2021-22017)****  高危**

由于UAI规范化实施不当，在vCenter ever中使用的Ritproxy 包含一个漏洞。VMware已评估此问题的严重性在重要严重性范围内，最高CVSSv3基本分数为7.3，此问题不会影响vCenter Server 7.0。  

**10、vCenter Server身份验证代码执行漏洞(CVE-2021-22014)  ****高危**

vCener sever在VAM(虚拟设备管理基础架构)中包含一个经过身份验证的代码执行漏洞。VMware已评估此问题的严重性在重要严重性范围内，最高CVSSv3基本分数为7.2。

  

**11、vCenter Server文件删除漏洞(CVE-2021-22018) ****中危**

vCener sever 在VAwrare vsphere Lfe cycle Manager 播件中包含任意文件删除漏洞。VMware已评估此问题的严重性在中等严重性范围内，最高CVSSv3基本分数为6.5。

  

**12、vCenter Server XML解析拒绝服务漏洞(CVE-2021-21992)**** 中危**

由于XML实体解析不当,vCenter Server包含拒绝服务漏洞。VMware已评估此问题的严重性在中等严重性范围内，最高CVSSv3基本分数为6.5。  

**13、vCenter Server本地信息泄露漏洞(CVE-2021-22007)****中危**

vCenter Sever在分析服务中包含一个本地信息泄露漏洞。VMware已评估此问题的严重性在中等严重性范围内，最高CVSSv3基本分数为5.5。此问题不会影响vCenter Server 6.5。

**14、vCenter Server拒绝服务漏洞(CVE-2021-22019) **** 中危**

vCenter Server在VAPI(vCenter AP)服务中包含拒绝服务漏洞。VMware已评估此问题的严重性在中等严重性范围内，最高CVSSv3基本分数为5.3。  

**15、vCenter Server VAPI多重拒绝服务漏洞(CVE-2021-22009) ****中危**

vCenterSever在VAP/(yCener API)服务中包含多个拒绝服务漏洞。VMware已将这些问题的严重性评估为中等严重性范围，最高CVSSv3基本得分为5.3。

  

**16、vCenter Server VPXD拒绝服务漏洞(CVE-2021-22010) **** 中危**

vcentr sever在VPXD(MirtalPprovsioning XDzemon)服务中包含拒绝服务漏洞。VMware已评估此问题的严重性在中等严重性范围内，最高CVSSv3基本分数为5.3。此问题不会影响vCenter Server 6.5。  

**17、vCenter Server 信息泄露漏洞(CVE-2021-22008) **** 中危**

vCenter Server在VAPl(Center API)服务中包含一个信息泄露漏洞。VMware已评估此问题的严重性在中等严重性范围内，最高CVSSv3基本分数为5.3。  

**18、vCenter Server Analytics 服务拒绝服务漏洞(CVE-2021-22020) ****中危**

vCenter Server在分析服务中包含拒绝服务漏洞。VMware已评估此问题的严重性在中等严重性范围内，最高CVSSv3基本分数为5.0。  

**19、vCenter Server SSRF漏洞(CVE-2021-21993) **** 中危**

由于vCenter Sever 内容库中的URL验证不当，vCenter Server包含一个SSRF（(服务器端请求伪造）漏洞。VMware已评估此问题的严重性在中等严重性范围内，最高CvSSv3基本分数为4.3。
