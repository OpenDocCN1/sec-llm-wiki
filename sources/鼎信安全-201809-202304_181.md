**01**

  

**情况描述**

9月14日，微软发布了2021年9月份的月度例行安全公告，修复了其多款产品存在的85个安全漏洞。受影响的产品包括：Windows 10 21H1 & Windows Server v21H1（33个）、Windows 10 20H2 & Windows Server v20H2（33个）、Windows 10 2004 & Windows Server v2004（33个）、Windows 8.1 & Server 2012 R2（25个）、Windows Server 2012（23个）、Windows RT 8.1（25个）和Microsoft Office-related software（9个）。  
利用上述漏洞，攻击者可进行欺骗，绕过安全功能限制，获取敏感信息，提升权限，执行远程代码，或发起拒绝服务攻击等。河南鼎信提醒广大Microsoft用户尽快下载补丁更新，避免引发漏洞相关的网络安全事件。

![](../Images/5468768237e1645ad03fbb731b94f3c5.png)

**02**

  

**需重点关注漏洞**

**1、**MSHTML远程代码执行漏洞（CVE-2021-40444）

9月初微软披露已发现在野利用的MSHTML远程代码执行漏洞，现已发布修复补丁。  
该漏洞为9月最值得关注的重点高危漏洞，攻击者试图通过使用特制的office文档来利用此漏洞，用户在office默认设置的“受保护的视图”阅读文档可以降低风险。  

**2、**Windows打印后台处理程序远程执行代码漏洞（CVE-2021-36958）

微软在这次的2021年9月不定安全更新中，发布了针对CVE-2021-36958的新安全更新，修复了剩余的printnightmare漏洞。

  

当Windows打印后台处理程序服务不正确地执行特权文件操作时，存在远程执行代码漏洞。成功利用此漏洞的攻击者可以使用系统特权运行任意代码。攻击者可随意安装程序；查看、更改或删除数据；创建用户管理员权限的新账户。

  

**3、**Windows WLAN autoconfig服务远程代码执行漏洞（CVE-2021-36965）

此次发布补丁修复了该漏洞，该漏洞可能允许网络相邻的攻击者在受影响的系统上以系统级别运行代码。当攻击者与目标主机们在相邻的网络上，攻击者利用此漏洞可以完全接管目标。这使在公共场所下的WiFi用户非常不安全。

  

**4、**开放管理基础设施远程代码执行漏洞（CVE-2021-38647）

此漏洞为本月微软最高威胁漏洞，在开放管理基础设施（OMI）中的RCE错误。OMI是一个开源项目，用于进一步开发DMTF CIM/WBEM标准的生产质量实现。

此漏洞不需要用户交互或特权，攻击者只需向受影响的系统发送特制消息即可在受影响系统上运行攻击代码。建议OMI用户尽快测试和修复该漏洞。
