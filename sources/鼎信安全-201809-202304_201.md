# 关于微软发布2021年5月补丁更新的安全通告

（2021 年 5月）

## **一、情况描述**

2021年5月12日，微软发布了2021年5月例行安全更新，本次更新共发布CVE 55个，其中包含4个严重级别漏洞，50个重要级别漏洞。按漏洞性质分类，包括远程代码执行漏洞22个，特权提升漏洞11个。鼎信安全专家建议用户尽快修复。

## **二、漏洞概述**

本次安全更新值得重点关注的安全漏洞包括：

Visual Studio 远程代码执行漏洞（CVE-2021-27068）：成功利用该漏洞的攻击者可以通过Visual Studio 2019 在服务器上执行任意代码，并控制服务器。该漏洞无需用户交互，且利用难度低。

Hyper-V 远程代码执行漏洞（CVE-2021-28476）：成功利用该漏洞的攻击者可以在 Hyper-V 的服务器上执行任意代码，并控制服务器。

Common Utilites 远程代码执行漏洞（CVE-2021-31200）：该漏洞存在在野利用，成功利用该漏洞可在服务器上执行任意代码，并控制服务器。

 .Net Core 权限提升漏洞（CVE-2021-31204）：该漏洞存在在野利用，.NET 5.0 以及 .NET Core 3.1 受到该漏洞影响，并同时影响Visual Studio2019，成功利用该漏洞可实现权限提升。

Exchange Server 安全特性绕过漏洞（CVE-2021-31207）：该漏洞存在在野利用，该漏洞为2021 Pwn2Own上公开的漏洞，成功利用该漏洞可获得一定的服务器控制权限。

HTTP 协议远程代码执行漏洞（CVE-2021-31166）：此漏洞允许未经身份验证的攻击者以内核身份远程执行代码，攻击者通过向主机发送特制流量包可触发该漏洞，该漏洞可能造成蠕虫利用，进而造成网络内恶意程序传播。

4个关于Microsoft Exchange Server的漏洞，分别为：Microsoft Exchange Server欺骗漏洞（CVE-2021-31209）、Microsoft Exchange Server安全功能绕过漏洞（CVE-2021-31207）、Microsoft Exchange Server远程执行代码漏洞（CVE-2021-31198）、Microsoft Exchange Server远程执行代码漏洞（CVE-2021-31195），最严重的可导致远程代码执行，但据官方描述，漏洞利用需要用户交互，存在一定难度。

## **三、影响范围**

本次安全公告发布覆盖以下软件：Windows操作系统、IE浏览器、Exchange Server、.Net Core、Office、SharePointServer、Hyper-V、 Visual Studio。

## **四、修复建议**

建议所有受影响的用户及时升级修复，个人用户推荐使用电脑管家或Windows 安全更新扫描漏洞安装补丁，企业用户推荐进行漏洞扫描后下载相应补丁进行安装。

备注：企业生产环境部署补丁前，建议进行充分测试，避免出现意外。
