> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwOTc4MTE4Nw==&mid=2247489543&idx=1&sn=c8cbb806e8c4cd158fdf97b4cf99c647&chksm=976ff0aba01879bdff4f03c2c4370c467349eaf81dba59154aeb0b8ce23ea11227c584d90434&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIwOTc4MTE4Nw==&mid=2247489543&idx=1&sn=c8cbb806e8c4cd158fdf97b4cf99c647&chksm=976ff0aba01879bdff4f03c2c4370c467349eaf81dba59154aeb0b8ce23ea11227c584d90434&scene=27#wechat_redirect)

### 漏洞简介

Grafana是Grafana实验室的一套提供可视化监控界面的开源监控工具。该工具主要用于监控和分析Graphite、InfluxDB和Prometheus等。  
该漏洞允许攻击者在经过身份认证的条件下，通过修改数据源配置文件利用该漏洞进行攻击。

### 影响版本

Grafana<=6.4.3

### 漏洞复现

下载漏洞利用文件^(\[1\])  

![](../Images/635e931adc889d21ece22919526c185a.png "null")

登录 Grafana

> Configuration → Data Sources → Add data source → MySQL

![](../Images/982c4dbc5aa2c95a71cd59689254122f.png "null")

HOST 填写攻击机的 ip 地址，Database 填写

> `test?allowAllFiles=true&`

![](../Images/6375d1e9ca01782a035f4fb007f868af.png "null")

点击保存与测试，实现了任意文件读取
