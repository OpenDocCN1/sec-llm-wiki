0x02 Xshell连接虚拟机ssh

毕竟排查受害终端的时候拍照截图不方便，Xshell的可视化要比kali的控制台更加清晰，连接自己虚机截图效果要好点。

1.修改配置文件

/etc/ssh/sshd_config

使用vi或者vim编辑器打开编辑，修改下面两个位置


vim /etc/ssh/sshd_config# 找到 #PasswordAuthentication yes  把#的注释去掉PasswordAuthentication yes# 将 #PermitRootLogin prohibit-password 修改为：PermitRootLogin yesPermitRootLogin yes


2.启动ssh

/etc/init.d/ssh start

3.设置开机自启

update-rc.d ssh enable

随后可以使用xshell连接，连接的时候正常输入用户名以及密码

0x03 日志分析

结合师傅们的一些Linux入侵排查思路还有自己使用的一些tricks，偶然看到下面这个张图，写的还真的是清晰，省去找命令的时间了

0x04 常见命令

lastlog           #查看所有用户最后一次登录信息

wtmp该日志文件永久记录每个用户登录、注销及系统的启动、停机的事件。因此随着系统正常运行时间的增加，该文件的大小也会越来越大，增加的速度取决于系统用户登录的次数，该日志文件可以用来查看用户的登录记录。

last -a

last -f /var/log/wtmp #指定查看wtmp文件

awk -F: '$3==0{print $1}' /etc/passwd   #查询特权用户(uid=0）

awk '/$1|$6/{print $1}' /etc/shadow    #查询允许远程登录的用户信息

more /etc/sudoers | grep -v "^#|^$" | grep "ALL=(ALL)"          #查看是否存在其它特权账号

crontab -l #查看当前用户是否存在定时任务

cat /var/log/secure| grep -i  "accepted password"
