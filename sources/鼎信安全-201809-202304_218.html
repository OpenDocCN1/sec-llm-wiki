0x01 序言

新一度的HVV开始了，总要碰见很多需要应急处置的电脑需要查看，这里总结一下简单Linux入侵排查思路

0x02 操作

1.查看用户密码文件

cat /etc/pwd

这些用户对应的含义为

account:password:UID:GID:GECOS:directory:shell
用户名：密码：用户ID：组ID：用户说明：家目录：登陆之后shell

无密码只允许本机登陆，远程不允许登陆  

一般情况下新创建的用户都在后面几行

2.查看影子文件

cat /etc/shadow

3.常用命令


who     查看当前登录用户（tty本地登陆  pts远程登录）w       查看系统信息，想知道某一时刻用户的行为uptime  查看登陆多久、多少用户，负载usermod -L user    禁用帐号，帐号无法登录，/etc/shadow第二栏为!开头userdel user       删除user用户userdel -r user    将删除user用户，并且将/home目录下的user目录一并删除


4.查看历史命令

history

清除历史命令>history -c

5.查看端口连接情况

netstat -antlp | more

6.对应相关进程查询常用命令

ps aux | grep 6666                          #查看PID=666进程信息ll /proc/$PID 或者 ls -l /proc/$PID   #查看对应的$PID进程的文件路径lsof -p 6071                                    # 根据pid号查看进程lsof -c sshd                                     # 通过服务名查看该进程打开的文件lsof -i :22                                        # 通过端口号查看进程ps -p 6071 -o lstart                         #查看进程的启动时间点kill -9 6071                                     #kill掉对应进程

7.查看定时任务

crontab -l  # 列出当前用户的计时器设置crontab -r  # 删除当前用户的cron任务

8.查看下列路径是否存在恶意文件

9.查看日志文件

/var/log/                    #日志默认存放位置：重要日志文件secure、historymore /etc/rsyslog.conf  #查看日志配置情况

10.明确日志文件存储路径以及位置
