# 关于VMware（CVE-2021-21972，CVE-2021-21973，CVE-2021-21974）高危漏洞的安全通告

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwOTc4MTE4Nw==&mid=2247489282&idx=1&sn=f7d06b1e2a2aa97e5a6ce3e3775dacf2&chksm=976fffaea01876b87b7c5e41b6a4094a1e80456dbac1e2d5e9c89a006aafc10f6fee0a9c5b9b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIwOTc4MTE4Nw==&mid=2247489282&idx=1&sn=f7d06b1e2a2aa97e5a6ce3e3775dacf2&chksm=976fffaea01876b87b7c5e41b6a4094a1e80456dbac1e2d5e9c89a006aafc10f6fee0a9c5b9b&scene=27#wechat_redirect)

（2021 年 2月）

## **一、情况概述**

2021年2月23日，VMware官方发布安全通告，披露了vSphere Client、ESXi VMware vCenter Server SSRF的三个高危漏洞。

CVE-2021-21972：vSphereClient（HTML5）在vCenter Server插件vRealize Operations中包含一个远程执行代码漏洞，CVSSv3评分9.8。受影响的vRealize Operations插件为默认安装。

CVE-2021-21973：vSphere Client（HTML5）包含SSRF（服务器端请求伪造）漏洞。

CVE-2021-21974：ESXi中使用的OpenSLP存在堆溢出漏洞，CVSSv3评分8.8。与ESXi处于同一网段中且可以访问427端口的攻击者可触发OpenSLP服务中的堆溢出问题，从而导致远程执行代码。

## **二****、漏洞危害**

**CVE-2021-21972：**vSphereClient（HTML5）在vCenterServer插件中包含一个远程执行代码漏洞。VMware已评估此漏洞等级为高风险，CVSS 得分为9.8。恶意攻击者可能会利用此问题在托管vCenter Server的操作系统上以不受限制的特权执行任意命令。

**CVE-2021-21974：**ESXi中使用的OpenSLP存在堆溢出漏洞，VMware已评估此问题的严重性为“重要”级别，CVSS得分为8.8。与ESXi处于同一网段中且可以访问端口427的攻击者可能会触发OpenSLP服务中的堆溢出问题，从而导致远程执行代码**。**

**CVE-2021-21973：**由于vCenter Server插件中URL的验证不正确，vSphere Client（HTML5）包含SSRF（服务器端请求伪造）漏洞。漏洞等级：中等，CVSS得分为5.3。攻击者可以通过端口443访问网络向vCenter Server插件发送POST请求来导致信息泄露。

## **三、影响范围**     

**受影响版本**

**CVE-2021-21972**：

VMware vCenter Server 7.0，6.7，6.5。

VMware Cloud Foundation（Cloud Foundation）4.X，3.X。

**CVE-2021-21974****：**

VMwareESXi 7.0，6.7，6.5。

VMware Cloud Foundation（ESXi）4.X，3.X。

**CVE-2021-21973****：**

VMwarevCenter Server 7.0，6.7，6.5。

VMware Cloud Foundation（vCenter Server）4.X，3.X。

**四、修复建议**

VMware 官方已于2020年12月发布相关安全更新补丁，河南鼎信安服团队提醒 VMware 用户尽快采取安全措施阻止漏洞攻击。

1、升级VMware vCenter Server 与 VMware ESXi 至最新版本。

2、针对 CVE-2021-21972 VMwarevCenter Server 远程代码漏洞与 CVE-2021-21973 VMwarevCenter Server SSRF漏洞，可按照 https://kb.vmware.com/s/article/82374 相关措施进行缓解。

3、针对 CVE-2021-21974 VMwareESXI堆溢出漏洞，可按照https://kb.vmware.com/s/article/76372 相关措施进行缓解。
