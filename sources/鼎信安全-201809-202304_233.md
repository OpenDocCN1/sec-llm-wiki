# 关于Windows Installer在野提权0day漏洞的安全通告

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwOTc4MTE4Nw==&mid=2247489009&idx=1&sn=8ca3323435430e8bd3d73ce34eaae491&chksm=976ffd5da018744b1b40ca39c1ee50e6193949bcbeaf5b916e6cadaf40218289713cb5232304&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIwOTc4MTE4Nw==&mid=2247489009&idx=1&sn=8ca3323435430e8bd3d73ce34eaae491&chksm=976ffd5da018744b1b40ca39c1ee50e6193949bcbeaf5b916e6cadaf40218289713cb5232304&scene=27#wechat_redirect)

（2021 年 2月）

## **一、情况概述**

2020年12月26日，国外安全研究员公开了一个Windows Installer(MSI 管理器)的0day提权漏洞，该漏洞允许攻击者在最新的Windows系统中完成特权提升（运行攻击者构造的恶意程序，可能在非管理员权限登录后获取系统最高权限）。由于目前还没有补丁，该漏洞尚处于0day阶段，但漏洞利用代码（EXP）已被公开，意味着漏洞风险严重，且黑客的恶意利用可能很快到来。

## **二****、漏洞危害**

Windows Installer(MSI 管理器)中存在一处逻辑漏洞，可导致本地特权提升。攻击者可通过MSI管理器的文件备份相关逻辑漏洞，欺骗Windows Installer使用攻击者提供的rbs回滚脚本，该脚本通过修改 HKEY\_LOCAL\_MACHINE\\SYSTEM\\CurrentControlSet\\services\\Fax\\ImagePath 键值来劫持Fax服务，导致该服务启动时会以高特权运行攻击者提供的程序。

如成功利用此漏洞，任何没有特权的用户都可以在易受攻击的主机上获得系统管理员特权，可任意上传木马文件和病毒文件来破坏服务器拥有者权益。

## **三、影响范围**     

**受影响版本**

Windows101607-20H2。

Windows 8.1。

WindowsServer系统。

**四、修复建议**

建议受影响的用户避免点击未知来源的文件，恶意攻击者可能通过伪造的电子邮件附件、社交媒体消息传送诱饵文件，欺骗受害者运行。预计微软会在本月的安全更新中修复该漏洞。

建议用户开启本地防火墙或者安装、运行杀毒软件来抵挡该漏洞带来的一部分攻击。
