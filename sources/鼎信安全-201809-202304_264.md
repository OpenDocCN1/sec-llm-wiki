# 关于Apache Solr存在未授权上传漏洞的安全通报

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwOTc4MTE4Nw==&mid=2247488358&idx=1&sn=94e4e42619bdc305f3de9f920d460d33&chksm=976ffbcaa01872dca7ca65175335476d1830af13d489e878ceb6a7d1ddcecfe823dfbb0eb2f9&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIwOTc4MTE4Nw==&mid=2247488358&idx=1&sn=94e4e42619bdc305f3de9f920d460d33&chksm=976ffbcaa01872dca7ca65175335476d1830af13d489e878ceb6a7d1ddcecfe823dfbb0eb2f9&scene=27#wechat_redirect)

2020年10 月

## **一、漏洞描述**  

Solr是用Java编写、运行在Servlet容器（如Apache Tomcat或Jetty）的一个独立的全文搜索服务器。是Apache Lucene项目的开源企业搜索平台。其主要功能包括全文检索、命中标示、分面搜索、动态聚类、数据库集成，以及副文本（如Word、PDF）的处理。  

ApacheSolr近日发布公告，修复了ConfigSet API中存在的未授权上传漏洞风险（漏洞编号：CVE-2020-13957），该漏洞被利用可导致远程代码执行，鼎信安全建议尽早升级版本。

## **二、漏洞危害**  

当Solr的API未设置认证并以SolrCloud mode启动启动时，此漏洞通过使用UPLOAD/CREATE操作的组合，规避了防止远程代码执行功能的检查，从而该配置集没有经过身份验证/授权即可导致远程代码执行。

漏洞等级：高。

## **三、影响范围**

**    受影响版本：**

Apache Solr 6.6.0 - 6.6.5

Apache Solr 7.0.0 - 7.7.3

Apache Solr 8.0.0 - 8.6.2 

    **安全版本：**

Apache Solr 8.6.3 

  

## **四、修复建议**  

1\. 禁用UPLOAD命令，即\-Dconfigset.  upload.enabled=false；

2. 进行Solr的API认证；

3. 升级到8.6.3及以上，若无法升级，尝试打这个补丁：SOLR-14663；

4. 设置防火墙规则进行访问控制，设置Solr API访问的白名单。
