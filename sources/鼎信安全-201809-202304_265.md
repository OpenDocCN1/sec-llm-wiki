# Vulnhub靶场攻略：DC-2

**项目介绍**  

VulnHub是一个面向所有人开放的黑客游戏靶场练习平台，里面有好多锻炼黑客技术，学习黑客技术的游戏虚拟机供所有人下载攻打，里面大部分靶场主机都是需要控制虚拟机，获得主机的最高权限才算挑战成功，只要下载相关镜像，在相关虚拟机软件上面运行就可以进行游戏了。

**游戏目标**

本次靶场名为DC-2，整个系列共九个环境，今天玩第一个，简单级别的一个渗透练习靶场，目标是通过收集信息，获取环境中的5个flag信息，利用寻找到的信息进行下一步，最后获取到最root账户权限下的flag。

**环境搭建**

1、官网下载连接：https://www.vulnhub.com/entry/dc-2,311/

2、下载之后，使用Oracle VM VirtualBox导入靶场环境

3、为了正常练习，将靶场的网卡模式设置为桥接模式，启动即可

![](../Images/443e3071479bcb1037bbfcc9f2320bc2.png)**靶场攻略**

1、使用nmap快速扫描的命令：nmap -sP --min-hostgroup 1024 --min-parallelism 1024 192.168.1.0/24，识别到靶场主机ip

![](../Images/10421905553274f6036ea352d174beec.png)2、使用命令：nmap -A -p- -T4 192.168.1.5，探测靶场突破口

![](../Images/d4479004d15515aacbe6f00ef90de747.png)开放了7744端口号，服务为ssh，80端口，服务为http

3、访问80端口，寻找进一步突破口，直接使用ip访问会跳转到http://dc-2/，所以添加hosts文件，让这个跳转域名来访问靶场ip

![](../Images/3b098fb8ebc05d66e641388b1888c69c.png)在/etc/hosts文件中添加域名

![](../Images/fa2f6a6091fb482e2c02bf5b6a1a7d82.png)成功访问域名，并得到flag1

![](../Images/2ac57825c88a8054e86c4aba1ba5eda7.png)4、根据提示，提示使用cewl来生成字典

输入命令：cewl dc-2 > password，爬取dc-2页面，将关键字生成字典写入到password文件中

![](../Images/b3e0929e1dddc6ce49758f2b8c473818.png)5、查看网站源码，发现网站中URL目录结构为wp-\*的，猜测网站为wordpress搭建的 

![](../Images/e20a82ad38396c78627a939af5f1f0ee.png)6、使用wpscan这个专门扫描检测wordpress搭建的工具来查看是否存在已知漏洞

使用命令：wpscan --url dc-2，扫到wordpress的版本，ip地址等信息

![](../Images/c47fac8ae895d6115ba67c55bb8e535a.png)使用命令：wpscan --url dc-2 -e u，用户信息枚举，得到几个可以用来登录的账户

![](../Images/4204419d4355112bb740ab349b31d820.png)7、使用得到的用户名，创建一个username用户文件.

![](../Images/acf6695fc910e363372328075b269702.png)

使用命令：wpscan --url dc-2 -U username -P password，使用得到的用户名还有cewl得到的密码尝试爆破，成功爆破出两个账户密码

![](../Images/8364734d8250efb3fb58f485034215ea.png)8、因为wordpress的后台登录目录是公开的，所以直接访问/wp-admin，成功出现后台登录界面

![](../Images/16f83330f7a733b2466a3dbc284c85a8.png)使用爆破的账户密码，登录成功

![](../Images/5e3d90d510e498218bf8ed5179cc4586.png)在jerry账户中，得到flag2

![](../Images/66b1c248a027eb92eef895e15cf799f4.png)9、根据flag2的提示，找另一个入口，想到ssh服务，使用命令:ssh tom@192.168.1.5 -p 7744，成功登录ssh

![](../Images/9a1cc681fe619d2de8e8602230e7fdd6.png)得到flag3，因为cat无法使用，所以使用vi命令，得到提示

![](../Images/20c4d5b54dc11ebb4e632c3dfc883522.png)

![](../Images/8f3226c10554460a07bf47aa96e32e82.png)10、因为使用tab，cat等命令无法使用，所以知道当前账户是受限制的，所以可以进行rbash绕过

输入以下命令：

BASH\_CMDS\[a\]=/bin/bash  
a  
/bin/bash  
export PATH=PATH:/sbin:/bin

输入之后，可以正常使用受限制的命令了

![](../Images/72c7beb1ac5c019910f5cb3c0d020742.png)11、进行收集信息，使用命令:ls -alhR /home，得到flag4和jerry账户信息

![](../Images/716fbff4b033724071dc3cbd2e05161a.png)

![](../Images/5c1e1d7bc4316958e9aea5daeb837926.png)12、根据flag4的提示信息，明显是要使用git提权

使用命令:su jerry，切换到jerry账户

使用命令:sudo -l，查看可以无密码使用root权限的命令，果然是git

![](../Images/ff37587cdd9f934a203fa84e3b0319b8.png)13、查询到git提权的方法

![](../Images/a78737198c49106ed66c86d88b745f96.png)

 输入命令：sudo git help config

之后直接在出现的help界面，输入 !/bin/bash，成功提权

![](../Images/7346845a7d396e08e5d6cd3315ff210e.png)

切换到root账户根目录，成功得到最后的final-flag.txt 

![](../Images/405c4343503cdfd6ca19877e14fd1af7.png)
