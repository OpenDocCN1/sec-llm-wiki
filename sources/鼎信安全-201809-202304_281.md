# **（2020 年7 月）**

## **一、漏洞描述**

  

2020年7月15日，Oracle发布2020年7月关键补丁更新（Critical Patch Update，简称CPU），此次更新共修复了443个危害程度不同的安全漏洞。

其中针对 WebLogic Server Core组件，且评分为9.8的严重漏洞共有4个，分别是CVE-2020-14625、CVE-2020-14644、CVE-2020-14645、CVE-2020-14687。

它们均和T3、IIOP 协议相关，允许未经身份验证的攻击者通过网络实现远程代码执行。

  

## **二、漏洞危害**

  

由于Weblogic默认安装会自动开启控制台，控制台默认开启 T3协议。T3、IIOP 协议用于在 WebLogic 和其他 Java 程序之间传输数据。IIOP 协议以 Java 接口的形式对远程对象进行访问，默认也是在启用状态。由此，这些Weblogic漏洞尤其需要重视。

在此次披露的多个高危漏洞中，未经授权的攻击者可以利用Internet Inter-ORBProtocol(互联网内部对象请求代理协议)或者T3协议，绕过WebLoig的反序列化黑名单，从而接管WebLogic服务器。**河南鼎信安全服务部提醒 Weblogic 用户尽快采取安全措施阻止漏洞攻击。**

  

## **三、影响范围**

**** 受影响版本****

·        **CVE-2020-14625**

Oracle WebLogic Server 12.2.1.3.0, 12.2.1.4.0, 14.1.1.0.0

·        **CVE-2020-14644**

Oracle WebLogic Server 12.2.1.3.0, 12.2.1.4.0, 14.1.1.0.0

·        **CVE-2020-14645**

Oracle WebLogic Server 10.3.6.0.0, 12.1.3.0.0, 12.2.1.3.0, 12.2.1.4.0,14.1.1.0.0

·        **CVE-2020-14687**

Oracle WebLogic Server 12.2.1.3.0, 12.2.1.4.0, 14.1.1.0.0

## **四、修复建议**

**安全建议**

  

官方已为受影响组件发布了补丁。强烈建议相关客户立即安装更新。 

请用户参考官方通告及时下载受影响产品更新补丁，并参照补丁安装包中的readme文件进行安装更新，以保证长期有效的防护。  

注：Oracle官方补丁需要用户持有正版软件的许可账号，使用该账号登陆https://support.oracle.com后，可以下载最新补丁。

  

缓解措施：

若用户暂时不能安装最新补丁，可通过禁用T3、IIOP 协议，对漏洞进行临时缓解。官方安全更新：

https://www.oracle.com/security-alerts/cpujul2020.html
