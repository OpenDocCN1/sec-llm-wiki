关于SAP NETWEAVER AS JAVA 严重漏洞 (CVE-2020-6287) 的安全通报

（2020 年7 月）


一、漏洞描述


2020年7月13日，美国东部时间（SAP），SAP发布了一个安全更新，以解决一个严重漏洞CVE-2020-6287，该漏洞影响SAP NetWeaver应用服务器（AS）Java组件LM配置向导。未经身份验证的攻击者可以通过超文本传输协议（HTTP）利用此漏洞来控制受信任的SAP应用程序。


二、漏洞危害


2020年7月13日，美国东部标准时间（SAP），SAP发布了针对严重漏洞CVE-2020-6287的补丁。该漏洞影响了其NetWeaver AS for Java组件。此漏洞可能导致易受攻击的SAP安装受到损害，包括修改或提取高度敏感的信息以及破坏关键业务流程。远程未经身份验证的攻击者可以通过HTTP接口利用此漏洞，该接口通常向最终用户公开，并且在许多情况下，向Internet公开。

引入此漏洞的原因是，SAP NetWeaver AS for Java的Web组件中缺少身份验证，从而导致SAP系统上的一些高特权活动。

由于漏洞的严重性，和漏洞所代表的攻击面以及SAP业务应用程序的重要性，河南鼎信网络安全服务部强烈建议组织立即应用补丁。建议组织优先考虑面向Internet的系统和内部系统的补丁。

在撰写本报告之时，鼎信网络安全服务部门还没有意识到对这些漏洞的任何积极利用。但是，由于补丁已公开发布，因此黑客可以对潜在漏洞进行反向工程以创建针对未应用补丁系统的攻击。


三、影响范围

 受影响版本

  • SAP NetWeaver AS JAVA (LM 配置向导) Versions = 7.30, 7.31, 7.40, 7.50

潜在易受攻击的SAP业务解决方案包括（但不限于）：

  • SAP Enterprise Resource Planning(ERP)

  • SAP Product Lifecycle Management

  • SAP Customer Relationship Management

  • SAP Supply Chain Management(SCM)

  • SAP Supplier Relationship Management

  • SAP NetWeaver Business Warehouse

  • SAP Business Intelligence

  • SAP NetWeaver Mobile Infrastructure

  • SAP Enterprise Portal

  • SAP Process

    Orchestration/Process Integration

  • SAP Solution Manager

  • SAP NetWeaver

    Development Infrastructure

  • SAP Central Process Scheduling

  • SAP NetWeaver

    Composition Environment

  • SAP Landscape Manager



四、修复建议

 安全建议

官方已为受影响组件发布了补丁。强烈建议相关客户立即安装更新。 

https://launchpad.support.sap.com/


无法立即修补的组织应通过禁用LM配置向导服务来缓解该漏洞（请参阅SAP安全说明＃2939665）。

https://launchpad.support.sap.com/#/notes/2939665


如果这些选项都不可用，或者操作将花费超过24小时才能完成，则建议密切监视SAP NetWeaver AS的异常活动。


官方安全更新：

https://wiki.scn.sap.com/wiki/pages/viewpage.action?pageId=552599675
