什么是

数据库安全服务




定义


DBSS（Database Security Service），即数据库安全服务，是一种基于反向代理及机器学习机制，提供数据脱敏、数据库审计、
敏感数据发现和防注入攻击等功能的，保障云上数据库安全的数据库安全防护服务。


当用户向应用服务器发出非法访问的数据（针对数据库的漏洞攻击、越权或者权限滥用、SQL注入或数据窃取）时，数据库防火墙（即申请的数据库安全服务实例）会拒绝该数据，并进行审计。
当用户查询的数据库中包含敏感信息时，数据库防火墙会通过内容检测及脱敏后，将合规、不含敏感信息的结果返回应用服务器，应用服务器会将加工后的数据返回给客户。


功能


DBSS服务有以下功能：
支持多类型数据库：支持多种类型数据库包括：MS-SQL、MySQL、PostgreSQL和
LibrA/DWS 。
数据库安全：数据库防火墙（基于查询、表或存储过程）和权责分离。涵盖了检测、告警和实时入侵风险的防御，包括SQL注入。
数据库活动监控、审计：提供数据库列级的管理和访问活动监控。高级活动监控包括敏感数据库表和列的前后视图，可独立监控和分析数据库活动，并对未授权活动告警。
敏感数据发现：根据规则自动定位和分类敏感数据，轻松创建脱敏和审计规则。
动态数据脱敏：敏感数据被实时脱敏，确保用户不会暴露敏感信息。

约束


使用DBSS防护数据库的条件限制：
DBSS实例与被防护的数据库只能通过私有IP连接，建议将被防护的数据库与DBSS实例放在同一VPC下。如果两者不在同一VPC下，请使用VPC的对等连接方式将两者互通。
DBSS实例不支持保护云外数据库。






相关概念





数据脱敏


数据脱敏指对某些敏感信息通过脱敏规则进行数据的变形，实现敏感隐私数据的可靠保护。


SQL注入攻击


通过输入域或页面请求的查询字符串，欺骗服务器执行恶意的SQL（Structured Query Language）命令。


实例


一个实例代表了一个独立运行的数据库防火墙，用户可以在数据库安全服务界面申请并管理数据库安全实例。






价值




满足合规


对数据库的操作进行安全审计，发现问题能够及时定位，满足合规。


攻击防护


基于查询组、表或者存储过程的安全策略规则，防止数据库被攻击，持久保护云上数据库安全。


精确脱敏


通过精确的脱敏引擎，对用户的敏感数据实施实时脱敏，几乎无性能损耗，且不会改变数据在数据库中的存储。





应用场景




自建数据库的安全审计

数据库安全服务可以对存放在云上数据库应用中的用户数据进行安全防护，同时对敏感数据进行自动识别和脱敏，防止外泄。

典型部署原则

SCC-Console

安全服务管理控制台，用户通过该模块访问DBSS，提供管理DBSS实例的界面入口，实现对实例的创建、查看、删除等。

部署于Global层，两节点集群部署。

SCC-LB

安全服务负载均衡节点，对通过SCC-Service或DBSS实例访问SCC-Service的集群进行负载均衡。

部署于Region层，两节点主备部署。

SCC-Service

安全服务业务节点，实现DBSS实例的服务化管理。

部署于Region层，两节点集群部署。

SCC-GaussDB

数据库节点，为DBSS服务提供数据存储能力。

部署于Region层，两节点主备部署。

DBSS实例

为用户的数据库提供包括数据库审计、数据库防护、敏感数据识别与脱敏等安全防护能力。

部署在租户侧，由调用ECS服务创建而成。

数据库

存储在一起的相关数据的集合，这些数据可以被访问，管理以及更新。

-


DBSS的业务流：

1.   租户通过运营面（B2B场景为租户面）安全服务界面（SCC-Console）申请DBSS实例。

2.   SCC-Console通过SCC-LB将创建实例的命令发送至SCC-Service。

3.   SCC-Service根据命令要求，完成DBSS实例的创建。

4.   DBSS实例开启防护功能后可防护用户的数据库实例。

5.   SCC-Service通过SCC-GaussDB存储DBSS数据。
