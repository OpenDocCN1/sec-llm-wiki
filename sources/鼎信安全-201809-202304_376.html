在前几天的315晚会中，央视“点名下架”了“社保掌上通”app，原因是该应用利用隐藏条款和向手机系统索要权限非法盗取用户个人信息和隐私数据。


1


//
315曝光软件绝不只是下架那么简单
//


终端应用盗取公民信息隐私在近年来不是一次或几次了，从互联网巨头到中小型企业，巨量的app都在用户的日常使用中获取信息，“社保掌上通”只是在获取后进行过度的不正当使用而被惩处的。近年来，我国的网络信息建设、数字化经济蓬勃发展的同时，网络安全问题变得非常突出。尤其是公民个人信息的安全问题，随大数据、区块链经济的蔓延，隐私数据暴露格外严重。如何加强网络安全建设，成为两会-315期间各委员、代表们热议的话题。



2

//
我们的隐私是怎样一步步泄露的呢
//


在数据流量时代，数据是基础，是企业在个人终端不择手段要获取的战略性资源。某政协委员在此次报告中提到，如今的问题是对个人数据的过度采集，大数据、物联网、人工智能、云计算等领域高度依赖对个人数据的读取、采集和应用，存在着严重的云端和终端的数据安全隐患。那么一旦企业资源发生泄漏，会严重危及公民的隐私、财产和人身安全，例如前不久的华住数据泄漏事件。

同时，数据处理缺乏防护，存在严重技术安全隐患。很多企业忽视对网络安全的研发投入和技术接入，企业在采集数据中只顾获取终端权限，没有按安全技术流程标准进行操作，数据在被传输、存储、应用过程中缺乏安全加密和系统保护。因此导致地下网络犯罪高发，有不法分子以贩卖盗取的数据为生，或以手中的数据从事诈骗犯罪活动。

终端数据能被企业轻松获取，跟操作系统开发方有着极大的关系。在安卓终端中，安装应用会要求获取如图中的权限。



理论上是可以管理权限，让某些应用不对手机本身数据进行访问，但某些大型应用如果不给予所有权限，它就不让下载者使用。



在iOS中，由于苹果公司企业理念偏向保护客户，对应用获取数据是明令禁止的，也因此下架很多曾经会调用手机数据的app，甚至有明令禁止大数据获取的选项，所以较安卓系统的安全性来讲好了很多。但道高一尺魔高一丈，iOS也因此不断被研究攻破，从各种漏洞中获取用户个人信息，每次系统大更新明面上是对用户体验的优化，实际是对系统底层的安全性升级。



如图，此选项开启后会避免app获取用户操作使用数据，避免被“大数据杀熟”。但经不少用户反应，此选项开启前，app是精准对用户投送广告，而开启后，广告将变为“以量取胜”。


3


//
好用的app没有表面上那么“好用”
//


笔者想在此特意让大家留意一个app，就是咱们经常使用的为WiFi万能钥匙。


如图，app显示通过等保三级测评。万能钥匙这款app以及其后台的主要数据为公民wifi的密码，也就是个人隐私，在即将落实的新测评标准“等保2.0”中，定级标准的“对公民信息会造成严重破坏”被划为3级，在1.0中这条是二级，从而看出国家对公民个人隐私的重视大幅上升。但软件做了等保，只是说如果发生泄露数据，肯定不是软件方的责任。在安卓系统中WiFi信息存于一个可用txt文本编辑器打开的文件中，大概路径是“根目录\wifi\msc\wap-xxxxx.xxx”，这样一个文件中，可能现在大部分手机由于系统定制，这个路径是直接找不到的，而有些国内定制安卓系统可主动把这个wifi密码给共享出来，比如小米的miui有分享密码功能，点击会形成二维码，扫描后会显示password数据，此数据就是密码。从wifi万能钥匙厂家的角度来看，他们初衷应该是想保护wifi隐私的，因为在前几年软件刚出来的时候，只要自己手机下了这个软件，曾经连接过的wifi账户密码都会被上传至其云服务器中，导致家里的wifi总是能被下了软件的人连上。而现在已经没有这种情况，并且特意为软件做了三级等保。所以问题又回到了刚才的话题，安卓系统，即谷歌公司，至少未对中国公民的隐私进行有效的保护措施。


4


//
企业又该怎样做好安全工作呢
//


政府数次提高对公民隐私数据的重视程度,与公民日益敏感的个人隐私保护意识,正在给企业带来一个全新的挑战——如何落实国家相关网络安全法规的规定,防止用户隐私数据泄露,打消用户对自身的不信任感和重重疑虑?所以企业方，应该建立有效的网络安全管理机制,加强员工网络安全意识培训,打牢企业网络安全基石,防止员工因操作失误造成的数据泄露。而针对外来的网络入侵行为,在高技术门槛与高攻防成本的难关下,往往企业并不具备独立的团队,缺乏安全运维人员,在网络安全投入预算有限的条件下,需要借助更专业的第三方网络安全服务团队来寻求技术支持,以获取更强有力的安全防御能力。

无论是用户隐私数据,还是企业核心机密数据,一旦发生数据泄露,对于用户和企业而言,后果都是难以想象的。只有提高全社会的网络安全意识，建立完善的网络安全公民个人信息法律法规,提高对于个人隐私数据的保护意识,建立更安全更高效的企业网络安全防护措施，才能真正推动网络安全的个人隐私保护工作。
