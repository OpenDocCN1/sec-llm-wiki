# 黑客专用操作系统Kali Linux 2019.1版发布

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwOTc4MTE4Nw==&mid=2247486645&idx=1&sn=62788426ea23af6a770303def7e2ed8c&chksm=976fe419a0186d0f5072e1f7fc286b280f8697d30a32c5af434bf1fd2f62403e7c2f02b2979c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIwOTc4MTE4Nw==&mid=2247486645&idx=1&sn=62788426ea23af6a770303def7e2ed8c&chksm=976fe419a0186d0f5072e1f7fc286b280f8697d30a32c5af434bf1fd2f62403e7c2f02b2979c&scene=27#wechat_redirect)

好吧！标题有点唬人是吧？其实，这个操作系统确实被黑客和渗透测试人员奉为圭臬，对黑客和渗透测试人员来说也确实是个好消息。当然，这把利器掌握在谁手里，产生的社会与经济效应是不一样的，我们再次强调技术与工具本无善恶，关键是它为谁所用！

通过Offensive Security网站了解到，刚刚发布了Kali Linux 2019.1，这是2019年这把瑞士军刀给网络安全专业人士更新的第一个版本。

![](../Images/fdf6b0d8facc4d32ea9cfc0244e8d332.png)

最新版本的Kali Linux操作系统使用最高版本为4.19.13的内核以及针对众多错误的进行了修复，更新了很多补丁，以及更新了许多软件，如经典的Metasploit，还有Harvester、DBeaver等。![](../Images/316a622ffde324a286b7fd583924e426.png)  

Kali Linux 2019.1自带最新版本的Metasploit（5.0版）渗透测试工具，该工具“包括数据库和自动化API，新的逃避功能以及整个可用性的改进”，这个工具对于渗透人员来说，应该是最不陌生的一个了，此次更新使其成为更有效的服务与渗透测试人员的平台。Metasploit 5.0版是该软件4.0版本是2011年发布的，时隔8年才更新5.0版，可见其更新的重要性。Kali Linux  提供ARM映像，现在再次添加了对内核版本4.19的Banana Pi和Banana Pro的支持。

![](../Images/01322687839535e5ed7f2e53cfb6aaa2.png)

Kali Linux项目维护人员在他们的官方发布公告中说：“Veyron已被转移到4.19内核，Raspberry Pi图像已被简化，因此更容易找出使用哪一个。对于使用TFT LCD的用户，不再有单独的Raspberry Pi图像，因为我们现在在所有这些图像上都包含了re4son的kalipi-tft-config脚本，因此如果你想设置一块带有TFT的电路板，请运行'kalipi-tft-config '并按照提示进行操作。“  

![](../Images/585d849f57916111f0e9dcf8a5220015.png)

  

如今，Kali linux的虚拟机和ARM映像也已更新到最新的2019.1版本。优秀如您一样的渗透测试工程师可以直接从官方网站或Torrent网络下载新的Kali Linux ISO，如果你是老用户，那么只需运行以下命令即可将其全面升级到最新且最好的Kali版本：**apt update && apt -y**。
