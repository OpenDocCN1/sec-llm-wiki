# 国家信息安全漏洞库预警通报了微软多个安全漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwOTc4MTE4Nw==&mid=2247486571&idx=2&sn=d735766af8f4ec37f76ec6576fa3fe76&chksm=976fe4c7a0186dd1bd7053934d833bd90d775f985178fe24c63b597cafe5d38bc3ad11bef861&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIwOTc4MTE4Nw==&mid=2247486571&idx=2&sn=d735766af8f4ec37f76ec6576fa3fe76&chksm=976fe4c7a0186dd1bd7053934d833bd90d775f985178fe24c63b597cafe5d38bc3ad11bef861&scene=27#wechat_redirect)

        昨日，我们和大家一起谈到微软2019年2月周二补丁日发布的70多个漏洞补丁的文章“[Microsoft发布2019年2月安全更新](https://mp.weixin.qq.com/s?__biz=MzIwOTc4MTE4Nw==&mid=2247486562&idx=1&sn=1745c16b959ca55b98814290e4306553&chksm=976fe4cea0186dd8686fa7a353b607b67cd77a924954e84f4c6ce2acbb2ab5e8a07544dfa292&token=1998515590&lang=zh_CN&scene=21#wechat_redirect)”，昨天文章漏洞是针对CVE，而昨天CNNVD同样也根据微软官方发布了多个安全漏洞的公告，进行了通报。从通报我们了解到，包括Microsoft Office 安全功能绕过漏洞（CNNVD-201902-356、CVE-2019-0540）、Windows 脚本引擎内存损坏漏洞（CNNVD-201902-405、CVE-2019-0590）、Microsoft SharePoint 远程执行代码漏洞（CNNVD-201902-349、CVE-2019-0594）等多个漏洞。黑客可利用上述漏洞的在目标系统上执行任意代码、获取用户数据。微软公司多个产品和系统受漏洞影响。我们从昨天文章已经知道，微软官方已经发布漏洞修复补丁，建议用户及时确认是否受到漏洞影响，采取修补措施。

![](../Images/0730d252c10e7a9da6f00d1015545dbb.png)

本次漏洞公告涉及Microsoft Windows系统 、Microsoft Office、Microsoft SharePoint、Microsoft Edge、Internet Explorer、Windows DHCP 客户端等Windows平台下应用软件和组件。引用昨天文章“[Microsoft发布2019年2月安全更新](https://mp.weixin.qq.com/s?__biz=MzIwOTc4MTE4Nw==&mid=2247486562&idx=1&sn=1745c16b959ca55b98814290e4306553&chksm=976fe4cea0186dd8686fa7a353b607b67cd77a924954e84f4c6ce2acbb2ab5e8a07544dfa292&token=1998515590&lang=zh_CN&scene=21#wechat_redirect)”漏洞描述如下，供大家参考！另外，国家信息安全漏洞库关于微软公司本次漏洞情况的预警通报有更详细内容，欲了解详情，请登录国家信息安全漏洞库进行核查。

   

 - **CVE-2019-0686**\- Microsoft Exchange Server特权提升漏洞

是本月公开存在的漏洞之一，补丁更正了Exchange中的特权提升，允许攻击中继NTLM凭据并接管服务器。该漏洞最初是由Fox-IT研究员的博客文章披露的。过去几周已经属于黑客广泛讨论过的主题，所以看到使用这个bug的主动攻击就不足为奇了。如果涉及这个补丁，绝是可将此补丁视为本月测试和部署的高优先级补丁之一。

\- **CVE-2019-0626 ****\- Windows DHCP服务器远程执行代码漏洞**如果所在网络上有DHCP服务器，则此修补程序应位于您的列表顶部。该错误允许攻击者仅通过向其发送特制数据包来接管DHCP服务器。虽然它只能用于DHCP服务器，但是通过以高权限执行的网络服务执行代码可作为可疑对象。虽然漏洞利用指数的评级较低，但还是建议你安装此补丁。

\- **CVE-2019-0594****，****CVE-2019-0604****\- Microsoft SharePoint远程执行代码漏洞**攻击者代码上载特制的SharePoint应用程序包，以在SharePoint应用程序池和SharePoint服务器账户的上下文中执行其代码。通过应用程序池拆分网站，可以突破站点之间的安全。

\- **CVE-2019-0676**** - InternetExplorer信息泄露漏洞**  
Internet Explorer是大家再熟悉不过的Windows产品了，此修补程序纠正了2月份一个主动攻击漏洞。如果用户浏览黑客特制网站，攻击者可以检查目标系统上的文件。考虑到微软现在将IE列为“ 兼容性解决方案 ”，现在是了解升级策略的好时机。

![](../Images/5f39684fb27f48d72f8e89f3cced52ab.png)  

再次友情提醒： 目前，微软官方已经发布补丁修复了上述漏洞，建议用户及时确认漏洞影响，及时采取修补措施，减少因漏洞带来的安全风险！网络信息安全注重防范于未然，谨防可能造成的安全威胁，减少经济及信誉损失。
