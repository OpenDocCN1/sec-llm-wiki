# 交易所创始人去世后，加密货币投资者1.9亿美元被锁定了

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwOTc4MTE4Nw==&mid=2247486534&idx=1&sn=660c20dfbca30640d4d82b110a45c41d&chksm=976fe4eaa0186dfc2163788e857224aa9f239f7213eef5b6c29a4212715f6fef9d3eefc53496&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIwOTc4MTE4Nw==&mid=2247486534&idx=1&sn=660c20dfbca30640d4d82b110a45c41d&chksm=976fe4eaa0186dfc2163788e857224aa9f239f7213eef5b6c29a4212715f6fef9d3eefc53496&scene=27#wechat_redirect)

**加拿大最大的虚拟货币交易所QuadrigaCX在去年12月因其CEO Gerald Cotten去世后，因无法访问密码或恢复密钥被锁定。**

据英国卫报报道，因**虚拟货币交易所QuadrigaCX**创始人去世后，大约1.9亿美元的加密货币已被锁定无法解密，显然我们看到加密货币的“安全性”了，而无法获得这笔资金。

![](../Images/2044ff1fe86afbd7a5932105fb3f530d.png)

  

据该公司称，30岁的Cotten去年12月发病死于印度。接此消息后，加拿大帝国商业银行（CIBC）以资产无法确定基金的真实所有者决定冻结 Quadriga持有的2800万美元。Robertson可以访问Cotten的笔记本电脑，但她无法打开它，称：“Gerry执行公司业务的笔记本电脑是加密的，不知道密码或恢复密钥。尽管经过反复和努力的搜索尝试，还是无法找到解决之道。”在Cotten去世后，该平台继续接受资金，在1月26日被董事会暂停。
