# 友情提醒：微软将在今后1年内终止Windows 7

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwOTc4MTE4Nw==&mid=2247486327&idx=1&sn=03061cbfc227a4732b01a109eab487c3&chksm=976fe3dba0186acdf6ebdc42b9de126c059885aa05db611dae48e3ce3774dccc8e0f72bb2f93&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIwOTc4MTE4Nw==&mid=2247486327&idx=1&sn=03061cbfc227a4732b01a109eab487c3&chksm=976fe3dba0186acdf6ebdc42b9de126c059885aa05db611dae48e3ce3774dccc8e0f72bb2f93&scene=27#wechat_redirect)

对于仍然坚持使用Windows 7操作系统的人来说，这是一个新的提醒：还有一年时间微软将终止Windows7的维护。微软终止对其已有9年历史的Windows 7操作系统的支持。可以说，现在是时候升级操作系统，向Windows 7说再见了！其五年的延长增值服务支持将于2020年1月14日结束，据距离今天已经不足一年了。  
在那之后，微软这个科技巨头将不再发布免费的安全更新、错误修复和操作系统的新功能。当然，该操作系统仍然可以被人们广泛使用，最终可能使大量用户更容易受到恶意软件攻击，也就是其因恶意攻击产生的后果则有使用者个人自己独立承担。但是，免费支持的终结并意味着终止Windows 7对大型企业和企业客户的支持。与往常一样，微软确实继续为那些愿意花很多钱购买增值服务的公司做了例外的支持。

![](../Images/c64bc5d0d392595385b8a32ee8630396.png)

根据内容交付公司Kollective发布的“Windows 7之死” 报告，多达43％的企业仍在使用这个已有9年历史的操作系统，其中17％的企业不知道微软的支持截止日期究竟何时到来。于此，看到我们这篇文章的人有福了，至少他们可以提前做好准备，做到未雨绸缪防范于未然。

Windows7在用户中的受欢迎程度高吗？要知道即使在自2015年以来，微软发布并积极推动Windows 10安装之后，其市场份额才在去年年底之前成功超越Windows 7用户量。Windows 7于2009年发布，根据2018年12月Netmarketshare的统计数据，目前约占全球PC机队数量的37％，远远领先于其后重新设计的Windows 8和8.1的继任者。  
微软在2015年1月停止了对Windows 7 的主流支持，但作为该公司延长支持的一部分，Windows用户仍然可以继续收到已知安全问题的安全更新和补丁，该延期支持运行时长为五年。2017年3月，微软还做出了开始阻止运行英特尔，AMD，高通等最新处理器措施，在Windows 7和Windows 8.1用户的新安全补丁和更新。  
Netmarketshare 表示：“对于Windows 7在任何现代芯片上运行，设备驱动程序和固件需要模仿Windows 7对中断处理，总线支持和电源状态的期望，这对WiFi、图形、安全性等都具有挑战性，了解此生命周期中的关键日期可帮助您做出有关何时更新、升级或对软件进行其他更改的明智决策。”  
除了明年终止对Windows 7的支持外，微软还将在2020年终止对MS Office 2010，Windows Server 2008/2008 R2，SQL Server 2008/2008 R2，Exchange 2010和Windows Embedded 7等一系列产品的支持。  
至于Windows 8，操作系统的延长支持则将于2023年1月10日结束。

那么，还留恋Windows 7的广大朋友应该怎么做？  
如果是企业仍在运行Windows 7，您还有一年的时间可以升级到最新的操作系统。当然，政府机构和大企业如果他们需要一年以上的时间才能迁移到新版本，继续从微软公司获得安全更新和补丁，则可以仍然可以选择支付高昂费用用于扩展支持。普通用户则建议你将其操作系统升级到Windows 10或该换为Linux发行版，当然你不升级或不改版，则面临的风险就是会日益受攻击的可能性大大提升，相信大家对Windows XP操作系统停止支持后，发生的诸多攻击也耳有所闻吧。

在此我们相信，你看到这篇文章，对你使用Windows系统过程中有个参考，特别是还在使用Windows 7系统的朋友，自然可以提前做好万全的准备，以防出现不好的结果。在此，再次提醒广大Windows 用户朋友，如果你还在使用Windows 7 操作系统，请注意微软公司将于2020年1月14日结束对它的技术支持。
