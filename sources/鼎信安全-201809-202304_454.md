# Microsoft针对9个严重漏洞发布软件更新

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwOTc4MTE4Nw==&mid=2247486253&idx=1&sn=6bf66f59ec0f5950d2f342301a83ad8e&chksm=976fe381a0186a97bcf2ef2ddbfe5d65d985731e3124abc04910c05431535a8e0bed904b479e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIwOTc4MTE4Nw==&mid=2247486253&idx=1&sn=6bf66f59ec0f5950d2f342301a83ad8e&chksm=976fe381a0186a97bcf2ef2ddbfe5d65d985731e3124abc04910c05431535a8e0bed904b479e&scene=27#wechat_redirect)

微软在2018年发布了一个相对较小的39个安全补丁，涵盖Internet Explorer（IE），Edge，ChackraCore，Microsoft Windows，Office和Microsoft Office Services和Web Apps以及.NET Framework等产品或组件。在这39个CVE中，9个被列为严重，30个被评为重要性严重。让我们仔细看看本月的一些更有趣的补丁，从主动预防攻击的开始：![](../Images/82ed52bf495f9921042e18b152c49492.png)  

**CVE-2018-8611**** - Win32k****特权提升漏洞**12月份连续第三个月出现了Win32K（内核模式驱动程序）特权提升漏洞，当前该漏洞列为主动攻击。与前几个月的情况一样，卡巴斯基实验室的研究人员报告了这个漏洞，表明这个漏洞正在恶意软件中得到使用。同样，这可能与其他漏洞一起用于针对性攻击。

**CVE-2018-8626**** - Windows DNS****服务器堆溢出漏洞**Windows DNS服务器中的漏洞，该漏洞可能允许攻击者在LocalSystem帐户的上下文中执行代码。利用此漏洞就像向受影响的DNS服务器发送特制请求一样简单。由于DNS服务器旨在处理请求的特殊性，除了应用补丁之外，暂时没有其他真正的防御措施。如果您在企业中运行DNS服务器，请务必优先考虑修补此服务器。  

**CVE-2018-8540**** - .NET Framework****远程代码注入漏洞**此修补程序解决了.NET Framework中的严重级别RCE，如果攻击者使用易受攻击的.NET将特定输入传递给应用程序，则可能允许攻击者控制系统方法。在应用此修补程序后，是否需要重新编译.NET应用程序尚不清楚，但通常情况下，可以完全保护输入验证错误。

**CVE-2018-8634**** - Microsoft****文本到语音远程执行代码漏洞**该漏洞涉及文本到语音的新功能的一些未知的攻击面。这不是第一个文本到语音相关的漏洞。几年前Android出现一个不常见的类似漏洞。其次，Microsoft本次没有说明示例漏洞可利用场景，但由于生成语音需要向Speech服务发出HTTP POST请求，因此如果您的应用程序面向网络，使用文本转语音，请不要忽略及时打上此补丁。
