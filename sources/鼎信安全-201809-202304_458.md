# 美国邮政将超过6000万用户数据置于风险中超过一年

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwOTc4MTE4Nw==&mid=2247486239&idx=1&sn=419b7a93e70ef790f281e456a2da157e&chksm=976fe3b3a0186aa5bc91725fb71a0eb7471a47568c2c8b0a93720da984e5d841d79112eab5f0&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIwOTc4MTE4Nw==&mid=2247486239&idx=1&sn=419b7a93e70ef790f281e456a2da157e&chksm=976fe3b3a0186aa5bc91725fb71a0eb7471a47568c2c8b0a93720da984e5d841d79112eab5f0&scene=27#wechat_redirect)

  

美国邮政局修补了一个严重的安全漏洞，该漏洞导致超过6,000万客户的数据暴露给在USPS.com网站上拥有账户的任何人。USPS是美国联邦政府的一个独立机构，在美国提供邮政服务，是美国为数不多由宪法明确授权的政府机构之一。该漏洞与USPS旨在帮助企业客户实时跟踪邮件的“InformedVisibility”程序的应用程序编程接口（API）中的身份验证弱点有关。

![](../Images/742712d52cdf90736ca092f648926e0b.png)

根据不愿透露其身份的网络安全研究员的说法，通过API漏洞编程为接受任意数量的“通配符”搜索参数，使登录到usps.com的任何人都可以向系统查询属于其他任何用户的帐户详细信息。换言之，攻击者可以从多达6,000万USPS客户帐户中提取到有关客户的电子邮件地址、用户名、用户ID、帐号、街道地址、电话号码、用户授权和邮寄活动数据等。  

![](../Images/f7e7a8c21cbb994399df7af1b7f82a16.png)

Setu Kulkarni WhiteHat Security 表示，在规模化互联网B2B连接和安全性方面，API正在成为一把双刃剑。不安全的API打破了他们帮助用户的初衷。为了避免类似的缺陷，政府机构和公司必须积极主动，而不仅仅是应对安全方面的反应。处理消费者数据的每个企业都需要使安全成为一致的，首要考虑的问题，并且有义务执行最严格的针对易受攻击途径的安全测试：API，网络连接，移动应用程序，网站和数据库。依赖数字平台的组织需要通过适当的安全培训，教育并授权开发人员在整个软件生命周期（SLC）中使用安全最佳实践进行编码和认证。

![](../Images/d490ab7ef875da906384ffe67d8a1f96.png)

  

据报道，虽然相关部门在短短48小时内解决了相应的漏洞问题，然而其实该漏洞去年已被发现，也就是说USPS延迟了一年多的时间才负责任的披露该消息，并修复相关漏洞。他们并且表示出于谨慎考虑，将进一步调查，以确保这一年来是否有人利用此漏洞，做不利于客户的事情。如果存在有人恶意利用该漏洞，则他们亦将诉诸法律手段。
