# 九月份恶意软件之“十恶不赦”排行榜

**从****Check Point****最新的全球威胁指数显示来看，针对****iPhone****用户的恶意加密软件攻击呈****400%****的增长。****安全研究人员发现，针对****iPhone****的加密恶意软件攻击增加了近****4****倍。特别是****9****月的后两周出现了激增，同时针对****Safari****浏览器用户的攻击也大幅增加。这些攻击使用了****Coinhive****挖掘恶意软件，最早于一年前****2017****年****9****月被发现后，该恶意软件从****2017****年****12****月以来一直霸占着恶意软件头号位置。**  

![](../Images/696205da7be0875b71c547620930abcd.png)

**加密货币挖掘仍然是世界各地组织面临的最猖狂的主要威胁。从研究看，对****Apple****设备的攻击没有使用任何新功能。增加背后的原因尚不完全清楚，但有助于提醒我们的是移动设备是组织被攻击面中经常忽视的元素。阻止移动设备成为企业安全防御的薄弱环节，移动设备保护防御解决方案已变得至关重要。**  

**Coinhive****现在影响占全球被检测组织的****19****％，稳居恶意软件排行榜之首，较上月提升2个百分点。与此同时，能够窃取敏感信息并发动拒绝服务攻击的木马****Dorkbot****仍位居第二，全球影响力为****7****％。**

* * *

*\*****箭头与上个月的排名变化有关****。*   

1.  **↔****Coinhive ** - **Crypto Miner**， **Cryptominer**，用于在用户访问网页时执行**Monero**加密货币的在线挖掘，在用户不知情的情况下通过挖掘门罗币获得收入利润。植入的**JavaScript**使用用户机器的大量算力来挖掘加密货币，并可能致使系统崩溃。。
    
2.    **↑****基于Dorkbot ** -是一种基于**IRC**设计的蠕虫，可以以操作员执行远程代码，以及下载其他恶意软件到被感染的机器。是一个银行木马，其主要动机是窃取敏感信息并可以发起拒绝服务攻击。
    
3.   **↓Cryptoloot** - **Cryptominer**，利用受害者的**CPU**或**GPU**功率和现有的资源开采加密的区块链和发布新的加密货币，是**Coinhive**的有力竞争对手。
    
4.   **↑Andromeda** - 是一款模块化僵尸程序，主要用作后门。在受感染的主机上，可以修改以创建不同类型的僵尸网络，运行其他的恶意软件。
    
5.    **↔****Jsecoin **\- 可以嵌入网站的JavaScript矿工。使用JSEcoin，可以直接在浏览器中运行矿工，以换取无广告体验，游戏内货币和其他奖励。
    
6.  **↓Roughted** - 大规模攻击各种网站和有效负载，以提供用于恶意广告传播，如诈骗广告软件，漏洞利用工具包和勒索软件。可用于攻击任何类型的平台和操作系统，并可以绕过广告拦截软件和指纹识别，以确保其进行最有效的相关攻击
    
7.  **↑Ramnit** - 是一款能够窃取银行凭据，**FTP**密码，会话**cookie**和个人数据的银行特洛伊木马。
    
8.    **↔****XMRig **\- 是一种开源利用**CPU**进行挖掘恶意软件，用于挖掘**Monero**加密货币，并于**2017**年**5**月首次被发现。
    
9.    **↓Conficker- **允许远程操作和恶意软件下载的蠕虫。受感染的计算机由僵尸网络控制，僵尸网络与其命令和控制服务器联系以接收指令。
    
10.  **↑****Emotet** - Emotet是一种针对Windows平台的特洛伊木马程序。此恶意软件将系统信息发送到多个控制服务器，并可下载配置文件和其他组件。据报道，它针对某些银行的客户，并挂钩各种API来监控和记录网络流量。该恶意软件会创建一个Run    key注册表项，以便在系统重新启动后启动。
     
     * * *
     
       
     
       
     
     **八月份三大移动恶意软件：**
     

*   **Lokibot -     Android**银行木马和信息窃取程序，它也可以变成一个勒索软件，以锁定手机，以防其管理员权限被删除。
    
*   **Lotoor -     Hack**工具利用**Android**操作系统上的漏洞获取受感染移动设备的root权限。
    
*   **Triada  -     Android**的模块化后门，为下载的恶意软件授予超级用户权限，有助于它嵌入到系统进程中。Triada也被视为欺骗浏览器中加载的URL。

    **九月份的三大漏洞：**  
    
*   **↔****MicrosoftIIS     WebDAV ScStoragePathFromUrl****缓冲区溢出（****CVE-2017-7269****）** - 通过在R2通过Microsoft Internet Information Services 6.0中的网络到Microsoft Windows Server 2003发送制作的请求，远程攻击者可以执行任意代码或引起拒绝目标服务器上的服务条件。这主要是由于HTTP请求中对长报头的不正确验证导致的缓冲区溢出漏洞。
    
*   **↑OpenSSL     tls\_get\_message\_body****函数****init\_msg****结构使用后免费（****CVE-2016-6309****）** - 在OpenSSL的tls\_get\_message\_body函数中报告了该漏洞。利用此漏洞远程攻击者在未经身份验证情况下可以通过向易受攻击的服务器发送消息。成功利用该漏洞后允许攻击者在系统上执行任意代码。
    
*   **↑Web****服务器****PHPMyAdmin****错误配置代码注入** -     PHPMyAdmin中已报告代码注入漏洞。该漏洞是由于PHPMyAdmin配置错误造成的。远程攻击者可以通过向目标发送特制的HTTP请求来利用此漏洞。

    **鼎信在此友情提醒广大用户朋友们，请核查自家运行（运营）的信息系统，看是否在影响之列，抓紧时间修补漏洞，提升自身信息系统整体安全性。通过长效机制，做好自家单位的网络安全工作。充分调动主管能动性，主动履行法律法规及政策要求。做到最大限度的合规，使自身系统的违规成本降至最低。积极落实网络安全等级保护制度，推进网络安全工作开展。有关网络安全等级保护制度可以参见《****网络安全法****》、《****网络安全等级保护条例****》（征求意见稿）等法律法规内容。**
