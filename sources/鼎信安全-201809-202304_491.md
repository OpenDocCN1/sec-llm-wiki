# 世界同步：OT安全性的基础是认真落实合规性

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwOTc4MTE4Nw==&mid=2247486028&idx=1&sn=59ebeacb8563d7a16388ed3737e11409&chksm=976fe2e0a0186bf6b5f590b2e995af5b2396318dbb0efaf34ab46ccdc73d176c2c3f3760c503&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIwOTc4MTE4Nw==&mid=2247486028&idx=1&sn=59ebeacb8563d7a16388ed3737e11409&chksm=976fe2e0a0186bf6b5f590b2e995af5b2396318dbb0efaf34ab46ccdc73d176c2c3f3760c503&scene=27#wechat_redirect)

法规是各个公司用来设定自己的政策方针、管理制度和操作规程的良好实践基准。是提高公众对法律法规及标准的认识，便于企业用户在不满足法规标准时，清楚需要承担相应的责任。作为企业组织应该明白合规性的影响力是全面的，且是完全正面的，企业组织不应将其视为是一种负担。

![](../Images/5e7723a0be6770539eedff74d252ad29.png)

   

在关键信息基础设施方面，现在已经有许多国家及国际机构已经着手制定或制定了**OT**网络安全的监管框架和标准。虽然他们的存在都有所不同，但总体目标是一致的：**促进最佳安全标准的实践，并确保对未能满足这些标准的人与组织，能够采取惩罚性强制执法，以期其满足对应标准**。 

合规作为一全球法律体系正在不断发展完善，其中欧盟和美国仍处于领先地位，欧盟有网络与信息安全（NIS）指令。美国则有**NERC**的关键信息保护（**CIP**）标准可用于对电力行业的安全漏洞，处罚高达一百万美元的罚款，是当今世界上运行最成熟的网络安全规则之一，而像**NIST**网络安全框架这样的新举措做的则更为全面。 

![](../Images/402c90adff9b0dfcb66cd2c1606934ce.png)

其他国家也正在实施自己的监管制度标准。仅举几例，如加拿大和卡塔尔已经出台，目前俄罗斯，南非和韩国正在开发。西方国家也在关注我国相关法律法规的制定，他们也在一致关注预计很快将在中国制定实施的**关键信息基础设施保护条例**（**CIIPR**）的最终草案。 

结合国际上有关法律法规的制定进程，这一全球法律体系虽然各有不同，却共同意味着，对于各国电力，石油和天然气，水和化学品等行业的供应商而言，遵守网络安全标准的监管不再是一种选择。而是要做好准备，否则当法律法规开始实施时，企业组织将会被强制执行，并面临巨额罚款的惩罚。

![](../Images/fdcfe1f76f8e3bd105844db44ddbd01c.png)

**不同的国家区域各有自己独立的立法方法及程序，这为跨国监管带来了一项挑战。围绕地缘政治冲突和知识产权保护的国际紧张局势，突出了对个国家区域**敏感**要求的重要性，与跨国协调监管是反向而行。**  

例如，即使在欧盟成员国内部，也有存在着一些微妙但重要的方式，影响着**NIS**指令在该区域解释，并最终将影响企业。英国，德国和法国实施的相关机构都需要采用不同类型的风险评估和流程，最终解读自然存在差异性。同时，欧盟大部分的经济体正实现将**NIS**完全纳入当地法律。

以强有力的监督，满足监管机构要求的标准，只是创建真正安全环境的开始第一步。美国计算机安全研究中心**5**月份发布的一份报告发现，尽管有法规规定，目前的激励措施只是倾向于一定程度上缩短执行的时间。企业组织并没有主动采取保护措施，去更广泛的使用最先进的工具和技术。但法规有助于提高组织中高级决策者对安全性和问责制的认识，并且他们越来越愿意参与旨在提高安全性长期战略中来。这一转变，使得原来必须有**IT**安全人员必须力争的一小部分**IT**预算，已经成为有高级管理层主动考虑将其列在预算的计划中。一定程度上，提升了安全工作者的话语权，理所当然为安全工作带来了正向推动作用。因为没有企业希望面对因网络安全事件，特别还要面临监管机构惩罚性的大额罚款之后，造成生产停工或声誉受损。随着公众意识的提高，如果没有做好充分的安全保障，也会引起利益相关者和投资者将网络安全合规作为对企业管理层的考察和考核。

![](../Images/9a96e23c366603bcb31c828e862097d1.png)

**明确合规性不等于安全性，合规性是实现安全性的第一步，而如果连合规性都未满足更谈不上安全性，所以首先理解一点合规性是走向安全性的第一步且是非常有必要。合规性同时也是规避政策风险的一个必要条件。所以合规性对于安全性来说是必要条件。**  

同时**OT**安全实践仅被视为内部和外部专家关注的问题是不够的，整体考虑应不会影响专业之外的工作流程和例程。网络安全和意识是所有员工的责任，必须开发更好的风险沟通机制和风险挑战的方法。

不断改进沟通方法，理解和采用最佳做法。需要采用与物理安全的相同举措和流程应用于**OT**网络安全，使其具有相同的效果。

![](../Images/691ebc6f3a9ef5df63bf9c3918f98747.png)

对决策者来说的好消息是可以通过与安全从业者建立联盟互动并通过这种方式培养主动合规的内部安全文化，合规问题本身将变得不再是一种负担，而是成为习以为常融入内部文化体制内的一种文化习惯。如果你的目标是真正关注安全，这将是领先于监管机构的理念，那么自然你很轻松的已经满足了当地法律的许多关键要求，监管机构也乐于见到这种超前的落实法律法规理念的在企业间流行。  

只要你真心关注安全，其实合规性并不难，但是千万不要把合规性与安全性混为一谈。合规性并不一定意味着绝对的安全性，合规性是你的单位或企业实现最基础的安全性，采用网络安全最佳实践实现安全性肯定有助实现合规性。
