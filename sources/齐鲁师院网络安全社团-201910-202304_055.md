# 第十三届科技节——首届网络安全技能大赛

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU3MDU5NTA1MQ==&mid=2247488722&idx=1&sn=418e438367cbf081a69389089d1d9aa5&chksm=fcec5756cb9bde40147c2dacb5c1c946e4a6d46f2d68cd589db8b5119ceef7aefeb57d0374a1&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzU3MDU5NTA1MQ==&mid=2247488722&idx=1&sn=418e438367cbf081a69389089d1d9aa5&chksm=fcec5756cb9bde40147c2dacb5c1c946e4a6d46f2d68cd589db8b5119ceef7aefeb57d0374a1&scene=27#wechat_redirect)

2021年10月29日，第十三届山东省大学生科技节-首届全省网络安全技能大赛的决赛在泰安市圆满结束。

经过6个小时的激烈角逐，我院网络安全社团的程思翰和孔欣宇同学获得团体三等奖的好成绩！

![](../Images/8188cfcb382630ac36d025ee6b90804c.png)

  

上午9点，首届全省网络安全技能大赛决赛拉开了序幕。

![](../Images/6bd2403d1cccea3c792020ee80caa1d6.png)

比赛采用线下 CTF（夺旗赛），通过离线分析或在线交互的方式，克服技术挑战获取“红旗”，考察内容包括 Web 渗透、二进制漏洞挖掘利用、密码分析、取证分析、逆向分析、安全编程等网络安全技能。

![](../Images/920b3450283b071ddd71b968449f76ad.png)

下午3点决赛落下帷幕，程思翰和孔欣宇同学最终拿下了团体三等奖的优异成绩。他们凭借着对网络安全的热爱，不断的学习扩充自己的知识储备，成功站上了领奖台！努力和付出终于得到回报。

网络安全在如今得到越来越多的重视，没有网络安全就没有国家安全，而此次大赛的目的正是为了促进网络安全知识的宣传普及，培养发现更多的优秀网络安全人才。

![](../Images/6998b30437f83e78bf73e9bf0d76171c.png)

网络安全社团深入学习贯彻落实习近平总书记的网络强国战略思想，树立正确的网络安全观，实现网络安全和网络发展同步推进。
