Fastjson 是一个 Java 库,可以将 Java 对象转换为 JSON 格式,当然它也可以将 JSON 字符串转换为 Java 对象 fastjson在解析json的过程中,支持使用@type字段来指定反序列化的类型,并调用该类的set/get方法来访问属性,当组件开启了autotype功能并且反序列化不可信数据时,攻击者可以构造数据, 使目标应用的代码执行流程进入特定类的特定setter或者getter方法中,即可构造出一些恶意利用链。

## 漏洞分析

### autotype

fastjson提供了autotype功能，允许用户在反序列化过程中中通过“@type”指定反序列化的Class类型，这个字段可以指定反序列化的任意类，并且会自动调用类中属性的特定的set、get方法。在1.2.24版本及之前，autotype默认开启，没有限制，在之后的版本中加入了黑名单限制，默认关闭autotype等机制。

### RMI触发点

由于这里的DataSourceName值经过构造后可控，导致了RMI漏洞

```
DataSource var2 \= (DataSource)var1.lookup(this.getDataSourceName());
```

### 漏洞跟踪分析

这里首先跟踪lookup方法，在connect()方法中当getDataSourceName不为空时，会触发lookup方法。

```
    private Connection connect() throws SQLException {
        if (this.conn != null) {
            return this.conn;
        } else if (this.getDataSourceName() != null) {
            try {
                InitialContext var1 \= new InitialContext();
                DataSource var2 \= (DataSource)var1.lookup(this.getDataSourceName());
                return this.getUsername() != null && !this.getUsername().equals("") ? var2.getConnection(this.getUsername(), this.getPassword()) : var2.getConnection();
            } catch (NamingException var3) {
                throw new SQLException(this.resBundle.handleGetObject("jdbcrowsetimpl.connect").toString());
            }
        } else {
            return this.getUrl() != null ? DriverManager.getConnection(this.getUrl(), this.getUsername(), this.getPassword()) : null;
        }
    }
```

再来看connect()是怎么被调用的，这里我们找到了调用connect()的三个方法

```
prepare()
getDatabaseMetaData()
setAutoCommit()
```

经分析，前两个无法进行调用，这里我们来看setAutoCommit()方法

```
public void setAutoCommit(boolean var1) throws SQLException {
    if (this.conn != null) {
        this.conn.setAutoCommit(var1);
    } else {
        this.conn \= this.connect();
        this.conn.setAutoCommit(var1);
    }
}
```

这里上面有提到，fastjson在反序列化时，自动对字符串的属性进行调用对应的set、get方法，即上面设置了autoCommit的值时，就会调用setAutoCommit方法。

### 思路总结

漏洞起因是在`JdbcRowSetImpl.class`文件中 `lookup()`发起了一个rmi服务，由于`lookup()`中的`DataSourceName()`可控，导致rmi远程地址由用户可控，通过传入`autoCommit`的值来调用`setAutoCommit`，从而调用`connect()` 方法，进而调用内部的`lookup()`方法，传入`dataSourceName` 的值来控制rmi的远程地址，达到任意代码执行目的。由于默认开启了`autotype`，因此我们可以在将 `@type` 的值设置为 `JdbcRowSetImpl`，使用该类进行反序列化操作。
