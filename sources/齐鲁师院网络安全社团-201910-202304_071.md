# 齐鲁师范学院第六届信息安全竞赛

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU3MDU5NTA1MQ==&mid=2247487936&idx=1&sn=11a84a5771e53a4fecd91718aa21a254&chksm=fcec5244cb9bdb5238ed5458c614ea8d87fecd6b0e9c67a1e6cf24a15b73b43f840b1d392c40&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzU3MDU5NTA1MQ==&mid=2247487936&idx=1&sn=11a84a5771e53a4fecd91718aa21a254&chksm=fcec5244cb9bdb5238ed5458c614ea8d87fecd6b0e9c67a1e6cf24a15b73b43f840b1d392c40&scene=27#wechat_redirect)

  
  

   为积极响应教育部《大中小学生国家安全教育指导纲要》要求，深入贯彻落实网络强国战略思想,提高在校生的网络安全意识，选拔新一批热爱网络安全的学生加入QLNU战队，并为全国大学生信息安全竞赛储备安全人才。2021年4月8日，齐鲁师范学院第六届信息安全竞赛圆满落幕。

   此次竞赛秉承“寓学于赛，以赛促学”的理念，将赛前指导、赛中锻炼和赛后交流三者有机结合，使参赛选手不仅可以参与比赛，还可以有针对性的学习。

赛前准备

  本次比赛采取解题赛，由QLNU战队核心成员命题，采取线上靶场的比赛模式，参赛队伍需要在线解题。题目分为基础编程题目，软件逆向 (ReverseEngineering)，密码（Crypto）、杂项（Misc）、Pwn、Web。每种类型的题有不同的分值，参赛队通过获得 Flag 从而得到对应的分值，按照积分高低和提交Flag时间进行排名，由QLNU战队核心成员命题，经过两个月认真努力的准备，一次次的反复测试，只为比赛的顺利进行，最终成功的呈现出一场极为精彩的比赛。

比赛现场

  本次比赛持续五个半小时，对参赛人员的脑力、体力、耐力与技术都是一个很大的考验，上午十点半比赛开始，赛场气氛瞬间紧张，所有参赛选手精力充沛，高度专注，手指在键盘上飞舞，大脑高速运转，所有人都为了解题拼尽全力，用尽浑身解数，让自己这段时间以来的努力得以体现，比赛进行到两个小时，选手都由些许疲惫，但是在微微调整状态后又整装待发，最终五个半小时结束，所有选手的脑力和体力都已达到极限同时也坚持到了最后一刻，获得了成功。
