一.LAMP环境搭建

1.Linux环境

首先，准备一个linux环境（我安装的是CentOS8）

第一次启动后，打开terminal终端，更换yum源为国内阿里云

2.安装Mysql

terminal中输入

sudo dnf install @mysql

安装mysql，成功后输入

systemctl start mysqld.service
启动mysql服务，参考文档https://www.cnblogs.com/kasnti/p/11929030.html ，配置好相关参数，输入以下命令添加到开机启动
sudo systemctl enable --now mysqld
最后输入
systemctl status mysqld
查看mysql状态，显示正常（running）即可


3.安装Apache

yum install httpd

安装完成后输入

systemctl start httpd

启动Apache，然后添加到开机启动

systemctl enable httpd

最后输入

systemctl status httpd

查看状态，显示(running)即可


4.安装php

yum install php php-devel

安装php扩展

yum install php-mysql php-gd php-imap php-ldap php-odbc php-pear php-xml php-xmlrpc

由于php-imap报错（无法找到）

我这里用了一种简单粗暴的方法，安装全部php扩展

yum install php-*

然后启动php

systemctl start php-fpm

然后将php添加到开机启动

systemctl enable php-fpm

输入

systemctl status php-fpm

查看运行状态，显示running即可

最后重启apache:

systemctl restart httpd

到此环境配置全部结束，根据参考文档，apache默认解析目录是在 /var/www/html 目录下，可更改成 /var/www 目录。

vim /etc/httpd/conf/httpd.conf

从 DocumentRoot “var/www/html/" 开始 改成 ”var/www/"，按下esc，输入:wq!保存并退出，然后重启apache：

systemctl restart httpd

5.测试

在/var/www/目录下新建文件 index.php 随便写点内容，然后保存，terminal输入

ifconfig | grep inet

查询本机ip

然后在pc中打开浏览器，输入192.168.44.128回车，看到正常显示php中的内容即可

三.Burp suite

分享一个安装网站：https://www.cnblogs.com/wangjunjiehome/p/10709198.html解压安装包（安装包在钉钉里），解压完成后打开burp-loader-keygen-2020_2.jar和burpsuite_pro_v2020.2.jar，工具运行需要Java环境，需要提前安装Java环境。

1.启动burp

通过burploader点击run打开Burpsuit

2.激活Burp

将Keygen中License复制粘贴到burpsuite中，点击next。

点击Manual activation

点击Copy request

点击Copy request，复制到keygen的Activation Request框里，然后Activation Response框里就有了结果

复制Activation Response框里的内容到burp剩下的那个框里，点击next

显示激活成功

再点击next

再点击Start Burp，即可打开主页面

如果用火狐浏览器去安装一个插件SwitchyOmega分享一个SwitchyOmega在火狐上的配置教程：https://www.cnblogs.com/nicole-zhang/p/11955881.html。
