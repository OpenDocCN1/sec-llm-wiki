3、PNG文件隐写

注：在进行png的题目时应先把文件放入010与identify中查看信息

文件头：89 50 4E 47

  

IHDR：第一个出现在数据流中的数据块，存储着宽高。

判断是否需要修改宽高:

长 \* 宽 \* 3 然后查看IDAT块的数据长度，若不一致则需要修改。

如果修改后发生报错可以考虑修改CRC校验和：

除了数据长度以外的部分进行选择，然后在工具里找到校验和进行计算，将新得到的CRC复制到IHDR数据块的校验和位置处，保存即可。

IDAT数据块：

存储图像像素信息，只有当一个IDAT数据块填满时才会对下一个IDAT数据块进行填充。

采用的压缩方法可以使用python的zlib模块解压：

*   
*   

```
import zlibzlib.decompress(data)
```

tcp数据包中的Flags字段存有标识字段：SYN，ACK，FIN，RST，PSH

SYN：建立连接

ACK：响应

FIN：结束连接

RST：重置连接

PSH：有DATA数据流传输，设置为1时要求数据尽快交给应用层

URG：设置为1时，首部中的紧急指针有效，Urgent pointer会有数值

再看本题，会发现Flags的标识字段有区别
