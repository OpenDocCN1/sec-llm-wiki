很容易让人联想到这是二维码题型，使用python脚本将其转换为二维码图片

使用python的外置库Pillow

这里对Pillow库进行简单的介绍：

Pillow是PIL的一个派生分支，但如今已经发展成为比PIL本身更具活力的图像处理库。pillow可以说已经取代了PIL，将其封装成python的库（pip即可安装），且支持python2和python3，目前最新版本是3.0.0。

在cmd中使用命令： pip install pillow 即可安装Pillow库

启用python并调用Pillow库中的Image类![](../Images/b6958544e4fb1e7cac81151813913993.png)

将0和1的字符赋值给data1，这里使用replace将所有的换行符‘\\n’替换成空![](../Images/003239498156ee3685d1fac965ba5fbf.png)

![](../Images/75f9742e08f693325a0566aea52cf8cb.png)

使用len()计算data1的长度![](../Images/cc97cd91016a1c59b951247616b477dd.png)

计算出是45\*45的图像大小，使用Image类创建图像im，并设置其大小为45\*45

 im = Image.new("RGB",(45\*45))

二维码是由黑白二色组成的图片

所以我们这里可以将data1中的字符‘1’转换成(255,255,255)的黑色，‘0‘转换成(0,0,0)的白色

 data2=\[\]

 for i in data1:

       if i=='1':

               data2 += \[(255,255,255)\]

       else: 

                data2 += \[(0,0,0)\]

使用putdata()将修改好的值放入新建的图像im中，并用show()将创建好的图片展示出来

 im.putdata(data2)

im.show()

![](../Images/84e73147f16f781f366ae9f5c6e26797.png)

扫描后得到flag值
