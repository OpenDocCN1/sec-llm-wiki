Sublime的安装即汉化


Sublime官网地址：http://www.sublimetext.cn/或前往我分享的网址下载：https://www.lanzous.com/b00nfqjuj 密码:7w8x

2、安装成功后打开Sublime，使用快捷键Ctrl+Shift+P，弹出搜索栏，如图

3、在搜索框中输入关键字 install ,出现下拉选项，点击选择其中的：Package Control: Install Package（注意：刚点击之后并不会立刻有反应，需要稍等一会）,如图：

4、然后就会弹出一个消息框，表示插件列表加载完成，出现如下列表：

5、在搜索框中输入Chinese，选择下拉框中的ChineseLocalizations（注意：刚点击之后并不会立刻有反应，需要稍等一会），如图：

在等待安装完成后，它会自动切换为中文如没有则关闭重启，重启以后依然没有则点击任务栏中的Help->最下面的Language->简体中文


Python编译系统配置


1、点击上方任务栏中的工具->编译系统->新建编译系统

2、删除大括号内的代码后将以下代码黏贴到大括号：

（红色加粗部分请替换成你的python.exe所在的目录 注意是\\）

编译系统1：Python2

    "encoding": "utf-8",  

    "working_dir": "$file_path",  

    "shell_cmd": "E:\\python2.7\\python2.exe -u \"$file\"",  

    "file_regex": "^[ ]*File \"(...*?)\", line ([0-9]*)",  

    "selector": "source.python" 

保存名为：python2.sublime-build

编译系统2：Python3

    "encoding": "utf-8",  

    "working_dir": "$file_path",  

    "shell_cmd": "E:\\python3.8\\python3.exe -u \"$file\"",  

    "file_regex": "^[ ]*File \"(...*?)\", line ([0-9]*)",  

    "selector": "source.python" 

保存名为：python3.sublime-build

3、配置完成后，关闭Sublime重启。在编译系统出可选择python2或3。

Ctrl+B 运行代码即可
