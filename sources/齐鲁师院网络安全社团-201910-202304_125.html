在 Linux 服务器部署 Halo


使用环境：

  • Centos 7.5

  • 512MB以上的内存

  • 阿里云服务器


1、服务器配置

1.1 开放8090端口

因为 halo 默认采用的是8090端口，应该首先在阿里云控制台将安全组里的规则开放8090端口，过程可以百度，这个就不详细写了。


1.2 更新软件包

sudo yum update -y

确保服务器的软件包已经是最新的。


1.3 安装 Java 运行环境

安装 OpenJRE

sudo yum install java-1.8.0-openjdk -y

检测是否安装成功

java -version

这种安装方式比较简单，也可以使用其他方式安装，若已经存在 Java 运行环境的可略过这一步。


2、安装 Halo

2.1 下载配置文件

下载配置文件到 ~/.halo 目录

curl -o ~/.halo/application.yaml --create-dirs https://dl.halo.run/config/application-template.yaml

2.2 修改配置文件

使用 Vim 工具修改配置文件

vim ~/.halo/application.yaml
完成上一步操作，就可以自己配置 Halo 的运行端口，以及数据库相关的配置了。

打开之后我们可以看到

    server:        port: 8090
        # Response data gzip.        compression:          enabled: false    spring:        datasource:
          # H2 database configuration.          driver-class-name: org.h2.Driver          url: jdbc:h2:file:~/.halo/db/halo          username: admin          password: 123456
          # MySQL database configuration.     #    driver-class-name: com.mysql.cj.jdbc.Driver     #    url: jdbc:mysql://127.0.0.1:3306/halodb?characterEncoding=utf8&useSSL=false&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true     #    username: root     #    password: 123456
       # H2 database console configuration.       h2:         console:           settings:             web-allow-others: false           path: /h2-console           enabled: false
    halo:
      # Your admin client path is https://your-domain/{admin-path}      admin-path: admin
      # memory or level      cache: memory
里面的内容可能会有所不同，但都大同小异，这里不建议修改里面的内容，有修改的东西，下面会提到，到时候再回头来改即可。


3、安装并运行 Halo

3.1 下载Halo

下载最新的 Halo 安装包，目前最新版为 1.3.2

  wget https://dl.halo.run/release/halo-1.3.2.jar -O halo-latest.jar

启动测试

java -jar halo-latest.jar
如果是别的版本，可以选择将1.3.2改成别的x.x.x即可，另外这地方不推荐使用启动测试。
上面就已经完成了 Halo 的整个配置和安装过程，但是我们如果关闭 ssh 连接，Halo 也将被关闭，所以要想一直处于运行状态，就需要继续做一些其他的设置。


3.2 下载新的 halo.service 配置文件

下载 Halo 官方的 halo.service 模板

sudo curl -o /etc/systemd/system/halo.service --create-dirs https://dl.halo.run/config/halo.service
我们下载这个模板进行完善设置，比如设置开机自启，这样就可以断掉ssh的时候也可以继续使用博客。


3.3 修改halo.service

修改 halo.service

sudo vim /etc/systemd/system/halo.service

打开之后我们可以看到

    [Unit]    Description=Halo Service    Documentation=https://halo.run    After=network-online.target    Wants=network-online.target
    [Service]    Type=simple    ExecStart=/usr/bin/java -server -Xms256m -Xmx256m -jar JAR_PATH    ExecStop=/bin/kill -s QUIT $MAINPID    Restart=always    StandOutput=syslog
    StandError=inherit
    [Install]    WantedBy=multi-user.target
其实只需要修改 JAR_PATH 就行了,将其换成自己的halo项目地址。
如果你是按照我上面的方法安装的，直接把 JAR_PATH 换成  /root/halo-latest.jar 就行了。


3.4 运行 Halo

修改 service 文件之后需要刷新 Systemd

sudo systemctl daemon-reload

使 Halo 开机自启

sudo systemctl enable halo

重启 Halo

sudo service halo restart
输入 sudo service halo restart 时可能会出现 Redirecting to /bin/systemctl restart halo.service 的提示，此时直接在次输入 /bin/systemctl restart halo.service 命令即可。
完成上述操作，就可以在浏览器输入 你的IP:8090 进行访问了，如果访问成功就说明已经将Halo部署到你的服务器了。


4、更改端口

如果想要直接在浏览器输入 IP 就可以访问到博客，这时候就可以进行下面的设置。


4.1 修改配置文件

使用 Vim 工具修改配置文件

vim ~/.halo/application.yaml

打开之后我们可以看到

 

    server:        port: 8090
        # Response data gzip.        compression:          enabled: false    spring:        datasource:
          # H2 database configuration.          driver-class-name: org.h2.Driver          url: jdbc:h2:file:~/.halo/db/halo          username: admin          password: 123456
          # MySQL database configuration.     #    driver-class-name: com.mysql.cj.jdbc.Driver     #    url: jdbc:mysql://127.0.0.1:3306/halodb?characterEncoding=utf8&useSSL=false&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true     #    username: root     #    password: 123456
       # H2 database console configuration.       h2:         console:           settings:             web-allow-others: false           path: /h2-console           enabled: false
    halo:
      # Your admin client path is https://your-domain/{admin-path}      admin-path: admin
      # memory or level      cache: memory
halo 默认使用的端口是 8090 ，只需要将默认端口改为 80 即可。
修改 server 下面的 port: 8090 修改为 port: 80 。


4.2 重启 Halo

sudo service halo restart
输入 sudo service halo restart 时可能会出现 Redirecting to /bin/systemctl restart halo.service 的提示，此时直接在次输入 /bin/systemctl restart halo.service 命令即可。
因为修改了配置文件所以需要重启一下 Halo，这时候在浏览器输入   你的IP 即可成功访问。
