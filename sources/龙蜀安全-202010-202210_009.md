## 提权

查看系统信息

```
sysinfo
```

不知为何无法执行命令

![](../Images/6f59940b622279fcced631adb5f4a55b.png)

  

  

使用老版kali（192.168.1.12）

![](../Images/9bfeef7027d085c7e0d990a589b2e4c2.png)

  

  

内核版本为2.6.18-92.el5，在互联网查漏洞利用https://www.exploit-db.com/exploits/8478

![](../Images/2dcd796f1980ed72f712ad7ba5df3138.png)

  

  

将提权脚本下载并查看

![](../Images/02dada5dd3333c9ffe7dceb290d047cf.png)

  

  

将dos格式修改为linux格式

```
dos2unix 8478.sh
```

![](../Images/96a6305d56685f1a9d23246a7193b312.png)

  

  

上传到靶机上的tmp目录中

![](../Images/b2e48e19d2068e6bb9cdd56012d513d5.png)

  

  

赋予脚本执行权限并执行

```
chmod +x 8478.sh
```

![](../Images/d1e36e1fbb47797d7dd099ec971c09a3.png)

  

  

报错，因为必须为脚本提供正确的 PID 才能使代码正常工作。所以现在我们必须找到一个合适的 PID，并在该 PID 的帮助下运行脚本

```
cat /proc/net/netlink
```

![](../Images/b8b9054caaa4aee252c2e1724623f966.png)

  

  

执行脚本，多尝试几次，成功得到root权限

```
./8478.sh 568
```

![](../Images/a1c799ae2239bd8fba175b6ec19cc2f6.png)
