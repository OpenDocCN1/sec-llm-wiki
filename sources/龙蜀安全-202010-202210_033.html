Hexo框架搭建博客

前言

    闲来无事想搭建一个博客玩玩，于是就上阿里云买了服务器和域名，于是就有了这篇文章。服务器买的是轻量应用服务器前三年每年99元，域名是三年59元，就让这个博客记录我毕业工作三年的成长吧。废话不多说先来看看成果。

XMTX的博客：http://www.xmtxsec.top

    Hexo是一个快速、简单且功能强大的博客框架。你用Markdown（或其他标记语言）写帖子，Hexo 会在几秒钟内生成带有漂亮主题的静态文件。


本地环境部署

安装git

可以在淘宝 Git for Windows 镜像 下载 git 安装包。


双击运行安装，修改好安装路径，一路next即可


安装完成可以在命令行输入git验证是否安装成功


安装Node.js

可以前往 淘宝 Node.js 镜像 下载。官方的 安装程序。一路next即可。


在命令行中可以使用node -v查看是否安装成功


检测npm是否安装成功


安装Hexo

    在电脑里创建一个文件夹，可以命名为Blog，Hexo框架与以后你自己发布的网页都在这个文件夹中。创建好后，进入文件夹中，按住shift键，右击鼠标点击命令行


使用nmp按包装Hexo

npm install -g hexo-cli


可以使用 hexo -v 查看是否安装成功


初始化博客

hexo init blog


查看blog目录


_config.yml网站的配置信息，您可以在此配置大部分的参数。
package.json应用程序的信息。
scaffolds模版文件夹。当您新建文章时，Hexo 会根据 scaffold 来建立文件。
Hexo的模板是指在新建的文章文件中默认填充的内容。例如，如果您修改scaffold/post.md中的Front-matter内容，那么每次新建一篇文章时都会包含这个修改。
source资源文件夹是存放用户资源的地方。除 _posts文件夹之外，开头命名为 _ (下划线)的文件 / 文件夹和隐藏的文件将会被忽略。Markdown 和 HTML 文件会被解析并放到 public 文件夹，而其他文件会被拷贝过去。
themes主题文件夹。Hexo 会根据主题来生成静态页面。


检测网站是否成功

hexo new Hello World  --新建一篇文章hexo g                 --生成网页hexo s                 --在本地预览


在浏览器中访问

http://localhost:4000


Hexo命令简介

npm install hexo -g #安装Hexonpm update hexo -g #升级hexo init #初始化博客
命令简写hexo n "我的博客" == hexo new "我的博客" #新建文章hexo g == hexo generate #生成hexo s == hexo server #启动服务预览hexo d == hexo deploy #部署
hexo server #Hexo会监视文件变动并自动更新，无须重启服务器hexo server -s #静态模式hexo server -p 5000 #更改端口hexo server -i 192.168.1.1 #自定义 IPhexo clean #清除缓存，若是网页正常情况下可以忽略这条命令


配置SSH密钥

鼠标右击打开Git Bash


设置user.name和user.email配置信息：

git config --global user.name "你的用户名"git config --global user.email "你的邮箱"



生成ssh密钥文件，输入命令后直接连续三个回车即可

ssh-keygen -t rsa -C "你的邮箱"


找到生成的.ssh的文件夹中的id_rsa.pub密钥，将内容全部复制后面用得上。



服务器环境部署

安装宝塔

    为了方便省时这里我就直接选择使用宝塔面板来安装LNMP（可以只安装Nginx，我这里装LNMP当然是还有其他的用途【狗头】）

Centos系统一键安装宝塔面板

yum install -y wget && wget -O install.sh http://download.bt.cn/install/install_6.0.sh && sh install.sh


在防火墙规则中开启8888端口，要不然是无法访问到宝塔面板滴！


安装LNMP

直接选择一键安装(没有其他需求可以只安装Nginx)


接下来就是漫长的等待了


git配置

安装git

yum install git


创建账户

adduser hexo


给创建的账户赋予权限

chmod 740 /etc/sudoersvim /etc/sudoers

在root ALL=(ALL) ALL 下面添加

hexo ALL=(ALL) ALL


改回权限

chmod 400 /etc/sudoers


设置hexo账户密码

passwd hexo


切换至hexo用户，创建 ~/.ssh 文件夹和 ~/.ssh/authorized_keys 文件，并赋予相应的权限

su hexomkdir ~/.sshvim ~/.ssh/authorized_keys


将生成的id_rsa.pub文件中的公钥复制到authorized_keys中


赋予权限

chmod 600 /home/hexo/.ssh/authorized_keyschmod 700 /home/hexo/.ssh


测试是否能免密登录git，其中SERVER为填写自己的云主机IP，执行输入yes后输入你之前配置的hexo密码，无报错就说明好了

ssh -v hexo@server_ip



创建仓库目录及相关配置

在var目录下创建repo作为Git仓库目录，返回服务端命令行切换到root账户，然后输入

mkdir /var/repo


赋予权限

chown -R hexo:hexo /var/repochmod -R 755 /var/repo


创建hexo目录作为网站根目录

mkdir /www/wwwroot/hexochown -R hexo:hexo /www/wwwroot/hexochmod -R 755 /www/wwwroot/hexo


接下来创建一个空白的git仓库

cd /var/repogit init --bare hexo.git


创建一个新的 Git 钩子，用于自动部署

在 /var/repo/hexo.git 下，有一个自动生成的 hooks 文件夹。我们需要在里边新建一个新的钩子文件 post-receive。

vim /var/repo/hexo.git/hooks/post-receive

进入编辑模式，然后将下面那两行代码粘贴进去，保存退出。

#!/bin/bashgit --work-tree=/www/wwwroot/hexo --git-dir=/var/repo/hexo.git checkout -


修改权限

chown -R hexo:hexo /var/repo/hexo.git/hooks/post-receivechmod +x /var/repo/hexo.git/hooks/post-receive


配置nginx

这里我就直接在宝塔中配置了


修改Hexo配置

进入本地电脑hexo博客的根目录，编辑站点配置文件 _config.yml，找到deploy，修改成以下

deploy:  type: git  repo: hexo@XXX.XXX.XXX.XXX:/var/repo/hexo.git  branch: master


最后在本地电脑hexo博客的根目录，打开终端，输入以下命令部署

hexo cleanhexo d -g

可能会报错


输入以下命令即可

npm install --save hexo-deployer-git


可能会因为权限问题而报错.


在服务器输入以下命令即可

chown -R hexo:hexo /var/repo/chown -R hexo:hexo /www/wwwroot/hexo/


在浏览器中测试，成功访问即可。

http:www.xmtxsec.top


美化

我这里选择的是使用hexo-theme-butterfly的主题

直接进入blog目录输入命令下载

npm i hexo-theme-butterfly


如下修改 Hexo 博客目录中的 _config.yml：

theme: butterfly  # 指定主题language: zh-CN  # 指定语言，会影响主题显示的语言，按需修改


如果你沒有pug以及stylus的渲染器，请下载安裝（这是我这个主题所需要的）：

npm install hexo-renderer-pug hexo-renderer-stylus --save


在浏览器中访问，部署成功。


主题的美化在每个主题的文档中都有相应的教程，不是很难。

到此博客的搭建就完成了，我大约是花了两周的时间，大部分时间都用在了域名备案和主题美化上，期间还更换了一次主题。
