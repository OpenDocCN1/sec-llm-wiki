# 前言

    闲来无事想搭建一个博客玩玩，于是就上阿里云买了服务器和域名，于是就有了这篇文章。服务器买的是轻量应用服务器前三年每年99元，域名是三年59元，就让这个博客记录我毕业工作三年的成长吧。废话不多说先来看看成果。

XMTX的博客：http://www.xmtxsec.top

    Hexo是一个快速、简单且功能强大的博客框架。你用Markdown（或其他标记语言）写帖子，Hexo 会在几秒钟内生成带有漂亮主题的静态文件。

## 创建仓库目录及相关配置

在var目录下创建repo作为Git仓库目录，返回服务端命令行切换到root账户，然后输入

*   

```

```

  

赋予权限

*   
*   

```
chown -R hexo:hexo /var/repochmod -R 755 /var/repo
```

  

创建hexo目录作为网站根目录

*   
*   
*   

```
mkdir /www/wwwroot/hexochown -R hexo:hexo /www/wwwroot/hexochmod -R 755 /www/wwwroot/hexo
```

  

接下来创建一个空白的git仓库

*   
*   

```
cd /var/repogit init --bare hexo.git
```

  

创建一个新的 Git 钩子，用于自动部署

在 /var/repo/hexo.git 下，有一个自动生成的 hooks 文件夹。我们需要在里边新建一个新的钩子文件 post-receive。

*   

```

```

进入编辑模式，然后将下面那两行代码粘贴进去，保存退出。

*   
*   

```
#!/bin/bashgit --work-tree=/www/wwwroot/hexo --git-dir=/var/repo/hexo.git checkout -
```

![](../Images/2c9b31dd1d3ee412eb2b09be2b0b8b39.png)

  

修改权限

*   
*   

```
chown -R hexo:hexo /var/repo/hexo.git/hooks/post-receivechmod +x /var/repo/hexo.git/hooks/post-receive
```

## 修改Hexo配置

进入本地电脑hexo博客的根目录，编辑**站点配置文件 \_config.yml**，找到deploy，修改成以下

*   
*   
*   
*   

```
deploy:  type: git  repo: hexo@XXX.XXX.XXX.XXX:/var/repo/hexo.git  branch: master
```

![](../Images/7efd0cddecd4f1f18a2358255aabe5bf.png)
