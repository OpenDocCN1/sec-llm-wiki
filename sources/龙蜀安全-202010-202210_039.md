**题目要求**

    确定哪个字段易受 XSS 影响   在服务器端验证所有输入始终是一个好习惯。  当在 HTTP 响应中使用未经验证的用户输入时，可能会发生 XSS。  在反射型 XSS 攻击中，攻击者可以使用攻击脚本制作一个 URL，并将其发布到另一个网站、通过电子邮件发送或以其他方式让受害者点击它。   找出字段是否容易受到 XSS 攻击的一种简单方法是使用 alert() 或 console.log() 方法。  使用其中之一来找出哪个字段易受攻击。

    你的目标是找到路线并利用它。  首先……什么是基本路线？  例如，查看本课程的 URL……它应该类似于  /WebGoat/start.mvc#lesson/CrossSiteScripting.lesson/9。  在这种情况下，“基本路由”是：  start.mvc#lesson/ CrossSiteScripting.lesson/9 之后是 JavaScript  路由处理程序处理的参数。

  

在生产过程中留在应用程序中的测试代码的路径是什么？  要回答这个问题，您必须检查 JavaScript 源代码。
