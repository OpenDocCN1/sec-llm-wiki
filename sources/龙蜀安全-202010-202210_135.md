# 环境搭建

sqli-labs、phpstudy、wampserve均已上传至知识星球，可自行下载。

  

## 使用phpstudy搭建

可搭建在虚拟机，然后使用桥接模式，或者NAT模式在主机上输入ip进行访问。

1.将下载的phpstudy安装（安装路径不要有中文）

![](../Images/dc19aa2ef06eab6e8ad709a775c44c7c.png)

  

2.安装完成后打开www目录将下载的sqli-labs放到www目录里面

![](../Images/0244a97201c9453018227c3c17e70ad9.png)

  

3.打开sqli-libs文件夹，找到并打开sql-connections文件夹，打来其中的db-credswe文件

![](../Images/545db9371aa7695f51579c53cd123962.png)

  

4.将$dbpass改为root并保存

![](../Images/7d724d9b509bda5a53778cd6934b1096.png)

  

5.启动服务，并在浏览器中打开127.0.0.1/sqli-labs

![](../Images/a69143192e3f6bb17716e3151dc22b65.png)

  

6.点击setup/reset database for labs

![](../Images/3097e5d4785789180efedda63c8b8815.png)

  

**成功，可以开始愉快的玩耍了。**

  

## 使用wampserver搭建

建议搭建在物理机方便使用

1.下载wampserver并安装

![](../Images/9289cfaf456388c674407967faf490aa.png)

  

2.安装完成后打开www目录，将sqli-labs放入www目录为了方便我修改为sql

![](../Images/9eb8a3994d1412b4aa3920474e92cab4.png)

  

3.在浏览器中输入127.0.0.1/sql

![](../Images/2cbf16e4a673f55de65b5216c0a0aacf.png)

  

4.点击Setup/reset Database for labs有点小毛病，这是用因为在新的php版本中不支持mysql\_connect():函数，不过问题不大，亲测不影响使用

![](../Images/13d35d75a4bbe4327a580a5aee203495.png)

  

打开第一关输入?id=1

![](../Images/1b242215de4ddec52cd4c58ae51e4b2e.png)

ok可以愉快的玩耍了。

  

## 在kali中搭建

可搭建在虚拟机，然后使用桥接模式，或者NAT模式在主机上输入ip进行访问。

1.查看kali的apach服务和mysql是否可用打开终端输入service apache2 start

![](../Images/882e0128f4d2269c868a153b98f489ac.png)

  

打开浏览器输入127.0.0.1

![](../Images/a6f1d40a5c9459d50b9839fee8880485.png)

ok没有问题

  

在终端输入 service mysql start

![](../Images/2337b4ad3fd8ed86d4317989debed4e3.png)

  

打开mysql

```
mysql -u root -p
```

![](../Images/ecd4011660a491b01c5e7a8343bbc363.png)

  

ok也没有问题

  

2.打开目录文件系统/var/www将sqli-labs文件放在www目录里面

![](../Images/12bb923d558ca7caf9733479d70f47ce.png)

  

3.在浏览器中输入127.0.0.1/sqli-labs

![](../Images/c5298adfd74586680406bd618c6080a7.png)

  

点击Setup/reset Database for labs

![](../Images/31649612209c33764c4e4029bc8eb980.png)

  

4.在数据库查看是否有security库

![](../Images/e7c447d30a8593a5e166ff3ea0cc4d02.png)

  

ok可以开始愉快的玩耍了。
